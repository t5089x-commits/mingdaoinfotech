02追蹤表：把電腦做的事寫在紙上

追蹤表的寫法：每一欄是一個變數，每一列是迴圈跑完一次之後的狀態。迴圈條件、印出的東西也可以一起寫。

要追蹤的程式 
s = 0
i = 1
while i < 20:
    s = s + i
    i = i * 3
print(s, i)
▼ 執行結果 13 27
第幾次條件 i < 20s = s + ii = i * 3
開始前—s = 0i = 1
11 < 20 ✓s = 1i = 3
23 < 20 ✓s = 4i = 9
39 < 20 ✓s = 13i = 27
427 < 20 ✗，離開迴圈

所以印出 13 27。單元 4 有巢狀迴圈的逐步動畫，單元 7 有函式呼叫的互動追蹤，可以回去複習追蹤的節奏。

03Python 識讀陷阱整理

下面這些是 Python 題本最容易出陷阱的地方，大部分在前面的單元都學過，這裡集中複習。每一個都附上程式和真正的執行結果。

① b = a 不是複製

兩個名字指向同一個串列，改 b 等於改 a。要複製一份新的，用 a[:] 或 a.copy()。 （回去看：單元 5 §05）

執行看看 
a = [1, 2, 3]
b = a
c = a[:]
b.append(4)
print(a)
print(c)
▼ 執行結果 [1, 2, 3, 4] [1, 2, 3]

② // 是「往下取整」，負數要小心

// 不是「去掉小數」，而是取比較小的那個整數。正數看不出差別，負數就不一樣了。% 的結果正負號跟除數一樣。 （回去看：單元 3 §01）

執行看看 
print(7 // 2, -7 // 2)
print(7 % 3, -7 % 3)
print(int(-7 / 2))   # 這個才是去掉小數
▼ 執行結果 3 -4 1 2 -3

③ and、or 回傳的是「值」

a and b：a 是假就回傳 a，否則回傳 b。a or b：a 是真就回傳 a，否則回傳 b。不一定是 True／False。 （回去看：單元 3 §02）

執行看看 
print(3 and 5)
print(0 and 5)
print(3 or 5)
print(0 or 5)
▼ 執行結果 5 0 3 5

④ range 不包含終點

range(a, b) 跑到 b-1。range(0, 101, 5) 有 21 個數，不是 20 個（官方範例第 26 題）。 （回去看：單元 4 §02）

執行看看 
print(len(range(0, 101, 5)))
print(list(range(6, 0, -2)))
▼ 執行結果 21 [6, 4, 2]

⑤ 字串不能直接修改

s[0] = 'X' 會出錯。要改字串，用切片組出新字串。 （回去看：單元 6 §01）

執行看看 
s = 'apcs'
s = 'A' + s[1:]
print(s)
▼ 執行結果 Apcs

⑥ 0、''、[] 都是假

放在 if 或 while 後面時，0、空字串、空串列、None 都當成 False，其他都是 True（官方範例第 10 題）。 （回去看：單元 3 §02、單元 4 §01）

執行看看 
for x in [0, 5, '', 'a', [], [0]]:
    print(repr(x), bool(x))
▼ 執行結果 0 False 5 True '' False 'a' True [] False [0] True

⑦ 在 for 迴圈裡改 i，不會影響下一輪

for i in range(...) 每一輪都會重新從 range 拿下一個值，裡面改 i 只影響這一輪。while 迴圈才會被影響。

執行看看 
for i in range(5):
    print(i, end=' ')
    i = i + 10
print()
▼ 執行結果 0 1 2 3 4

⑧ 交換兩個變數

Python 可以直接 a, b = b, a。用暫存變數的寫法要注意順序（官方範例第 7、9 題）。 （回去看：單元 5 §04）

執行看看 
a, b = 1, 2
a, b = b, a
print(a, b)
x, y = 1, 2
x = y      # 錯誤示範：x 原本的值不見了
y = x
print(x, y)
▼ 執行結果 2 1 2 2

⑨ 函式裡改參數

傳進函式的如果是數字或字串，函式裡改它不會影響外面；如果是串列，用 append 或改元素會影響外面。 （回去看：單元 7 §03）

執行看看 
def f(n, lst):
    n = n + 1
    lst.append(9)

x = 1
a = [1]
f(x, a)
print(x, a)
▼ 執行結果 1 [1, 9]

⑩ 比較運算可以連寫

0 <= x < 10 等於 0 <= x and x < 10。 （回去看：單元 3 §02）

執行看看 
x = 5
print(0 <= x < 10, 10 < x < 20)
▼ 執行結果 True False

⑪ round() 不是課本的四捨五入

round() 遇到剛好 .5 時取偶數那一邊；int() 則是直接去掉小數（負數也一樣往 0 靠）。 （回去看：單元 2 §03）

執行看看 
print(round(2.5), round(3.5), round(4.6))
print(int(3.9), int(-3.9))
▼ 執行結果 2 4 5 3 -3
⇄ 學過 C++？這裡規則不一樣

上面不少陷阱，剛好是 C++ 和 Python 規則相反的地方：除法與餘數、and／or、b = a、迴圈變數。 完整對照見 C++ ⇄ Python 對照表。

04看懂錯誤訊息

程式出錯時，Python 會印出一段紅字。只要看最後一行：冒號前面是錯誤種類，後面是原因；往上一行的 line 幾 告訴你錯在第幾行。

IndentationError：縮排錯誤

if 後面那一行沒有縮排，或空白、Tab 混用。

會出錯的程式 
x = 5
if x > 3:
print(x)
▼ 執行結果 （沒有輸出） File "程式.py", line 3 print(x) IndentationError: expected an indented block after 'if' statement on line 2

SyntaxError：語法錯誤

少了冒號、括號沒成對、用了全形符號。

會出錯的程式 
for i in range(3)
    print(i)
▼ 執行結果 （沒有輸出） File "程式.py", line 1 for i in range(3) SyntaxError: expected ':'

NameError：名字沒定義

變數或函式名稱打錯、還沒指定就使用。

會出錯的程式 
total = 10
print(totl)
▼ 執行結果 （沒有輸出） Traceback (most recent call last): File "程式.py", line 2, in <module> NameError: name 'totl' is not defined. Did you mean: 'total'?

TypeError：型態不對

字串和數字相加，最常見的是忘了把 input() 轉成 int。

會出錯的程式 
age = '16'
print(age + 1)
▼ 執行結果 （沒有輸出） Traceback (most recent call last): File "程式.py", line 2, in <module> TypeError: can only concatenate str (not "int") to str

ValueError：值不能轉換

一行有好幾個數字卻用 int(input()) 讀。

會出錯的程式 
line = '3 5'
n = int(line)
▼ 執行結果 （沒有輸出） Traceback (most recent call last): File "程式.py", line 2, in <module> ValueError: invalid literal for int() with base 10: '3 5'

IndexError：索引超出範圍

串列只有 3 個元素卻拿 a[3]，或迴圈多跑了一次。

會出錯的程式 
a = [10, 20, 30]
for i in range(4):
    print(a[i])
▼ 執行結果 10 20 30 Traceback (most recent call last): File "程式.py", line 3, in <module> IndexError: list index out of range

ZeroDivisionError：除以 0

平均數時資料筆數是 0。

會出錯的程式 
scores = []
print(sum(scores) / len(scores))
▼ 執行結果 （沒有輸出） Traceback (most recent call last): File "程式.py", line 2, in <module> ZeroDivisionError: division by zero

KeyError：字典沒有這個鍵

還沒放進字典就去讀。用 d.get(k, 0) 可以避免。

會出錯的程式 
d = {'a': 1}
print(d['b'])
▼ 執行結果 （沒有輸出） Traceback (most recent call last): File "程式.py", line 2, in <module> KeyError: 'b'

05常考題型：找錯與設計測資

官方範例裡大約有 6 題是「這段程式有錯，哪一個輸入可以測出來」或「哪一行永遠不會執行」。解法是專挑邊界情況去試：

測資類型例子常抓到的錯
最小／最大值n = 1、分數 0 和 100迴圈範圍少一個、比較用 < 還是 <=
剛好在分界上成績剛好 60、70、80> 和 >= 寫錯、判斷順序錯（第 17 題）
找不到的情況要找的數比全部都大二分搜尋的邊界（第 22 題）
排列順序不同遞增、遞減、全部一樣只處理了某一種順序（第 29 題）
官方範例第 17 題的程式：分數區間判斷順序錯了 
def grade(s):
    if s >= 90:
        return 'A'
    elif s >= 80:
        return 'B'
    elif s > 60:          # 應該要先判斷 70
        return 'D'
    elif s > 70:          # 永遠不會執行到
        return 'C'
    else:
        return 'F'

print([grade(s) for s in [95, 85, 75, 65, 60, 30]])
▼ 執行結果 ['A', 'B', 'D', 'D', 'F', 'F']

75 應該是 C，卻被判成 D；60 應該是 D，卻被判成 F。只要把 60、70、75 這些分界附近的數代進去，錯誤馬上出現。

06常考題型：執行幾次？時間複雜度 O( )

效能分析題會問「迴圈執行了幾次」或「比較了幾次」。記住這幾個常見的模式：

程式執行次數寫成 O( )說明
for i in range(n)nO(n)最基本
for i in range(n): for j in range(n)n × nO(n²)兩層都跑 n 次
for i in range(n): for j in range(m)n × mO(mn)兩層各跑各的，兩個變數都要留著
for i in range(n): for j in range(i, n)n + (n-1) + … + 1 = n(n+1)/2O(n²)內層越跑越少，但還是 n² 等級
k = 1; while k <= n: k *= 2⌊log₂n⌋ + 1O(log n)每次翻倍，n = 20 跑 5 次
循序搜尋 n 筆資料最多 n 次O(n)從頭一個一個比
二分搜尋 n 筆已排序資料最多約 log₂n + 1 次O(log n)每次砍掉一半，100 筆最多 7 次
循序搜尋 vs. 二分搜尋 
a = [3 * k + 1 for k in range(100)]      # 官方範例第 6 題的資料
target = 100

n1 = 0
for i in range(100):                     # 循序搜尋
    n1 += 1
    if a[i] == target:
        break

n2, low, high = 0, 0, 99                 # 二分搜尋
while low <= high:
    n2 += 1
    mid = (low + high) // 2
    if a[mid] == target:
        break
    elif a[mid] < target:
        low = mid + 1
    else:
        high = mid - 1
print("循序", n1, "次；二分", n2, "次")
▼ 執行結果 循序 34 次；二分 5 次
每次翻倍的迴圈 
n = 20
cnt, k = 0, 1
while k <= n:
    cnt += 1
    k *= 2
print(cnt)
▼ 執行結果 5

把執行次數寫成 O( )：時間複雜度

識讀題常不問「剛好幾次」，而是問「時間複雜度是哪一個」，選項長得像 O(n)、O(n²)、O(mn)。O( ) 只看「資料變大時，次數長多快」，寫法只要記兩條規則：

  1. 只留最大的那一項：n² + 3n + 5 → O(n²)。n 很大時，n² 比 3n 大太多，後面的項可以不管。
  2. 常數倍數拿掉：3n → O(n)；n(n+1)/2 = n²/2 + n/2 → O(n²)。

題目有兩個變數（例如 n 列、m 行）時，兩個都要留著：兩層迴圈各跑 n 次、m 次是 O(mn)，不能寫成 O(n²)；兩個迴圈一前一後（不是包在一起）各跑 n、m 次，是 O(m + n)。

寫法唸法例子（n = 1000 大約跑幾次）
O(1)常數a[i]、x + y：跟 n 無關，1 次
O(log n)對數二分搜尋、每次翻倍的迴圈：約 10 次
O(n)線性一層迴圈、循序搜尋：1000 次
O(n log n)sorted() 排序：約 1 萬次
O(n²)平方兩層迴圈：100 萬次
O(2ⁿ)指數沒有記錄的費氏數列遞迴：多到跑不完

迴圈裡呼叫函式時，要把函式本身跑幾次也算進去。下面的 g(k) 自己有一層 range(k) 的迴圈，外面再呼叫 n 次，總次數是 0 + 1 + … + (n-1)，所以是 O(n²)，不是 O(n)：

函式裡的迴圈也要算：n 變 10 倍，次數約變 100 倍 
def g(k):
    c = 0
    for i in range(k):      # 跑 k 次
        c += 1
    return c

for n in [10, 100, 1000]:
    total = 0
    for i in range(n):      # 呼叫 n 次，第 i 次跑 i 次
        total += g(i)
    print(n, total)
▼ 執行結果 10 45 100 4950 1000 499500
🔎 用「n 變 10 倍」來檢查

不確定答案時，想像 n 變成 10 倍：次數也變 10 倍是 O(n)，變 100 倍是 O(n²)，只多跑幾次是 O(log n)。如果函式裡的迴圈只跑到 i * i > k 就停（大約 √k 次），外面再呼叫 n 次，總共就是 n × √n ＝ O(n1.5)。

（第 4 題是用 head／tail 兩個索引模擬佇列，追蹤時把串列畫出來，標出 head、tail 指到哪裡）

  4. 印出什麼？ 
    s = 0
for i in range(10):
    if i % 3 == 0:
        continue
    if i == 8:
        break
    s += i
print(s)
    ▶ 顯示解答

    執行結果：

    19

    跳過 0、3、6，i 到 8 時結束，只加了 1、2、4、5、7，合計 19。

  5. 印出什麼？ 
    def f(x):
    x = x * 2
    return x

x = 3
f(x)
print(x)
    ▶ 顯示解答

    執行結果：

    3

    函式裡的 x 是區域變數，而且沒有用回傳值，外面的 x 還是 3。

  6. 下面程式想找串列的最大值，但有錯。輸入哪一組資料可以測出錯誤？
    (A) [3, 5, 7]　(B) [-3, -5, -7]　(C) [7, 5, 3]　(D) [5, 7, 3] 
    def biggest(a):
    m = 0
    for x in a:
        if x > m:
            m = x
    return m

print(biggest([-3, -5, -7]))
    ▶ 顯示解答

    執行結果：

    0

    答案是 (B)。m 從 0 開始，資料全部是負數時，沒有任何數比 0 大，回傳 0 是錯的。正確寫法是 m = a[0]。
