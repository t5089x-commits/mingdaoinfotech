明道中學 115學年度第一學期 資電APCS週六課程（資電群 APCS 程式設計能力培訓班）— 教學網站
  資料夾：apcs-ee/（跟普通高中部的 apcs/ 是兩個獨立課程，請勿混用）
===========================================================

■ 使用方式
1. 解壓縮整個資料夾（請保持資料夾結構完整，html 檔要和 assets 資料夾在一起）。
2. 用瀏覽器（Chrome / Edge / Safari）打開「index.html」即為課程首頁。
3. 從首頁點選任一單元進入獨立頁面上課。

■ 這門課在教什麼
  專為資電群二年級同學開設的 APCS 培訓課程，分兩梯次、每梯 4 次（星期六，
  每次 7 節）。從 Python 基礎開始，目標程式識讀 4 級分、程式實作中級 3 級分。
  第一梯：115/10/31、11/14、12/5、12/19；第二梯：115/11/7、11/21、12/12、116/1/9。

■ 功能
- 右上角月亮/太陽圖示可切換 淺色（預設）/ 深色。
- 每個 Python 範例右上角有「⧉ 複製」按鈕，複製到 IDLE 執行即可。
  （配合 APCS 考場不能上網，頁面刻意不放線上編譯器連結，見單元 1 附。）
- 單元7 有一個「函式呼叫追蹤」互動小工具，一步一步看參數怎麼傳進函式、
  回傳值怎麼傳出來（離線可用）。
- 練習題可展開解答（離線可用）。
- 按 Ctrl/⌘ + P 可列印或另存 PDF（練習解答會自動展開）。
