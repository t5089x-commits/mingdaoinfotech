上機評測基本功：ZeroJudge 與考場規則

邏輯都對卻拿 0 分？大多是輸入輸出格式的問題。第一次上 ZeroJudge 之前先讀這一頁。

🎯 學習目標

  • 知道 Judge 怎麼評分，看得懂 AC、WA、TLE、RE、CE 是什麼意思
  • 寫 Judge 題目時，input() 不放提示文字、輸出不多印說明文字
  • 會用 print(*a)、sep、end 控制輸出格式
  • 知道 APCS 考場只評分最後一次上傳的檔案，懂得「先拿子題分數」的作答策略

01Judge 是怎麼改你的程式？

ZeroJudge 和 APCS 考場的程式實作，都是由電腦自動評分。流程是這樣的：

①把測資當成「鍵盤輸入」餵給你的程式
➜
②收集你 print 出來的每一個字
➜
③跟標準答案逐字比對

重點在第 ③ 步：電腦不會「看懂」你的答案，它只會逐字比對。所以多印一個字、少一個空白、多一行，都會被判錯。一題通常有好幾筆測資（APCS 每題 20 筆），每通過一筆就拿那一筆的分數。

結果意思通常是哪裡出問題
AC　Accepted全部測資都通過🎉
NA　Not Accepted部分測資通過（ZeroJudge 的說法），會拿到部分分數子題只寫了簡單版、邊界情況沒處理
WA　Wrong Answer有執行完，但輸出跟答案不一樣邏輯錯、輸出格式錯、多印了提示文字
TLE　Time Limit Exceeded跑太久，超過時間限制無窮迴圈、迴圈層數太多、在等一筆不存在的輸入
RE　Runtime Error執行到一半當掉索引超出範圍、轉型失敗、除以 0（看下面的錯誤訊息）
CE　Compile Error程式根本沒辦法執行語法錯誤、縮排錯誤、選錯語言

02陷阱一：input() 括號裡不要放任何文字

很多課本和網路範例會寫 input("請輸入數字:")，讓使用者知道要輸入什麼；寫給人用的程式這樣很好。但是在 Judge 上，括號裡的提示文字會被印到輸出裡，跟答案混在一起，結果就是 WA。

❌ 會被判 WA

錯誤寫法 
a = int(input("請輸入 a:"))
b = int(input("請輸入 b:"))
print(a + b)
▼ 輸入（測資） 3 5 ▼ 執行結果 請輸入 a:請輸入 b:8

✅ 正確

正確寫法 
a = int(input())
b = int(input())
print(a + b)
▼ 輸入（測資） 3 5 ▼ 執行結果 8

左邊的執行結果就是 Judge 收到的輸出：「請輸入 a:請輸入 b:8」，跟正確答案「8」不一樣。在 IDLE 裡自己打字時，提示文字和你輸入的數字會分在不同行，看起來很正常，所以這個錯誤很難自己發現。

📌 規則

寫 Judge 題目時，input() 一律空括號。也不要印「答案是：」「請輸入」這類說明文字——題目要求印什麼，就只印什麼。
不是送 Judge 的程式（寫給別人用的小工具、專題作品），才在括號裡放提示文字，例如 input("請輸入分數：")。

03陷阱二：輸出格式要一字不差

題目的「輸出說明」和「範例輸出」就是格式規定。最常見的錯誤是把串列直接印出來：

❌ 直接印串列 
a = [3, 1, 4]
print(a)          # 會印出中括號和逗號
▼ 執行結果 [3, 1, 4]

題目通常要的是「用一個空白隔開」。有三種寫法都可以：

✅ 用空白隔開 
a = [3, 1, 4]
print(*a)                      # 寫法 1：* 把串列拆開，預設用空白隔開
print(" ".join(map(str, a)))   # 寫法 2：先轉成字串，再用空白接起來
for x in a:                    # 寫法 3：一個一個印，不換行
    print(x, end=" ")
print()
▼ 執行結果 3 1 4 3 1 4 3 1 4

寫法 1 的 * 是什麼？在串列前面加 *，意思是把串列「拆開」，一個一個傳給 print：print(*[3, 1, 4]) 就等於 print(3, 1, 4)。print 收到好幾個值時，預設用一個空白隔開，所以剛好是 Judge 要的格式。

想要的格式寫法印出
同一行、空白隔開print(a, b) 或 print(*lst)3 5
同一行、不要空白print(a, b, sep="")35
用逗號隔開print(*lst, sep=",")3,1,4
每個一行for x in lst: print(x)3
1
4
數字後面接符號print(f"{p}%")50%
小數點後兩位print(f"{x:.2f}")3.14

另一個常見錯誤是除法：題目要整數，你卻用 /，結果印出 2.0。

/ 和 // 印出來不一樣 
total, n = 10, 5
print(total / n)    # 2.0  ← 多了 .0，WA
print(total // n)   # 2    ← 整數除法
▼ 執行結果 2.0 2
✅ 送出前的檢查清單

① 範例輸入跑出來的結果，跟範例輸出逐字比對過嗎？ ② 有沒有多印說明文字或提示文字？ ③ 空白、換行、大小寫、標點跟範例一樣嗎？ ④ 該印整數的地方有沒有變成小數？

⇄ 學過 C++？這裡規則不一樣

C++ 的 7 / 2 是 3，Python 是 3.5；要整數一定要寫 //。 完整對照見 C++ ⇄ Python 對照表。

04用範例測資自己先測

每一題都會附「範例輸入／範例輸出」。在 IDLE 裡按 F5 執行後，把範例輸入整段複製、貼到 Shell 視窗，再按 Enter，就能看到你的程式印出什麼。

  1. 範例都對了，不代表一定 AC。範例通常很小，真正的測資會有更多情況。
  2. 自己再想幾組「邊界測資」測一下：只有 1 筆資料、全部一樣、最大值、最小值、0、負數。
  3. 多行的範例輸入可以一次貼上，input() 會一行一行讀。
💡 為什麼範例對了還是錯？

最常見的原因：① 只處理了範例剛好有的情況（例如範例沒有平手，你就沒處理平手）；② 迴圈範圍少算一個（range(n) 和 range(1, n)）；③ 題目說「保證」的條件你沒有用到，或是題目沒保證的你卻假設了。

05APCS 考場規則：只算最後一次上傳

APCS 官方〈作答系統說明〉有幾條規則一定要知道：

規則代表什麼
每一題只保留並評分最後一次上傳的檔案改到一半上傳，會蓋掉之前會過的版本。上傳前一定要先測過。
可以重複上傳，直到時間結束可以先上傳簡單版拿部分分，之後再上傳更好的版本。
程式檔名要照題目規定檔名錯了，系統找不到你的程式。
程式存在桌面的 backup 資料夾系統會自動備份到伺服器，不要存到別的地方。
提早交卷之後就不能再上傳確定每一題都上傳完成再交卷。

資料來源：APCS 作答系統說明（官方）↗，實際規定以當次考試公告為準。

06子題配分：先拿 60 分，再拚 100 分

中級每一題都分成兩個子題，例如官方範例「特殊位置」：

子題配分限制
第 1 子題60 分n = 1（只有一列）
第 2 子題40 分無額外限制

意思是：就算你只會處理「只有一列」的情況，也能拿 60 分。中級 3 級分只要 150 分，三題都先拿到 60 分就有 180 分了。

  1. 先讀子題限制，寫出能過第 1 子題的版本，測過範例後上傳。
  2. 把這個版本另存一份（例如 p1_60.py），再改進完整版。
  3. 完整版測過才上傳；如果時間不夠、改壞了，就把 60 分的版本再上傳回去。
⚠ 不要卡在一題

實作考 120 分鐘、3 題，平均一題 40 分鐘。卡住超過 15 分鐘就先換下一題，回頭再寫。

07ZeroJudge 送出步驟

  1. 到 zerojudge.tw ↗ 註冊、登入（可以用 Google 帳號）。
  2. 打開題目（課程規劃頁的題號都可以直接點）。
  3. 先在 IDLE 寫好、用範例測過。
  4. 按題目頁的「解題」，語言選 Python，把整個程式貼上，送出。
  5. 看結果：AC 就完成；不是 AC 就點進去看是哪一筆測資錯、錯誤訊息是什麼。
📌 第一題就從這裡開始

ZeroJudge a001 哈囉：讀入一個字串，印出 hello, 字串。注意逗號後面有一個空白——這就是「輸出格式要一字不差」的第一次練習。

✏️ 識讀練習：先自己追蹤，再按「顯示解答」

  1. 題目要求：讀入兩個整數（各一行），輸出兩數相加的結果。下面這個程式送上 Judge 會得到什麼結果？為什麼？ 
    x = int(input("x="))
y = int(input("y="))
print("x+y =", x + y)
    ▶ 顯示解答

    執行結果：

    x=y=x+y = 10

    會是 WA。兩個 input() 的提示文字和 "x+y =" 都會被印出來，跟答案只有一個數字不一樣。改成 x = int(input())、print(x + y)。

  2. 題目要求：一行讀入 n 個整數，由小到大輸出，用一個空白隔開。這個程式哪裡會錯？ 
    a = list(map(int, input().split()))
a.sort()
print(a)
    ▶ 顯示解答

    執行結果：

    [1, 2, 5, 9]

    印出了中括號和逗號，會被判 WA。改成 print(*a)。

  3. 題目要求：輸入 n 個成績，輸出平均（保證整除）。範例輸入 80 90 100，範例輸出 90。這個程式會印出什麼？ 
    a = list(map(int, input().split()))
print(sum(a) / len(a))
    ▶ 顯示解答

    執行結果：

    90.0

    印出 90.0，多了 .0，WA。題目保證整除時用 //。

  4. 題目的輸入是「第一行一個整數 n，第二行 n 個整數」，要輸出 n 個整數的總和。範例輸入第一行是 3、第二行是 5 2 9。下面這個程式會印出什麼？ 
    a = list(map(int, input().split()))
print(sum(a))
    ▶ 顯示解答

    執行結果：

    3

    這個程式想算總和，卻只印出 3：a = list(map(int, input().split())) 只讀了第一行，把 n 當成資料，第二行根本沒讀到。要先 n = int(input())，再讀第二行。單元 4 附的「多行輸入」會整理所有常見格式。
