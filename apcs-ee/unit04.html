條件判斷與迴圈

選擇結構、重複結構，以及初級最愛考的「程式追蹤」

🎯 學習目標

  • 會用 if／elif／else 寫出單向、雙向、多向的條件判斷
  • 會用 for、while 寫迴圈，並掌握 break／continue
  • 能處理巢狀迴圈，並在腦中「追蹤」程式的執行過程
  • 看得懂 if n:、while k: 這種用真假值當條件的寫法，會用字串乘法印圖形

01條件判斷：if / elif / else

python 
score = 78
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "D"
print(grade)   # C

elif 是「上面條件不成立，再檢查這個」，是由上往下、只會走進第一個成立的分支，走進去之後其他分支就都不看了。條件可以互相包在裡面，叫做巢狀判斷：

python 
age = 17
has_ticket = True
if age >= 18:
    print("可以進場")
else:
    if has_ticket:
        print("未成年但有票，可由家長陪同進場")
    else:
        print("不能進場")
⚠ elif 陷阱：多個 if 各自獨立，不會互相排除

如果把上面 elif 全部改成各自獨立的 if，每一行都會被檢查一次，可能同時符合好幾個條件、結果被後面的覆蓋掉，這是程式識讀常出的陷阱：看清楚是 elif 還是獨立的 if。

條件裡放的不是比較式：0 和空字串是「假」

if、while 後面不一定要寫比較式，也可以直接放一個數字或字串。規則是：0、空字串 ''、空串列 [] 是假，其他都是真。

if n:、while k: 
n = 0
if n:
    print('n 不是 0')
else:
    print('n 是 0')          # 會走這裡

name = ''
if not name:
    print('沒有名字')        # 空字串是假，not 之後變成真

k = 3
while k:                     # k 變成 0 時停下來
    print(k, end=' ')
    k -= 1
print()
▼ 執行結果 n 是 0 沒有名字 3 2 1
⚠ 識讀陷阱：if x: 不是 if x == 1:

if x: 的意思是「x 不是 0」，所以 x 是 5、-1 都會進去。巢狀 if 裡混著這種寫法時（官方識讀範例第 10 題），先把每個條件換成「是不是 0」再追蹤。

🟥 跑出紅字了？先看最後一行

寫 if 最常遇到的是 IndentationError（下一行沒縮排）和 SyntaxError（少了冒號、用了全形符號）。紅字只要看最後一行的錯誤種類，再看上一行寫的 line 幾。常見錯誤訊息整理在 單元 9 §04 看懂錯誤訊息，第一次出錯就可以先去對照。

02重複結構：for 與 while

for 通常搭配 range()，用在「知道要跑幾次」的情況；while 用在「不知道要跑幾次，只知道什麼時候該停」的情況。

python 
# for：range(start, stop, step)，不包含 stop
for i in range(1, 6):
    print(i, end=" ")        # 1 2 3 4 5
print()
for i in range(10, 0, -2):
    print(i, end=" ")        # 10 8 6 4 2
print()

# while：條件成立就一直跑
n = 1
total = 0
while n <= 100:
    total += n
    n += 1
print(total)                  # 5050

break 與 continue

下面兩個程式只差一個字：遇到 3 的倍數時，一個用 continue、一個用 break。按下面的分頁切換，看看兩者跑出來有什麼不一樣。

continue.py 
for i in range(1, 11):
    if i % 3 == 0:
        continue      # 3 的倍數：跳過這一輪剩下的程式，直接換下一個 i
    print(i, end=" ")
print()
▼ 執行結果 1 2 4 5 7 8 10
ii % 3 == 0？結果
1否印出 1
2否印出 2
3是continue：跳過，不印
4否印出 4
5否印出 5
6是continue：跳過，不印
7否印出 7
8否印出 8
9是continue：跳過，不印
10否印出 10

遇到 3、6、9 只是跳過那一輪，迴圈繼續跑到 10，印出 1 2 4 5 7 8 10。

break.py 
for i in range(1, 11):
    if i % 3 == 0:
        break         # 3 的倍數：整個迴圈直接結束
    print(i, end=" ")
print()
▼ 執行結果 1 2
ii % 3 == 0？結果
1否印出 1
2否印出 2
3是break：迴圈結束
4～10—不會執行，迴圈已經結束了

遇到 3 就整個迴圈結束，後面的 4～10 都不會跑，只印出 1 2。

🔎 break vs continue，一次記住

break：整個迴圈直接結束，後面的迴圈不再跑。continue：只跳過這一輪剩下的程式碼，迴圈繼續跑下一輪。兩個都只作用在最靠近它的那一層迴圈。

03巢狀迴圈

迴圈裡面還有迴圈，外層跑一次，內層就整個跑完一輪。常用來處理「表格」「座標」「兩兩配對」這類題目：

python 
for i in range(1, 4):        # 外層跑 3 次：1, 2, 3
    for j in range(1, 4):    # 內層每次都跑 3 次：1, 2, 3
        print(f"({i},{j})", end=" ")
    print()   # 每跑完一次外層，換行

# (1,1) (1,2) (1,3)
# (2,1) (2,2) (2,3)
# (3,1) (3,2) (3,3)

動畫：一步一步看巢狀迴圈怎麼跑

按「下一步」，每按一次執行一行。注意看：i 停在原地等 j 跑完一整圈，然後才換下一個 i。

💡 追蹤巢狀迴圈的技巧

「外層跑幾次」×「內層跑幾次」＝ 內層程式碼總共執行的次數。上面外層 3 次、內層 3 次，print(f"({i},{j})"...) 就會執行 3×3 = 9 次。這是效能分析題常用的計算方式。

用字串乘法印圖形

單元 2 學過 '*' * 3 是 '***'。印三角形這類圖形時，外層迴圈決定「第幾列」，每一列要印幾個符號，用字串乘法算出來就好，不一定要再寫一層迴圈：

靠左與靠右的三角形 
n = 4
for i in range(1, n + 1):
    print('*' * i)

for i in range(1, n + 1):
    print(' ' * (n - i) + '*' * i)   # 前面先補 n-i 個空白，變成靠右
▼ 執行結果 * ** *** **** * ** *** ****
🔎 識讀題怎麼追圖形

先算出每一列的「空白幾個、符號幾個」，列成表：i = 1 時 3 個空白 1 顆星、i = 2 時 2 個空白 2 顆星……再畫出來。官方識讀範例第 5 題就是印星號圖形的除錯題。

✏️ 課堂練習

  1. 寫程式印出 1 到 100 之間所有 3 的倍數。
  2. 追蹤下面程式，寫出印出的內容：
    total = 0
    for i in range(1, 10):
        if i % 3 == 0: continue
        if i >= 8: break
        total += i
    print(total)
  3. 用巢狀迴圈印出九九乘法表（1×1 到 9×9）。
  4. 讀入 n，印出 n 列的倒三角形（n = 3 時第一列 3 顆星，最後一列 1 顆星）。
  5. 追蹤：x, c = 6, 0，接著 while x: 迴圈裡做 x -= 2、c += 1，最後 print(c) 印出什麼？如果 x 一開始是 5 會怎樣？
▶ 顯示解答
第 1 題參考解 
for i in range(1, 101):
    if i % 3 == 0:
        print(i, end=" ")

第 2 題：i 從 1 跑到 9；i=3、6 被 continue 跳過不加；i=8 時先判斷 i>=8 為真，break 直接結束——所以只加了 1+2+4+5+7 = 19，答案是 19。

第 3 題參考解 
for i in range(1, 10):
    for j in range(1, 10):
        print(f"{i}x{j}={i*j}", end="\t")
    print()
第 4 題參考解 
n = int(input())
for i in range(n, 0, -1):
    print('*' * i)
▼ 輸入（測資） 3 ▼ 執行結果 *** ** *

第 5 題：x 依序是 6 → 4 → 2 → 0，跑了 3 次，印出 3。如果一開始是 5：5 → 3 → 1 → -1 → -3……永遠不會剛好等於 0，while x: 一直成立，變成無窮迴圈。
