第 1 次課前測

你們高一學過 Python，這份前測是看看還記得多少。不算成績，老師會依照全班的結果，決定第 1 次課哪些地方快速帶過、哪些地方要多講。

📋前測怎麼進行

部分時間內容怎麼作答
A　實作35 分鐘ZeroJudge 基本 6 題＋挑戰 2 題，由易到難在 IDLE 寫好、用範例測過，再上 ZeroJudge 送出（語言選 Python）
B　識讀15 分鐘基本 8 題＋挑戰 3 題，追蹤程式印出什麼用 Google 表單作答；用紙筆追蹤，不能執行程式
📌 規則

前測時不看教學網站、不查資料、不問同學，寫不出來就跳下一題。結果只用來調整上課進度，老師會記錄下來當作之後輔導的參考，不影響任何成績。

A實作：ZeroJudge 基本 6 題＋挑戰 2 題（35 分鐘）

依序寫，能寫幾題就寫幾題，基本題寫完再挑戰。input() 括號裡不要放提示文字，輸出格式要跟範例一模一樣（見 單元 2 附）。

題目（按下去開啟 ZeroJudge）會用到
基本a002簡易加法一行讀兩個整數
基本d050妳那裡現在幾點了？運算、%
基本a003兩光法師占卜術運算＋多重判斷
基本d498我不說髒話迴圈
基本a038數字翻轉字串、開頭的 0
基本c299連號或不連號串列、排序（APCS 第 1 題）
挑戰e357遞迴函數練習照題目給的遞迴式寫函式
挑戰c00210696 - f91遞迴裡再呼叫遞迴、讀到 0 為止
💡 寫完了？

挑戰的兩題是遞迴，高一可能沒學過，寫不出來沒關係，不影響第 1 次課的進度安排。全部都寫完的同學舉手，老師會請你幫忙看看旁邊同學卡在哪裡。

B識讀：接下來 15 分鐘

識讀前測用 Google 表單作答，共 11 題單選（基本 8 題＋挑戰 3 題），限時 15 分鐘。

📝 開啟識讀前測（Google 表單）

📌 作答規則

① 只能開這個表單，不能開其他網頁、不能上網查資料。② 不能用 IDLE 或任何軟體執行程式，請用紙筆追蹤，可以在計算紙上畫追蹤表。③ 不能問同學、不能用手機。④ 15 分鐘時間到就提交，寫不出來的題目可以空著。⑤ 第 9～11 題是挑戰題，用到函式和遞迴，寫不出來沒關係。

👀 老師模式：題目內容（和 Google 表單相同）

網址有加老師密鑰才看得到這一區。紙本備用：📄 識讀前測紙本 PDF

  1. 下面的程式印出什麼？

    print(17 // 5, 17 % 5)

    (A) 3 2　(B) 3.4 2　(C) 3 3　(D) 2 3

  2. 下面的程式印出什麼？

    print(-7 // 2, -7 % 2)

    (A) -3 -1　(B) -4 1　(C) -3 1　(D) -4 -1

  3. 下面的程式印出什麼？

    x = 0 or 5
y = 3 and 0
print(x, y)

    (A) 5 0　(B) True False　(C) 0 3　(D) 1 0

  4. 下面的程式印出什麼？

    c = 0
for i in range(2, 20, 3):
    c += 1
print(c)

    (A) 5　(B) 6　(C) 7　(D) 18

  5. 下面的程式印出什麼？

    t = 0
for i in range(4):
    for j in range(i):
        t += 1
print(t)

    (A) 4　(B) 10　(C) 6　(D) 16

  6. 下面的程式印出什麼？

    s = "APCS2027"
print(s[2:5], s[-1])

    (A) PCS 7　(B) CS20 7　(C) CS2 A　(D) CS2 7

  7. 下面的程式印出什麼？

    a = [1, 2, 3]
b = a
b.append(4)
print(len(a), len(b))

    (A) 3 4　(B) 3 3　(C) 4 4　(D) 執行錯誤

  8. 下面的程式印出什麼？

    n = 2027
s = 0
while n > 0:
    s += n % 10
    n //= 10
print(s)

    (A) 7　(B) 11　(C) 2027　(D) 0

挑戰題（第 9～11 題，寫不出來沒關係）

這三題用到函式和遞迴，高一可能沒學過，會的就寫，不會就空著。挑戰題不影響第 1 次課的進度安排。

  1. 下面的程式印出什麼？

    def f(a, n):
    a.append(n)
    n += 1
    return n

x = [1]
k = 5
k2 = f(x, k)
print(len(x), k, k2)

    (A) 2 6 6　(B) 1 5 6　(C) 2 5 6　(D) 2 5 5

  2. 下面的程式印出什麼？

    def f(n):
    if n <= 1:
        return 1
    return n + f(n - 2)

print(f(7))

    (A) 16　(B) 28　(C) 15　(D) 13

  3. 下面的程式印出什麼？

    def p(n):
    if n == 0:
        return
    p(n - 1)
    print(n, end=" ")
    p(n - 1)

p(3)

    (A) 3 2 1　(B) 1 2 3　(C) 3 2 1 1 2 3　(D) 1 2 1 3 1 2 1

➜前測之後

老師會依照全班的結果調整第 1 次課：大部分同學都會的部分只挑重點講，把時間留給 ZeroJudge 實作和檢討；卡住的地方再回頭講清楚。不管前測寫得如何，第 1～4 次課的內容都會用到，教學網站上每個單元都可以回去複習。
