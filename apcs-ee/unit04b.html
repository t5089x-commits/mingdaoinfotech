輸入技巧與常用函式：split()／map()／多行輸入

APCS 實作題最常見的輸入方式，加上課程中會一直用到的內建函式，這裡一次補齊

🎯 學習目標

  • 知道 APCS 程式實作最常見的輸入格式：「一行裡有好幾個數字，用空白隔開」
  • 會用 split() 把一行文字切開，並理解切開後還是字串
  • 會用 map(int, ...) 批次轉型態，寫出 list(map(int, input().split())) 這個最常見的一行寫法
  • 看得懂串列生成式 [int(x) for x in input().split()]，知道它跟 list(map(...)) 一樣
  • 會讀 APCS 中級最常見的多行輸入：先讀 n，再讀 n 行；以及 n×m 的表格
  • 認識課程中會一直用到的內建函式對照表：sorted()、sum()、zip()、enumerate() 等

01APCS 最常見的輸入格式

APCS 實作題最常見的輸入方式，是「一行裡有好幾個數字，用空白隔開」，例如輸入 3 5 7 9。這種情況要用 split() 和 map() 這組技巧——後面每一題只要牽涉到「一次讀好幾個數字」，幾乎都會用到：

split()：把一行文字依空白切開 
line = input()          # 假設使用者輸入：3 5 7 9
parts = line.split()      # 依空白切開 → ['3', '5', '7', '9']
print(parts)               # 注意：這些還是「字串」，不是數字！
print(parts[0] + parts[1])  # '3' + '5' → '35'（字串相加是接在一起，不是數學運算）
⚠ 切開之後，還是字串！

split() 回傳的 list 裡，每一個元素都還是字串，不是數字。如果直接拿去做加法，Python 不會報錯，而是會把字串「接在一起」，例如 '3' + '5' 的結果是 '35'，不是 8。這是初學者很容易忽略、但又不會報錯的陷阱，跟單元 2 學過的 input() 一樣，記得要先轉型。

02map() 與串列生成式：把切開的每一段文字都轉成數字

map(f, x) 會把函式 f 套用到 x 裡的每一個元素上，回傳一個新的結果。搭配 int 一起用，就能把一整排字串「一次」轉成數字：

map(int, ...)：批次轉換型態 
line = "3 5 7 9"
parts = line.split()          # ['3', '5', '7', '9']（字串）
nums = list(map(int, parts))    # 把每個字串都轉成 int → [3, 5, 7, 9]
print(nums)
print(sum(nums))                  # 24，這次是真的數學運算

# APCS 最常見的寫法，直接一行搞定：
nums = list(map(int, input().split()))
print(nums)
📌 這一行程式碼，課程中會一直看到

nums = list(map(int, input().split())) 這行等於做了三件事：input() 讀一行文字 → .split() 依空白切開 → map(int, ...) 把每一段都轉成整數，最後用 list(...) 包成一個 list。這個「一行讀多個數字」的寫法值得直接背起來。

另一種寫法：串列生成式

很多程式（包括識讀題）會把上面那行寫成 [int(x) for x in input().split()]。這叫串列生成式：[運算式 for 變數 in 一串東西]，意思是「把一串東西裡的每一個拿出來，套進運算式，收集成一個新的串列」。

串列生成式 
print([x * x for x in range(1, 6)])          # [1, 4, 9, 16, 25]
print([int(x) for x in "3 5 7".split()])     # [3, 5, 7]
print([x for x in range(10) if x % 3 == 0])  # [0, 3, 6, 9]（後面加 if，只留下符合的）
print([0 for _ in range(4)])                 # [0, 0, 0, 0]
▼ 執行結果 [1, 4, 9, 16, 25] [3, 5, 7] [0, 3, 6, 9] [0, 0, 0, 0]
用 map()用串列生成式
list(map(int, input().split()))[int(x) for x in input().split()]
list(map(float, input().split()))[float(x) for x in input().split()]

兩種寫法結果完全一樣，挑一種習慣就好。後面二維表格的讀法 [list(map(int, input().split())) for _ in range(n)] 也是串列生成式：每一輪讀一行，收集成 n 列。

⚠ 識讀陷阱一：生成式裡的變數不會改到外面

中括號裡的 x 只在生成式裡面有效。外面如果也有一個 x，跑完生成式之後還是原來的值。

外面的 x 沒有被改掉 
x = 'hi'
a = [x for x in range(3)]
print(x, a)          # hi [0, 1, 2]
▼ 執行結果 hi [0, 1, 2]
⚠ 識讀陷阱二：左右的個數要一樣

a, b = [int(x) for x in input().split()] 左邊有 2 個變數，右邊的串列就必須剛好 2 個元素；輸入 3 個數會出錯。

輸入 3 個數，卻只用 2 個變數接 
a, b = [int(x) for x in "100 45 25".split()]
▼ 執行結果 （沒有輸出） Traceback (most recent call last): File "程式.py", line 1, in <module> ValueError: too many values to unpack (expected 2)

03split(sep)：依指定符號切開

split() 不寫參數預設依「空白」切開；如果資料是用逗號或其他符號分隔（例如處理 CSV 這類資料），可以直接指定分隔符號：

依指定符號切開 
line = "小明,88,92,76"
parts = line.split(",")     # 依逗號切開 → ['小明', '88', '92', '76']
name = parts[0]
scores = list(map(int, parts[1:]))   # 第 0 個是名字，其餘轉成數字
print(name, scores, sum(scores))

04多行輸入：APCS 中級題目的標準格式

前面學的是「一行裡有好幾個數字」。但 APCS 中級的題目，幾乎都是多行輸入：第一行先告訴你有幾筆資料，後面再一行一行給。官方中級範例的三題全部都是這種格式。

格式 ①：第一行 n，接著 n 行、每行一個數

一行一個數 
n = int(input())          # 第一行：有幾筆
nums = []
for _ in range(n):        # 再讀 n 行
    nums.append(int(input()))
print(nums, sum(nums))
▼ 輸入（測資） 3 10 20 30 ▼ 執行結果 [10, 20, 30] 60

for _ in range(n) 裡的 _ 是「我不會用到這個變數」的意思，只是要重複 n 次而已。

格式 ②：第一行 n，第二行 n 個數

第二行一次給完 
n = int(input())
a = list(map(int, input().split()))
print(n, a)
▼ 輸入（測資） 4 5 2 9 1 ▼ 執行結果 4 [5, 2, 9, 1]

格式 ③：n 行，每行有好幾個數（例如每人的兩個成績）

每行固定幾個數 
n = int(input())
for _ in range(n):
    a, b = map(int, input().split())   # 每行固定兩個數，直接拆給 a、b
    print(a + b)
▼ 輸入（測資） 3 1 2 10 20 7 8 ▼ 執行結果 3 30 15

如果之後還要用到這些資料，就先存起來：

存起來之後再處理 
n = int(input())
data = []
for _ in range(n):
    t, s = map(int, input().split())
    data.append([t, s])        # 存成「串列裡面裝串列」
print(data)
▼ 輸入（測資） 3 3 89 5 -1 10 90 ▼ 執行結果 [[3, 89], [5, -1], [10, 90]]

格式 ④：第一行兩個數 n、m，接著 n 行、每行 m 個數（二維）

這是官方中級範例「特殊位置」的格式，也是二維串列題最常見的寫法：

讀入一個 n×m 的表格 
n, m = map(int, input().split())
g = []
for _ in range(n):
    g.append(list(map(int, input().split())))
print(g)
print(g[1][2])      # 第 1 列第 2 行（從 0 開始數）
▼ 輸入（測資） 2 3 1 3 4 1 1 4 ▼ 執行結果 [[1, 3, 4], [1, 1, 4]] 4

熟了之後可以寫成一行：g = [list(map(int, input().split())) for _ in range(n)]。二維串列的用法在單元 6 附會完整介紹。

格式 ⑤：n 行，每行一個字串

讀入字串 
n = int(input())
codes = [input() for _ in range(n)]
print(codes)
print(codes[0][:3])    # 第一筆的前 3 個字
▼ 輸入（測資） 2 0309876543216 4711234560012 ▼ 執行結果 ['0309876543216', '4711234560012'] 030
⚠ 看起來是數字，不一定要轉成 int

像條碼、學號、電話這種「開頭可能是 0」的資料，轉成 int 之後開頭的 0 就不見了（int('0309') 變成 309）。題目要你看「第幾位是什麼」的時候，要保持字串。

格式對照表

輸入長這樣寫法
5（一個數）n = int(input())
3 5（固定兩個數）a, b = map(int, input().split())
3 1 4 1 5（一串數）a = list(map(int, input().split()))
n 行，每行一個數for _ in range(n): x = int(input())
n 行，每行一串數（表格）g = [list(map(int, input().split())) for _ in range(n)]
n 行，每行一個字串s = [input() for _ in range(n)]
🔎 讀錯格式會怎樣？

一行有兩個數，卻寫 int(input())，會出現 ValueError: invalid literal for int() with base 10: '3 5'，意思是「'3 5' 不能轉成整數」。看到這個錯誤，先回頭檢查輸入格式。

✏️ 識讀練習：先自己追蹤，再按「顯示解答」

  1. 輸入格式：第一行 n，接下來 n 行各有一個學生的「座號 分數」。請寫出讀入資料、印出最高分那位學生座號的程式。（範例輸入如下）
    ▶ 顯示解答

    參考寫法：

    n = int(input())
best_id, best = 0, -1
for _ in range(n):
    sid, score = map(int, input().split())
    if score > best:
        best_id, best = sid, score
print(best_id)
    範例輸入 3 / 1 80 / 2 95 / 3 70（每個斜線代表換行）會印出 2。

  2. 下面的輸入要怎麼讀？
    2 3
    1 2 3
    4 5 6
    讀完之後，g[1][0] 是多少？ 
    n, m = map(int, input().split())

    ▶ 顯示解答

    第一行讀 n、m，再讀 n 行。g[1] 是第二列 [4, 5, 6]，g[1][0] 是 4。

05課程中會一直用到的內建函式對照表

下面這些函式，後面每一個單元幾乎都會用到——先在這裡認識一次，之後看到就不會陌生：

函式用途範例
len(x)取得長度（字串、list 都可以用）len([1,2,3]) → 3
x.append(v)在 list 尾端加入一個元素a=[1,2]; a.append(3) → [1,2,3]
x.pop()從 list 尾端取出並刪除一個元素a=[1,2,3]; a.pop() → 3
deque.popleft()從佇列前端取出並刪除（中高級補充，要先 from collections import deque）q=deque([1,2,3]); q.popleft() → 1
"..".split()把字串依空白（或指定符號）切成 list"3 5 7".split() → ['3','5','7']
"-".join(x)把 list 的元素接成一個字串，中間插入指定符號"-".join(['a','b']) → 'a-b'
map(f, x)對 x 裡的每個元素都套用函式 flist(map(int,['1','2'])) → [1, 2]
set(x)把 list 轉成集合（自動去除重複）set([1,1,2]) → {1, 2}
list(x)把其他型態轉成 listlist(range(3)) → [0, 1, 2]
sorted(x)回傳排序好的「新」list（原本的不會被改變）sorted([3,1,2]) → [1, 2, 3]
x.sort()直接把 list 原地排序（沒有回傳值）a=[3,1,2]; a.sort() → a 變 [1,2,3]
sum(x)加總 list（或其他可迭代物件）裡所有的值sum([1,2,3]) → 6
zip(a, b)把兩個 list 一一配對起來list(zip([1,2],['a','b'])) → [(1,'a'), (2,'b')]
enumerate(x)走訪的同時取得「索引」和「值」for i, v in enumerate(['a','b']):
round(x, n)取到小數點第 n 位（剛好 .5 時不一定進位，見單元 2）round(3.14159, 2) → 3.14
"x".isalpha()判斷字串是否全部是英文字母"ABC".isalpha() → True
🔎 sorted(x) 跟 x.sort() 差在哪？

sorted(x) 是內建函式，會回傳一份「排序好的新 list」，原本的 x 不會被改變；x.sort() 是 list 的方法，直接把 x 原地排序、沒有回傳值。如果題目要求「保留原本順序、另外輸出排序結果」，就要用 sorted()；如果只是要把資料排好備用，用 x.sort() 更省記憶體。

🔎 排序也可以指定規則：key= 與 reverse=True

reverse=True 是由大到小；key=len 是「依長度排序」：每個元素先丟進 len() 算出長度，再依長度排。sorted() 和 .sort() 都可以加這兩個參數。

key= 與 reverse=True 
words = ['pear', 'fig', 'banana']
print(sorted(words))                     # ['banana', 'fig', 'pear']（字典順序）
print(sorted(words, key=len))            # ['fig', 'pear', 'banana']（依長度）
print(sorted([3, 1, 2], reverse=True))   # [3, 2, 1]
▼ 執行結果 ['banana', 'fig', 'pear'] ['fig', 'pear', 'banana'] [3, 2, 1]

✏️ 課堂練習

  1. 讀入一行以空白分隔的整數（例如 12 45 7 89 23），輸出這些數字的總和與最大值。
  2. 讀入一行以逗號分隔的姓名（例如 小明,小華,小美），輸出總共有幾個名字，並依字母排序後印出（原本的順序不要被改變）。
  3. 追蹤思考：如果忘記寫 map(int, ...)，直接對 input().split() 的結果做 sum()，會發生什麼事？為什麼？
▶ 顯示解答
第 1 題參考解 
nums = list(map(int, input().split()))
print("總和：", sum(nums))
print("最大值：", max(nums))
第 2 題參考解 
names = input().split(",")
print("共有", len(names), "個名字")
print(sorted(names))     # 用 sorted()，names 原本的順序不會被改變
print(names)               # 印出來確認：names 本身還是原來的順序

第 3 題：會直接出錯：sum(['3','5']) 會得到 TypeError（sum() 預設從整數 0 開始加，0 + '3' 型態不合會報錯）。要先用 map(int, ...) 把每個字串都轉成數字，sum() 才能正確加總。
