C++ ⇄ Python 對照表

你們現在每週上 C++，週六寫 Python。兩種語言長得很像，但有幾個地方規則剛好相反：寫程式會出錯，識讀題會答錯。這一頁把容易混淆的地方放在一起，每個例子的兩邊程式都實際執行過。

01最容易被 C++ 習慣害到的 10 件事

C++Python寫錯會怎樣
17 / 2 是 37 / 2 是 3.5；要整數用 7 // 2輸出多了小數，Judge 判 WA
2-7 / 2 是 -3、-7 % 2 是 -1-7 // 2 是 -4、-7 % 2 是 1識讀題直接答錯
3&&　||　!and　or　not，而且回傳的是其中一邊的值語法錯誤；識讀題答錯
41 <= x <= 9 永遠成立（先算出 0 或 1，再拿去跟 9 比）1 <= x <= 9 就是數學的意思判斷結果完全不同
5i++、i--沒有這種寫法，要寫 i += 1語法錯誤
6{ } 和 ; 決定範圍縮排和冒號 : 決定範圍IndentationError，或程式跑進錯的區塊
7else ifelif語法錯誤
8vector b = a; 是複製一份b = a 是同一個串列，改 b 等於改 a識讀題答錯
9for 迴圈裡改 i 會影響下一輪；迴圈結束後 i 是 n改 i 不影響下一輪；結束後 i 是 n-1識讀題答錯
10char 可以直接加減：'A' + 1、c - '0'字元就是字串，不能加數字：用 chr(ord(c) + 1)、int(c)TypeError
💡 怎麼用這一頁

寫 Python 卡住、或識讀題的答案跟你想的不一樣時，先想想「是不是用 C++ 的規則在想」。下面各節依主題整理，左邊 C++、右邊 Python。

02輸入與輸出

要做的事C++Python
讀一個整數cin >> n;n = int(input())
一行讀兩個整數cin >> a >> b;a, b = map(int, input().split())
讀一整行的數字迴圈 cin >> a[i];a = list(map(int, input().split()))
印出、空白隔開cout << a << " " << b << endl;print(a, b)
不換行不寫 endlprint(x, end="")
小數點後 2 位printf("%.2f", x);print(f"{x:.2f}")
⚠ 最大的差別：cin 不管換行，input() 一次讀一整行

C++ 的 cin >> 會自動跳過空白和換行，數字放在同一行或分好幾行都讀得到。Python 的 input() 每呼叫一次就讀一整行，所以一定要照題目的輸入格式讀：同一行的用 split() 切開，不同行的就呼叫好幾次 input()。

C++ 
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    int s = 0;
    for (int x : a) s += x;
    cout << s << endl;
}
▼ 輸入（測資） 4 3 1 4 1 ▼ 執行結果 9
Python 
n = int(input())
a = list(map(int, input().split()))
print(sum(a))
▼ 輸入（測資） 4 3 1 4 1 ▼ 執行結果 9

03除法、餘數與大數字（識讀重點）

C++（int）Python
7 除以 27 / 2 → 37 / 2 → 3.5，7 // 2 → 3
-7 除以 2 的商-7 / 2 → -3（往 0 靠）-7 // 2 → -4（往下取整）
-7 除以 2 的餘數-7 % 2 → -1（跟被除數同號）-7 % 2 → 1（跟除數同號）
次方pow(2, 10)（回傳小數）2 ** 10 → 1024
整數上限int 約 21 億，超過會溢位沒有上限
C++ 
#include <bits/stdc++.h>
using namespace std;
int main() {
    cout << 7 / 2 << " " << 7.0 / 2 << endl;
    cout << -7 / 2 << " " << -7 % 2 << endl;
    cout << -13 / 5 << " " << -13 % 5 << endl;
}
▼ 執行結果 3 3.5 -3 -1 -2 -3
Python 
print(7 // 2, 7 / 2)
print(-7 // 2, -7 % 2)
print(-13 // 5, -13 % 5)
▼ 執行結果 3 3.5 -4 1 -3 2
🔎 識讀題怎麼辦

Python 的規則是：// 一律往下取整（往數線左邊），% 再用 a == (a // b) * b + a % b 算回來。除數是正數時，餘數一定落在 0～b-1。詳細說明在 單元 3 §01。

Python 的整數沒有上限 
print(2 ** 100)   # C++ 的 int、long long 都裝不下，Python 照算
▼ 執行結果 1267650600228229401496703205376

04邏輯運算與條件判斷

C++Python
且／或／非&&　||　!and　or　not
真／假true／false（印出來是 1／0）True／False（大寫開頭）
否則如果else if (...) { }elif ...:
三元運算c ? a : ba if c else b
連續比較1 <= x <= 9 是錯的寫法1 <= x <= 9 正確
and／or 的結果一定是 true／false回傳其中一邊的值：3 and 5 是 5
C++ 
#include <bits/stdc++.h>
using namespace std;
int main() {
    int x = 20;
    cout << (1 <= x && x <= 9) << " ";
    cout << (1 <= x <= 9) << endl;   // 先算 1<=x 得 1，再算 1<=9
    cout << (3 && 5) << " " << (0 || 7) << endl;
}
▼ 執行結果 0 1 1 1
Python 
x = 20
print(1 <= x <= 9)
print(3 and 5, 0 or 7)
▼ 執行結果 False 5 7
⚠ 識讀陷阱

Python 的 and／or 不一定回傳 True／False，而是回傳「決定結果的那一邊」的值。看到 print(0 or 'A') 這種題目，答案是 A，不是 True。規則見 單元 3 §02。

05迴圈

C++Python
跑 n 次for (int i = 0; i < n; i++)for i in range(n):
從 a 到 b-1for (int i = a; i < b; i++)for i in range(a, b):
每次減 2for (int i = 10; i > 0; i -= 2)for i in range(10, 0, -2):
走訪每個元素for (int x : a)for x in a:
do-while有沒有，用 while True: 加 break
⚠ 兩個識讀陷阱

① C++ 在 for 裡改 i，下一輪會接著改過的值跑；Python 的 for i in range(...) 每一輪都重新從 range 拿下一個值，裡面改 i 沒用。② 迴圈跑完之後，C++ 的 i 停在 n（條件不成立才離開），Python 的 i 停在最後一個值 n-1。

C++ 
#include <bits/stdc++.h>
using namespace std;
int main() {
    for (int i = 0; i < 5; i++) {
        cout << i << " ";
        i += 1;
    }
    cout << endl;
    int i;
    for (i = 0; i < 5; i++) { }
    cout << i << endl;
}
▼ 執行結果 0 2 4 5
Python 
for i in range(5):
    print(i, end=" ")
    i += 1
print()
for i in range(5):
    pass
print(i)
▼ 執行結果 0 1 2 3 4 4

C++Python
n 個 0vector<int> a(n, 0);a = [0] * n

指定給另一個變數b = a; 複製一份b = a 是同一個；複製要 a[:]
C++ 
#include <bits/stdc++.h>
using namespace std;
int main() {
    vector<int> a = {1, 2, 3};
    vector<int> b = a;    // 複製一份
    b[0] = 99;
    cout << a[0] << " " << b[0] << endl;
}
▼ 執行結果 1 99
Python 
a = [1, 2, 3]
b = a                 # 同一個串列
b[0] = 99
print(a[0], b[0])
▼ 執行結果 99 99
⚠ 識讀陷阱

這是 C++ 同學最常栽的一題：Python 的 b = a 只是多一個名字指向同一個串列，改 b 就是改 a。函式傳串列進去也一樣，函式裡改元素會改到外面。見 單元 5 §05、單元 7 §03。

07字元與字串

C++Python
字元型態char c = 'A';沒有字元型態，'A' 就是長度 1 的字串
下一個字母char(c + 1)chr(ord(c) + 1)

數字 ↔ 字串to_string(n)、stoi(s)str(n)、int(s)
C++ 
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s = "APCS";
    s[0] = 'a';
    char c = 'A';
    cout << s << " " << s.substr(1, 2) << " ";
    cout << char(c + 2) << " " << ('7' - '0') + 1 << endl;
}
▼ 執行結果 aPCS PC C 8
Python 
s = "APCS"
s = 'a' + s[1:]
c = 'A'
print(s, s[1:3], chr(ord(c) + 2), int('7') + 1)
▼ 執行結果 aPCS PC C 8
⚠ 注意 substr 和切片

s.substr(1, 2) 是「從 1 開始拿 2 個字」；Python 的 s[1:3] 是「從 1 到 3、不含 3」，結果一樣是 2 個字，但第二個數字的意思不同。

08函式

C++Python
定義int f(int x) { return x * 2; }def f(x):　換行縮排　return x * 2
沒有回傳值void f()不寫 return，回傳的是 None
在函式裡改到外面的變數傳參考 int &x數字、字串改不到；串列的元素改得到
回傳兩個值pair、structreturn a, b
交換兩個變數swap(a, b);a, b = b, a
C++ 
#include <bits/stdc++.h>
using namespace std;
void sw(int &a, int &b) {
    int t = a; a = b; b = t;
}
int main() {
    int x = 1, y = 2;
    sw(x, y);
    cout << x << " " << y << endl;
}
▼ 執行結果 2 1
Python 
def sw(a, b):
    a, b = b, a      # 只換了函式裡的 a、b

x, y = 1, 2
sw(x, y)
print(x, y)          # 外面沒變
x, y = y, x          # 要換就直接在外面換
print(x, y)
▼ 執行結果 1 2 2 1

09那考 APCS 要用哪一種？

APCS 的程式識讀，我們報考的是 Python 題本，所以識讀一定要用 Python 的規則來想，上面標「識讀陷阱」的地方要特別小心。

程式實作雖然可以選語言，但這門課統一用 Python：範例、講解、ZeroJudge 練習和模擬考都用 Python 寫，考 APCS 實作也請用 Python 作答。C++ 留在專業課好好學，這一頁只是幫你分清楚兩邊的規則，不要混在一起用。
