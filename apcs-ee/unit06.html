字元與字串（String）

中級的另一半：文字處理與流程模擬

🎯 學習目標

  • 會用 s[i]、切片、for ch in s 處理字串，並知道字串不可變的特性
  • 會用 isupper()、isdigit() 判斷字元種類，用 int(c)、str(n) 在字元和數字之間轉換
  • 熟悉常用字串方法，能處理基本的文字處理題
  • 能組合迴圈＋字串，寫出「迴文判斷」等 APCS 常見題型
  • 會用字典（dict）統計每一種東西出現幾次，找出出現最多的
  • （補充）知道 ASCII 編碼與 ord()／chr()

01字串是「字元的序列」

APCS 中級範圍的「字元」，在 Python 裡就是長度 1 的字串：s[i] 拿出第 i 個字元，for ch in s 一個字元一個字元處理。字串的索引、切片規則和 list 完全一樣：

python 
s = "Mingdao"
print(s[0])       # 'M'
print(s[-1])       # 'o'
print(s[1:4])       # 'ing'
print(s[::-1])       # 'oadgniM'　（反轉）
print(len(s))         # 7

for ch in s:
    print(ch, end="-")   # M-i-n-g-d-a-o-
print()
⚠ 字串是「不可變」的（immutable）

跟 list 不一樣，字串不能直接改某一個字元：s[0] = 'X' 會直接 TypeError 報錯！要「修改」字串，只能建立一個新的字串去取代它，例如 s = 'X' + s[1:]。這是程式測試與除錯常考的觀念。

02字元判斷與轉換：中級最常用的寫法

拿到一個字元 c 之後，最常要做的兩件事是：判斷它是哪一種字元，以及把數字字元轉成真正的數字。

判斷字元的種類

寫法什麼時候是 True例子
c.isupper()大寫英文字母'A'.isupper() → True
c.islower()小寫英文字母'a'.islower() → True
c.isalpha()英文字母（大小寫都算）'Q'.isalpha() → True
c.isdigit()數字字元 0～9'7'.isdigit() → True
c == '1'剛好是某一個字元數 0/1 字串時最常用
c in 'aeiou'是這幾個字元的其中一個判斷母音
統計大寫、小寫、數字、其他 
s = "Mingdao2026!"
up = low = digit = other = 0
for c in s:
    if c.isupper():
        up += 1
    elif c.islower():
        low += 1
    elif c.isdigit():
        digit += 1
    else:
        other += 1
print(up, low, digit, other)
▼ 執行結果 1 6 4 1

大小寫轉換

upper()、lower() 
c = 'g'
print(c.upper(), 'G'.lower())
s = "aPcS"
t = ""
for c in s:                     # 大寫變小寫、小寫變大寫
    if c.isupper():
        t += c.lower()
    else:
        t += c.upper()
print(t)
▼ 執行結果 G g ApCs

數字字元 ↔ 數字：int(c) 與 str(n)

'7' 是字元，7 才是數字。要把每一位數字拿來計算，先用 int(c) 轉成數字；反過來要把數字接進字串，用 str(n)。

條碼每一位相加（2025 年 10 月中級「商品包裝地」的寫法） 
code = "4710018000102"
odd = even = 0
for i in range(12):            # 前 12 位
    d = int(code[i])           # 字元轉成數字
    if i % 2 == 0:             # 第 1、3、5…位（索引 0、2、4…）
        odd += d
    else:
        even += d
print(odd, even)
print("位數和：" + str(odd + even))   # 數字接進字串要先 str()
▼ 執行結果 14 8 位數和：22

數 0/1 字串裡有幾個 1

官方中級範例「字串解碼」會用到 
e = "10110"
cnt = 0
for c in e:
    if c == '1':
        cnt += 1
print(cnt, e.count('1'))      # 自己數，或用 count()
▼ 執行結果 3 3
⚠ 開頭是 0 的數字字串，不要整個轉成 int

int('0309') 會變成 309，開頭的 0 不見了，「第幾位是什麼」就對不上了。題目要看每一位時，保持字串，需要計算的那一位再 int(c)。

📌 對照 C 語言

C／C++ 要把數字字元轉成數字，常寫 c - '0'，那是利用 ASCII 編碼。Python 直接 int(c) 就好，ASCII 的原理放在本單元最後的補充。

03常用字串方法

方法作用範例
.upper() / .lower()轉大寫／小寫"Hi".upper() → "HI"
.strip()去掉頭尾空白（含換行）" hi ".strip() → "hi"
.split(sep)依分隔符切成 list"a,b,c".split(",") → ['a','b','c']
sep.join(list)把 list 用分隔符接成字串（split 的相反）"-".join(['a','b']) → "a-b"
.replace(a, b)把所有 a 換成 b"aabb".replace("a","x") → "xxbb"
.find(sub)回傳子字串第一次出現的索引，找不到回傳 -1"hello".find("l") → 2
.count(sub)計算子字串出現次數"banana".count("a") → 3
.isdigit() / .isalpha()是不是純數字／純英文字母"123".isdigit() → True

04常見題型：迴圈＋字串

算母音字母個數（不用內建方法，自己判斷）

python 
s = "hello world"
vowels = "aeiou"
count = 0
for ch in s:
    if ch in vowels:      # in 可以直接判斷字元在不在另一個字串裡
        count += 1
print(count)   # 3

判斷迴文（正著讀、反著讀一樣）

python 
def is_palindrome(s):
    n = len(s)
    for i in range(n // 2):
        if s[i] != s[n - 1 - i]:
            return False
    return True

print(is_palindrome("level"))    # True
print(is_palindrome("apple"))    # False
💡 更快的寫法

如果題目沒有限制不能用切片，其實一行 s == s[::-1] 就能判斷迴文（比較原字串和反轉後的字串是否相同）。但用迴圈手刻一次，能確保自己真的理解「頭尾往中間比對」這個邏輯，遇到變化題（例如「只看英文字母，忽略大小寫與空白」）才寫得出來。

字串組字（用迴圈一個字一個字組出新字串）

python 
s = "abcde"
result = ""
for ch in s:
    result += ch.upper() + "-"   # 逐字組合成新字串
print(result)   # A-B-C-D-E-
🔎 為什麼要練「自己刻」，不直接呼叫方法？

程式識讀考的是邏輯拆解能力，題目常常要求「不能用某個內建函式」，逼你用迴圈把邏輯自己想一遍。內建方法（如 .count()）平常寫程式當然可以直接用，但練習時建議兩種都會，遇到限制條件也不慌。

05字典（dict）：統計每一種出現幾次

「每一種東西各出現幾次」「出現最多的是哪一個」是中級很常見的問題，例如 2025 年 10 月中級第 3 題「商品包裝地」要統計每個產地的條碼數。用字典最直接：字典是一組一組的「鍵：值」，用鍵去查值。

字典的基本用法 
d = {}                 # 空字典
d['471'] = 2           # 新增：鍵 '471'，值 2
d['030'] = 1
print(d)
print(d['471'])        # 用鍵查值
print('471' in d, '999' in d)   # 鍵在不在字典裡
▼ 執行結果 {'471': 2, '030': 1} 2 True False

計數的標準寫法

d.get(鍵, 0) + 1 
words = ['471', '030', '471', '300', '471']
cnt = {}
for w in words:
    cnt[w] = cnt.get(w, 0) + 1     # 沒出現過就從 0 開始
print(cnt)
▼ 執行結果 {'471': 3, '030': 1, '300': 1}

cnt.get(w, 0) 的意思是「有這個鍵就拿它的值，沒有就當作 0」。如果直接寫 cnt[w] += 1，第一次遇到 w 時字典裡還沒有它，會出現 KeyError。

找出現最多的

max(d, key=d.get) 與 items() 
cnt = {'471': 3, '030': 1, '300': 1}
best = max(cnt, key=cnt.get)       # 依「值」比大小，回傳鍵
print(best, cnt[best])

for k, v in cnt.items():           # 同時拿到鍵和值
    print(k, v)
▼ 執行結果 471 3 471 3 030 1 300 1

items() 是什麼？

d.items() 會把字典拆成一組一組的（鍵, 值），讓 for 迴圈一次拿到兩個東西。for k, v in cnt.items(): 的意思是：每一輪拿出一組，鍵放進 k、值放進 v。

items() 拿出來的是什麼 
cnt = {'471': 3, '030': 1, '300': 1}
print(list(cnt.items()))     # 每一組都是 (鍵, 值)

for pair in cnt.items():     # 不拆開：pair 是一整組
    print(pair)

for k, v in cnt.items():     # 拆開：鍵給 k、值給 v
    print(k, "出現", v, "次")
▼ 執行結果 [('471', 3), ('030', 1), ('300', 1)] ('471', 3) ('030', 1) ('300', 1) 471 出現 3 次 030 出現 1 次 300 出現 1 次
寫法每一輪拿到什麼時候用
for k in d:只有鍵只需要鍵，值再用 d[k] 查
for k, v in d.items():鍵和值鍵和值都要用，最常見
for v in d.values():只有值只在乎數量，例如加總 sum(d.values())

for k, v in ... 這種「一次拆給兩個變數」的寫法，跟 a, b = 3, 5 是同一個道理：右邊有兩個東西，就分給左邊的兩個變數。

字串＋字典：統計字母

每個字母出現幾次 
s = input()
cnt = {}
for c in s:
    if c.isalpha():
        cnt[c] = cnt.get(c, 0) + 1
for k in sorted(cnt):              # 依字母順序印出
    print(k, cnt[k])
▼ 輸入（測資） banana ▼ 執行結果 a 3 b 1 n 2
💡 不用字典也可以嗎？

如果「種類」很少而且是固定的（例如只有 26 個小寫字母），也可以用串列 cnt = [0] * 26 搭配 ord(c) - ord('a') 當索引。但種類不固定時（產地、名字、條碼），字典最方便。

06補充：ASCII 與 ord()／chr()補充・點開閱讀

這一節是補充，平常寫中級題目用前面的 isupper()、int(c) 就夠了。電腦裡的每個字元都對應一個數字編碼，英文字母、數字、符號常用的是 ASCII 碼。Python 用 ord() 查字元對應的編碼，chr() 反過來把編碼變回字元：

python 
print(ord('A'))    # 65
print(ord('a'))    # 97
print(ord('0'))    # 48
print(chr(65))      # 'A'
print(chr(97))      # 'a'

# A~Z 是連續的 65~90，a~z 是連續的 97~122
c = 'D'
print(chr(ord(c) + 1))   # 'E'　←　字母往後移一位
💡 大小寫轉換的原理

大寫和小寫字母的 ASCII 碼剛好差 32（ord('a') - ord('A') == 32；Python 不能直接寫 'a' - 'A'，那是 C 的寫法，在 Python 會 TypeError）。所以 chr(ord(c) + 32) 可以把大寫字母 c 轉成小寫——雖然平常直接用 .upper()／.lower() 更方便，但看懂原理，遇到「自己刻轉換」的題目才不會卡住。

什麼時候真的需要 ord()？

官方中級範例和 2025 年 10 月中級真題都沒有用到。會用到的情況主要是兩種：字母轉成 0～25 的索引來計數，以及字母位移（單元 8 的凱薩密碼補充）。識讀也可能出現，例如吳邦一 125 題的 Q19、Q69。

字母轉成 0～25 的索引（吳邦一 125 題 Q69 的寫法） 
cnt = [0] * 26                 # 26 個小寫字母各一格
for c in "banana":
    cnt[ord(c) - ord('a')] += 1    # 'a'→0、'b'→1、…、'z'→25
print(cnt[:3], max(cnt))
▼ 執行結果 [3, 1, 0] 3

✏️ 課堂練習

  1. 輸入一個字串，統計裡面有幾個數字字元（可用 .isdigit()）。
  2. 不用 [::-1]，用迴圈把字串反轉後輸出。
  3. 輸入一段句子，計算裡面出現最多次的字元是哪一個、出現幾次。
▶ 顯示解答
第 2 題參考解 
s = "hello"
result = ""
for ch in s:
    result = ch + result   # 每次把新字元加在「前面」，就會自然反過來
print(result)   # olleh
第 3 題參考解 
s = "programming"
best_ch, best_n = "", 0
for ch in s:
    n = s.count(ch)
    if n > best_n:
        best_ch, best_n = ch, n
print(best_ch, best_n)   # r 2（r、g、m 都出現 2 次，最先遇到的是 r）
