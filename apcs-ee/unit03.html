運算子大全：算術・比較・邏輯・位元

APCS 初級範圍的運算子，這裡一次補齊；位元運算列為補充

  • 熟悉算術、比較、邏輯運算子與複合指定運算子

  • （補充）認識位元運算子：AND、OR、XOR、NOT、位移

01算術運算子

+ 加、- 減、* 乘、/ 除、% 餘數、// 整數除（商）、** 指數。

python 
a, b = 17, 5
print(a + b)   # 22
print(a - b)   # 12
print(a * b)   # 85
print(a / b)   # 3.4   （/ 一定回傳浮點數）
print(a % b)   # 2     （餘數）
print(a // b)  # 3     （商，捨去小數）
print(a ** b)  # 1419857
🔎 % 和 // 是好朋友

任何整數 a、b（b 不為 0），一定滿足 a == (a // b) * b + a % b。// 求「商」、% 求「餘數」，APCS 常考「奇偶判斷」（n % 2 == 0）、「個位數」（n % 10）都是靠它們。

負數的 // 和 %：往下取整

// 不是「把小數去掉」，而是取比真正答案小、最接近的整數（往下取整）。正數看不出差別，負數就不一樣了：-7 / 2 是 -3.5，往下取整是 -4，不是 -3。% 再用上面那條式子算回來：-7 - (-4)×2 = 1。

負數的整數除法與餘數 
print(7 // 2, -7 // 2)      # 3 -4
print(7 % 2, -7 % 2)        # 1 1
print(-13 // 5, -13 % 5)    # -3 2
print(int(-7 / 2))          # -3（int() 才是直接去掉小數）
▼ 執行結果 3 -4 1 1 -3 2 -3
📌 記法

除數 b 是正數時，a % b 的結果一定落在 0～b-1，不會是負的。所以 -13 % 5 是 2，商就是 (-13 - 2) // 5 = -3。

02比較與邏輯運算子

比較運算子的結果一定是布林值：==、!=、>、>=、<、<=。邏輯運算子用來組合多個條件：and（且）、or（或）、not（否定）。

python 
score = 78
print(score >= 60)                          # True
print(score >= 90 or score >= 60)            # True（有一個為真就是 True）
print(score >= 60 and score < 90)            # True（兩個都要為真）
print(not (score >= 60))                     # False

n = 15
print(1 <= n <= 100)                          # Python 可以連續比較，等同 (1<=n) and (n<=100)
aba and ba or b
TrueTrueTrueTrue
TrueFalseFalseTrue
FalseTrueFalseTrue
FalseFalseFalseFalse

真假值：不是只有 True 和 False

放在 if、while、and／or／not 裡的資料，Python 都會把它看成「真」或「假」：0、0.0、空字串 ''、空串列 [] 是假，其他（不是 0 的數、有內容的字串……）都是真。用 bool() 可以查。

哪些是假？ 
print(bool(0), bool(7), bool(-1))      # False True True
print(bool(''), bool('0'), bool(' '))   # False True True（'0' 和空白都是有內容的字串）
print(bool([]), bool([0]))              # False True
▼ 執行結果 False True True False True True False True

and、or 回傳的是「其中一邊的值」

兩邊都是 True／False 時，結果就跟上面的真值表一樣。但如果放的是數字或字串，and／or 回傳的是其中一邊原本的值，不一定是 True／False：

運算左邊是真左邊是假
a and b回傳 b回傳 a（右邊不用看）
a or b回傳 a（右邊不用看）回傳 b
and／or 的回傳值 
print(3 and 5)            # 5
print(0 and 5)            # 0
print(3 or 5)             # 3
print('' or 'empty')      # empty
print((2 and 'ok') or 0)  # ok
print(not 0, not 'a')     # True False（not 一定回傳 True／False）

name = ''
print(name or '無名氏')    # 常見用法：空字串時給一個預設值
▼ 執行結果 5 0 3 empty ok True False 無名氏
🔎 右邊不用看＝不會執行

and 左邊是假、or 左邊是真時，右邊根本不會被算（短路）。所以 x != 0 and 10 / x > 1 在 x 是 0 時會直接得到 False，不會發生除以 0 的錯誤。

03複合指定運算子

把「運算」和「指定」合在一起的簡寫。a += b 就等同 a = a + b：先用 a 原本的值算出結果，再存回 a。

寫法等同於假設 a = 10，執行後 a 變成
a += 3a = a + 313
a -= 3a = a - 37
a *= 3a = a * 330
a /= 4a = a / 42.5（變成小數）
a //= 3a = a // 33
a %= 3a = a % 31
+=、-=、*=、/= 連續執行，追蹤 a 的變化 
a = 10
a += 5      # a = 10 + 5  → 15
print(a)    # 15
a -= 3      # a = 15 - 3  → 12
print(a)    # 12
a *= 2      # a = 12 * 2  → 24
print(a)    # 24
a /= 4      # a = 24 / 4  → 6.0
print(a)    # 6.0（/ 的結果一定是小數）
最常見的用法：在迴圈裡累加 
total = 0
for i in range(1, 6):
    total += i     # 每一輪把 i 加進 total
print(total)        # 1+2+3+4+5 = 15

count = 0
for ch in "banana":
    if ch == "a":
        count += 1  # 計數器：遇到 a 就加 1
print(count)        # 3
⚠ 識讀常見陷阱

/= 之後變數就變成小數（例如 6.0），印出來會多一個 .0；想保持整數要用 //=。另外 Python 沒有 a++、a-- 這種寫法，要寫成 a += 1、a -= 1。

04運算子優先順序

一個式子裡有好幾個運算子時，Python 照固定的順序算：先算上面的，同一層由左到右。

順序運算子說明
1( )括號最優先
2**次方；連續兩個 ** 是由右到左
3-x負號；-2 ** 2 是先算 2 ** 2 再加負號，結果 -4
4*　/　//　%乘除同一層，由左到右
5+　-加減
6==　!=　<　<=　>　>=比較，可以連寫
7not
8andand 比 or 先算
9or最後才算
照順序算算看 
print(2 + 3 * 4)               # 14
print((2 + 3) * 4)             # 20
print(10 - 4 - 3)              # 3（同一層由左到右）
print(2 ** 3 ** 2)             # 512（先算 3 ** 2）
print(-2 ** 2)                 # -4
print(17 // 5 * 5 + 17 % 5)    # 17
print(1 + 2 > 2 and not 3 < 1) # True
print(True or False and False) # True（先算 and）
▼ 執行結果 14 20 3 512 -4 17 True True
💡 看不懂就自己加括號

寫程式時，不確定順序就加括號，例如 (a + b) * c、(x > 0) and (y > 0)，自己和別人都好讀。識讀題則要照上面的順序一步一步算，最常考的是 -2 ** 2、2 ** 3 ** 2 和 and／or 混在一起。

05補充：位元運算子自主補充・點開閱讀

位元運算子把數字看成二進位，一個 bit 一個 bit 做運算，規則跟數位邏輯課學過的 AND、OR、XOR 閘一樣：

📌 為什麼列為補充？

官方把位元運算列在初級題本的檢測範圍內，但我們查過官方公布的識讀範例題（C 語言版 75 題、Python 版 30 題），都沒有出現位元運算的題目，網路上整理的歷屆觀念題也找不到相關題目。所以這一節當作補充：知道每個運算子的意思、看得懂結果就好，時間有限時優先把前面四節練熟。

運算子名稱規則範例
&AND兩個 bit 都是 1 才是 10b1100 & 0b1010 → 0b1000（8）
|OR只要有一個 bit 是 1 就是 10b1100 | 0b1010 → 0b1110（14）
^XOR兩個 bit 不同才是 10b1100 ^ 0b1010 → 0b0110（6）
~NOT每個 bit 反過來（結果 = -x-1）~5 → -6
<<左移所有 bit 往左移 n 位，右邊補 0（等於 ×2ⁿ）3 << 2 → 12
>>右移所有 bit 往右移 n 位（等於整數除以 2ⁿ）12 >> 2 → 3
python 
a = 12   # 二進位 1100
b = 10   # 二進位 1010

print(bin(a))     # 0b1100
print(a & b)      # 8   →  1000
print(a | b)      # 14  →  1110
print(a ^ b)      # 6   →  0110
print(a << 1)      # 24  → 11000（左移 1 位＝乘以 2）
print(a >> 2)      # 3   → 0011（右移 2 位＝除以 4，取商）
🔎 位元運算子 vs 邏輯運算子：不要搞混！

&／| 是位元運算，作用在整數的每一個 bit 上；and／or 是邏輯運算，作用在 True／False 這種布林值上，考慮的是「兩個條件成不成立」。3 & 5（結果是 1）和 3 and 5（結果是 5，因為兩者都不是 0，取後面那個）意思完全不一樣，這兩組很容易搞混，看到時要特別注意。

💡 為什麼要學位元運算？

位元運算常用來用一個整數同時記錄很多個開關狀態（例如用 8 個 bit 記錄 8 種權限的開／關），或是快速做「乘 2 的次方」「除 2 的次方」「判斷奇偶」（n & 1 就能判斷 n 是不是奇數）。

位元運算的複合指定（補充）

位元運算也有對應的複合指定運算子：&=、|=、^=、<<=、>>=，用法跟 += 一樣。常見用途是用一個整數記錄好幾個「開關」：

用 |= 開、&= 關某一個 bit 
flags = 0b0000
flags |= 0b0100     # 打開第 3 個開關 → 0b100
print(bin(flags))   # 0b100
flags &= ~0b0100    # 再把它關掉     → 0b0
print(bin(flags))   # 0b0
x = 3
x <<= 2             # x = x << 2 → 12（乘以 4）
print(x)            # 12

✏️ 課堂練習

  1. 13 // 4、13 % 4、2 ** 6 分別是多少？
  2. 追蹤程式：x = 7，接著依序執行 x *= 3、x -= 5、x //= 4，最後 print(x) 印出什麼？如果最後一行改成 x /= 4 呢？
  3. print(-11 // 3, -11 % 3) 印出什麼？
  4. print(0 or 'A', 5 and 0, 4 and 'B') 印出什麼？
  5. print(2 + 3 * 4 ** 2 // 8) 印出什麼？依照優先順序寫出每一步。
  6. （補充）a = 6（0b0110），b = 3（0b0011），求 a & b、a | b、a ^ b。
  7. （補充）不用 %，改用位元運算判斷一個整數 n 是不是奇數，該怎麼寫？
▶ 顯示解答
  1. 13 // 4 = 3、13 % 4 = 1、2 ** 6 = 64。
  2. x 依序變成 7 → 21 → 16 → 4，印出 4；改成 x /= 4 的話是 16 / 4，印出 4.0（/ 的結果一定是小數）。
  3. -11 / 3 約是 -3.67，往下取整是 -4；餘數 -11 - (-4)×3 = 1，印出 -4 1。
  4. 0 or 'A' 左邊是假 → A；5 and 0 左邊是真 → 0；4 and 'B' → B。印出 A 0 B。
  5. 4 ** 2 = 16 → 3 * 16 = 48 → 48 // 8 = 6 → 2 + 6 = 8，印出 8。
  6. 0b0110 & 0b0011 = 0b0010（2）、0b0110 | 0b0011 = 0b0111（7）、0b0110 ^ 0b0011 = 0b0101（5）。
  7. (n & 1) == 1（或直接寫 if n & 1:）：奇數的最後一個 bit 一定是 1，偶數一定是 0。在 Python 裡，& 會比 == 先算，所以不加括號的 n & 1 == 1 結果也一樣；但 C／C++ 剛好相反（== 先算），加上括號最不會看錯。
