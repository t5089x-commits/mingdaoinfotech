# 明道中學．資訊科技教學網

高一資訊科技、高二演算法、高三資訊安全導論、高三進階程式設計、APCS 先修班——五科課程教材網站，
由陳楷翔老師花了大量時間整理、撰寫、製作而成。

線上瀏覽：把這個 repo 開啟 GitHub Pages（設定成從根目錄 `/` 發布），
`index.html` 就是總首頁，連到五科各自的課程網站。

## 這份教材可以怎麼使用

這個 repo 是公開的，依照 GitHub 上常見的分享精神，**歡迎任何人自由取用、參考、修改**——
不管是老師想借用單元架構、學生想自己讀、或是想拿去改成自己學校的版本，都沒問題。

唯一想拜託的一件小事：如果你有拿去用，**麻煩寄封信跟我說一聲**，讓我知道：

- 你／你的學校打算怎麼使用這份教材（例如：整份沿用、只借用某幾個單元、參考架構自己重寫……）

不是要管控你怎麼用，單純是希望能因此認識更多同樣在教資訊科技的老師、看看這份教材
在別的教室裡發生了什麼事——**希望能藉這個機會互相交流、一起成長**，不要用完就沒有下文了。

  另有部分示意圖是自己繪製的教學插圖（圖說會註明「自製示意圖」）。
