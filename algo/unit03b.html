字串處理 String

字串就是「字元的序列」，所以陣列會的（索引、切片、走訪），字串幾乎都會。這一單元把文字處理最常用的工具一次講齊——它是後面很多題目的基本功，也是 APCS 實作題最常出現的題型之一。

🎯 學習目標

  • 會用 s[i]、切片、for ch in s 處理字串，並理解字串不可變（immutable）的特性
  • 會用字串的 +（接）與 *（重複），知道布林值計算時 True／False 就是 1／0
  • 會判斷字元種類（isupper()、isdigit()…）、在字元與數字間轉換（int(c)、str(n)）
  • 能用迴圈＋字串寫出母音計數、迴文判斷、逐字組字等常見題型
  • 會用字典（dict）統計「每一種出現幾次、哪個最多」
  • （補充）理解 ASCII 編碼與 ord()／chr()，看懂 C 的 c - '0' 寫法
💻 如何執行這些程式？

每個範例右上角有 ⧉ 複製，點一下複製，貼到 IDLE 就能跑。不熟 IDLE 可先看單元 01b。

01字串是「字元的序列」

字串（String）就是一串字元排在一起。因為它是「序列」，索引、切片、走訪的規則跟上一單元的陣列（list）完全一樣：

索引、切片、走訪 
s = "Mingdao"
print(s[0])        # 'M'      （第 0 個字元）
print(s[-1])       # 'o'      （最後一個）
print(s[1:4])      # 'ing'    （切片：索引 1~3）
print(s[::-1])     # 'oadgniM'（反轉）
print(len(s))      # 7

for ch in s:
    print(ch, end="-")   # M-i-n-g-d-a-o-
⚠ 字串是「不可變（immutable）」的——跟 list 最大的差別

list 可以直接改某一格（a[0] = 99），但字串不行：s[0] = 'X' 會直接 TypeError。要「修改」字串，只能組一個新字串去取代，例如 s = 'X' + s[1:]。這是很常考的觀念。

🖥️ 對照 C／C++

C 的字串其實是「字元陣列」char s[] = "Mingdao";，結尾還藏了一個 '\0' 當結束符號；C++ 另外有好用的 std::string。概念都是「字元排成一排」，但 Python 的字串用起來最省事，所以本單元以 Python 為主。

02字串的 + 與 *、布林值當 1／0、印圖形

同一個運算子，碰到字串意思就變了：+ 是「接起來」，* 是「重複幾次」。

字串的 + 與 * 
print("py" + "thon")   # python
print("py" * 3)        # pypypy
print("-" * 10)        # ----------（印分隔線、印圖形很常用）
print("[" + "x" * 0 + "]")   # []（乘 0 是空字串）
print("py" + str(2))   # py2（數字要先 str() 才能接進字串）

True 當 1、False 當 0

布林值其實是一種特別的整數：拿去計算時 True 就是 1、False 就是 0。這個特性能把「判斷」直接變成「計數」：

布林值拿去算 
print(True + True)       # 2
print(10 * (2 > 5))      # 0   （2>5 是 False=0）
print("ab" * (3 > 1))    # ab  （3>1 是 True=1）

# 應用：一行數出字串裡有幾個大寫字母
s = "Mingdao2026"
print(sum(c.isupper() for c in s))   # 1

用字串乘法印圖形

印三角形時，外層迴圈決定「第幾列」，每列印幾個符號用字串乘法算出來就好，不用再寫一層內迴圈：

靠左與靠右的三角形 
n = 4
for i in range(1, n + 1):
    print("*" * i)

for i in range(1, n + 1):
    print(" " * (n - i) + "*" * i)   # 前面補 n-i 個空白 → 變靠右

03字元判斷與轉換

拿到一個字元 c，最常做的兩件事：判斷它是哪一種、把數字字元轉成真正的數字。

寫法什麼時候是 True例子
c.isupper()大寫英文字母'A'.isupper() → True
c.islower()小寫英文字母'a'.islower() → True
c.isalpha()英文字母（大小寫都算）'Q'.isalpha() → True
c.isdigit()數字字元 0～9'7'.isdigit() → True
c in 'aeiou'是這幾個字元之一判斷母音
統計大寫、小寫、數字、其他 
s = "Mingdao2026!"
up = low = digit = other = 0
for c in s:
    if c.isupper():   up += 1
    elif c.islower(): low += 1
    elif c.isdigit(): digit += 1
    else:             other += 1
print(up, low, digit, other)   # 1 6 4 1

數字字元 ↔ 數字：int(c) 與 str(n)

'7' 是字元，7 才是數字。要把某一位數字拿來計算，先 int(c)；反過來要把數字接進字串，用 str(n)。

把一串數字字串逐位相加 
code = "4710018"
total = 0
for c in code:
    total += int(c)          # 字元轉數字再加
print("位數和：" + str(total))   # 位數和：21
⚠ 開頭是 0 的數字字串，不要整個轉成 int

int("0309") 會變成 309，開頭的 0 不見了，「第幾位是什麼」就對不上。要看每一位時保持字串，需要算的那一位再 int(c)。

🖥️ 對照 C：為什麼 C 要寫 c - '0'？

C／C++ 把數字字元轉成數字常寫 c - '0'，那是利用 ASCII 編碼（本單元最後補充）。Python 直接 int(c) 就好。

04常用字串方法（查表）

方法作用範例
.upper() / .lower()轉大寫／小寫"Hi".upper() → "HI"
.strip()去掉頭尾空白（含換行）" hi ".strip() → "hi"
.split(sep)依分隔符切成 list"a,b,c".split(",") → ['a','b','c']
sep.join(list)把 list 用分隔符接成字串"-".join(['a','b']) → "a-b"
.replace(a, b)把所有 a 換成 b"aabb".replace("a","x") → "xxbb"
.find(sub)子字串第一次出現的索引，找不到回 -1"hello".find("l") → 2
.count(sub)子字串出現次數"banana".count("a") → 3

05常見題型：迴圈＋字串

迴文判斷（正著讀、反著讀一樣）

頭尾往中間比對 
def is_palindrome(s):
    n = len(s)
    for i in range(n // 2):
        if s[i] != s[n - 1 - i]:   # 頭尾對應位置不同 → 不是迴文
            return False
    return True

print(is_palindrome("level"))   # True
print(is_palindrome("apple"))   # False
💡 更快的寫法，但也要會手刻

沒限制的話，一行 s == s[::-1] 就能判斷迴文。但手刻「頭尾往中間比」一次，遇到變化題（只看英文字母、忽略大小寫與空白）才寫得出來——這也是資工訓練的重點：先懂邏輯，再用捷徑。

逐字組出新字串

因為字串不可變，所以用「+ 出新字串」 
s = "hello"
result = ""
for ch in s:
    result = ch + result    # 每次把新字元加在「前面」→ 自然反轉
print(result)   # olleh

06字典（dict）：統計每一種出現幾次

「每一種各出現幾次」「哪個最多」是超常見的需求。用字典最直接：字典是一組組的「鍵：值」，用鍵查值。

計數的標準寫法：d.get(鍵, 0) + 1 
s = "banana"
cnt = {}
for c in s:
    cnt[c] = cnt.get(c, 0) + 1    # 沒出現過就從 0 開始
print(cnt)                         # {'b': 1, 'a': 3, 'n': 2}

best = max(cnt, key=cnt.get)       # 依「值」比大小，回傳鍵
print(best, cnt[best])             # a 3

cnt.get(c, 0) 的意思是「有這個鍵就拿它的值，沒有就當 0」。如果直接寫 cnt[c] += 1，第一次遇到時字典還沒有它，會 KeyError。

💡 種類固定時也可以用陣列計數

如果種類很少又固定（例如 26 個小寫字母），也能用 cnt = [0]*26 搭配 ord(c)-ord('a') 當索引（見下方補充）。種類不固定時（名字、產地），字典最方便。

07補充：ASCII 與 ord()／chr()

電腦裡每個字元都對應一個數字編碼，常用的是 ASCII 碼。ord() 查字元的編碼，chr() 把編碼變回字元：

ord() 與 chr() 
print(ord('A'), ord('a'), ord('0'))   # 65 97 48
print(chr(65), chr(97))               # A a

# A~Z 是連續的 65~90，a~z 是連續的 97~122
print(chr(ord('D') + 1))   # 'E'（字母往後移一位）
print(ord('c') - ord('a')) # 2（字母轉成 0~25 的索引）
💡 大小寫差 32，這就是 C 的 c - '0' 原理

大小寫字母的 ASCII 剛好差 32。C 把數字字元 '7' 轉成數字 7 寫 '7' - '0'，就是算「它在 ASCII 上比 '0' 大多少」。Python 不能寫 '7' - '0'（會 TypeError），直接 int(c) 即可。

🔥 挑戰題

  1. print(True + 2, "x" * (5 > 3), "[" + "x" * (5 < 3) + "]") 印出什麼？

    ▸ 看答案

    True+2=3；5>3=True → "x"*1="x"；5<3=False → "x"*0=""。印出 3 x []。

  2. 輸入一段句子，找出出現最多次的字元是哪一個、出現幾次（多個同次時取最先遇到的）。

    ▸ 看答案

    s = input()
cnt = {}
for c in s:
    cnt[c] = cnt.get(c, 0) + 1
best = max(cnt, key=cnt.get)
print(best, cnt[best])
  3. 判斷一個字串是不是迴文，但只看英文字母、忽略大小寫與空白（例如 "A man a plan" 的變化題）。

    ▸ 看答案

    s = input()
t = ""
for c in s:
    if c.isalpha(): t += c.lower()  # 先過濾＋轉小寫
print(t == t[::-1])
