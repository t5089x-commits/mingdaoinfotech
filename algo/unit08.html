集合是「元素不重複、沒有順序」的資料結構，查詢平均只要 O(1)，是去重複、判斷是否出現過最好用的工具。

01集合 Set 是什麼？

集合（Set）是一種「元素不重複、沒有順序」的資料結構，概念跟數學課的集合一模一樣。它最大的特色是：檢查某個元素在不在集合裡，平均只要 O(1)（陣列要逐一比對是 O(n)），因為底層是用雜湊表（Hash Table）實作的。

💡 什麼時候該想到用集合？

看到題目要「判斷某個值是否出現過」、「去除重複」、「兩群資料的交集/聯集」，就該想到集合——比逐一比對的陣列寫法快很多。

02Python 集合的基本操作

建立集合、新增、刪除、查詢 
s = {1, 2, 3}          # 建立集合
s.add(4)                # 新增元素
s.remove(2)              # 刪除元素（不存在會報錯）
s.discard(99)             # 刪除元素（不存在也不會報錯，比較安全）

print(3 in s)             # True，查詢是否存在，平均 O(1)
print(len(s))              # 集合大小

nums = [5, 3, 9, 3, 5, 8]
unique = set(nums)          # 一行去除重複！
print(unique)                # {3, 5, 8, 9}（順序不保證）
#include <iostream>
#include <unordered_set>
using namespace std;
int main(){
    unordered_set<int> s = {1, 2, 3};
    s.insert(4);
    s.erase(2);

    cout << (s.count(3) > 0) << endl;   // 查詢是否存在
    cout << s.size() << endl;

    // 去除重複
    int nums[] = {5, 3, 9, 3, 5, 8};
    unordered_set<int> unique(nums, nums+6);
    for (int x : unique) cout << x << " ";
    cout << endl;
    return 0;
}

03集合運算：聯集、交集、差集

運算符號方法意義
聯集 Union|a.union(b)兩邊全部的元素（不重複）
交集 Intersection&a.intersection(b)兩邊都有的元素
差集 Difference-a.difference(b)在 a 但不在 b 的元素
對稱差集 Symmetric Difference^a.symmetric_difference(b)只在其中一邊出現的元素
集合運算範例 
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a | b)   # 聯集 {1, 2, 3, 4, 5, 6}
print(a & b)   # 交集 {3, 4}
print(a - b)   # 差集（a有b沒有）{1, 2}
print(a ^ b)   # 對稱差集 {1, 2, 5, 6}

# 子集合判斷
print({1, 2} <= a)   # True，{1,2} 是 a 的子集合
#include <iostream>
#include <set>
#include <algorithm>
#include <iterator>
using namespace std;
int main(){
    set<int> a = {1, 2, 3, 4};
    set<int> b = {3, 4, 5, 6};
    set<int> result;

    set_union(a.begin(), a.end(), b.begin(), b.end(), inserter(result, result.begin()));
    for (int x : result) cout << x << " "; cout << endl;   // 聯集

    result.clear();
    set_intersection(a.begin(), a.end(), b.begin(), b.end(), inserter(result, result.begin()));
    for (int x : result) cout << x << " "; cout << endl;   // 交集
    return 0;
}

04APCS 實戰：用集合快速判斷是否出現過

經典題型：給兩個整數陣列 A、B，判斷有多少對 (a, b) 滿足 a + b = K。如果用雙迴圈暴力比對是 O(n²)，用集合可以降到 O(n)。

Two-Number Problem 
def count_pairs(a, b, k):
    s = set(b)
    count = 0
    for x in a:
        if k - x in s:      # O(1) 查詢
            count += 1
    return count

a = [1, 6, -3]
b = [5, 1, -1, -3]
print(count_pairs(a, b, 2))   # 2
#include <iostream>
#include <unordered_set>
#include <vector>
using namespace std;

int countPairs(vector<int>& a, vector<int>& b, int k){
    unordered_set<int> s(b.begin(), b.end());
    int count = 0;
    for (int x : a){
        if (s.count(k - x)) count++;
    }
    return count;
}

int main(){
    vector<int> a = {1, 6, -3};
    vector<int> b = {5, 1, -1, -3};
    cout << countPairs(a, b, 2) << endl;
    return 0;
}

05兩種不錯的去重複寫法

🔀 陣列去重複，保留原本順序 vs 不保留順序

用 set()：最快但不保留順序

適合「只在意結果有哪些值」的情境。

set 去重複 
nums = [5, 3, 9, 3, 5, 8]
result = list(set(nums))
print(result)   # 順序不保證，例如 [8, 9, 3, 5]

先排序再逐一比對：保留由小到大順序

適合題目要求「輸出時要由小到大排序」的情境（第 5 章 AP325 例題就是這種寫法）。

排序去重複 
nums = [5, 3, 9, 3, 5, 8]
result = sorted(set(nums))
print(result)   # [3, 5, 8, 9] 保證由小到大

如果題目沒特別要求順序，用 set() 最簡單；如果要「由小到大」，就用 sorted(set(...))。
