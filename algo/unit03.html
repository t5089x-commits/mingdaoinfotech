資料結構(一) 陣列

陣列是最基礎、最常用的資料結構。這一單元會介紹陣列的宣告、種類、記憶體位置計算公式（這部分是 C／C++ 底層概念，會特別標註），以及基本操作的時間複雜度。

🎯 學習目標

  • 理解陣列的定義與使用時機
  • 能用 Python／C++ 宣告一維、二維、多維陣列
  • 理解陣列位置計算公式，並知道這是 C／C++ 的底層概念
  • 能反推二維陣列是 Row-major 還是 Column-major
  • 能說出陣列基本操作的時間複雜度，並理解陣列的優缺點

01什麼是陣列？

陣列（Array）是「有限個相同類型的變數」組成的有序集合，陣列中的每一個變數稱為元素。陣列是最簡單、也最常用的資料結構。

什麼時候要用陣列？當你需要處理「一大堆同性質的資料」時——例如全班 40 位學生的成績，與其宣告 40 個變數（score1, score2, ... score40），不如宣告一個陣列，用索引（index）去區分每一筆資料。

🖥️ 這是 C／C++ 的規則：陣列佔用「連續」記憶體空間

在 C／C++ 裡，陣列裡的每個元素會被安排在連續的記憶體位址上，這也是後面「位置計算」整節的理論基礎。Python 的 list 不是這樣運作的——Python 的 list 存的其實是一串「指向物件的參照」，物件本身可能散落在記憶體各處，list 只是照順序記住「這些物件在哪裡」。這個差異平常寫程式感覺不出來，但如果要深入理解「陣列位置計算」那幾節公式，務必記得那是 C／C++ 的底層規則，不是 Python 的實際運作方式。

02陣列的宣告

陣列宣告（含初始值） 
number = [1, 2, 3]                 # 宣告 3 個元素的整數陣列
score = [80.5, 50.9, 51.2, 90.6]     # 宣告 4 個元素的浮點數陣列
astring = ["abc", "aaa"]              # 宣告 2 個元素的字串陣列

x = [1, 2, 3, 4, 5]                    # 宣告時直接給初始值
z = [[1,2,3,4], [5,6,7,8], [0,1,2,3]]  # 二維陣列也是直接寫進去
a = []                                   # 空陣列
b = [0] * 6                             # 6 個元素，全部預設為 0
int number[10];      // 宣告 10 個元素的整數陣列
double score[10];    // 宣告 10 個元素的浮點數陣列
char ascii[10];      // 宣告 10 個元素的字元陣列

int x[5] = {1, 2, 3, 4, 5};            // 宣告時直接給初始值
int z[3][4] = {{1,2,3,4},{5,6,7,8},{0,1,2,3}}; // 二維陣列
int a[4] = {};                          // 全部預設為 0
int b[6] = {0};                          // 第一個是 0，其餘也自動補 0

索引值都是從 0 開始，最大索引值是「陣列大小 − 1」。

🖥️ C／C++ 的規則：宣告時要先講好「大小」與「型態」

C／C++ 宣告陣列時必須先決定好元素型態與陣列大小（例如 int number[10] 就固定是 10 格整數，之後不能隨意增減）。Python 呢？Python 的 list 不用事先宣告型態或大小，甚至同一個 list 裡可以放不同型態的資料（雖然不建議這樣做），長度也能隨時用 append()、insert() 之類的方法動態增減——這是 Python list 跟 C／C++ 陣列最大的差異之一。

從記憶體的角度看：這就是兩者最大的差異

光看程式碼可能感覺差不多，但如果把「變數名稱、儲存位址、實際內容」畫出來，會發現兩者的記憶體配置方式完全不同：

🐍 Python list：位址可能是散落的

list 本身（存放參照的那排格子）是連續的，但每一格存的是「地址」，指向的實際資料可能散落在記憶體各處，彼此不相鄰。

⚙️ C++ array：宣告就固定一整條

宣告的當下就決定了一整塊連續記憶體，每個元素的值直接存在對應的位址裡，中間沒有任何「轉一手」的過程。

🔗 這跟後面要學的「鏈結串列」有什麼關係？

你會發現 Python 的 list，其實已經有點「不是傳統陣列」的味道了——它靠的是參照（也就是位址）把資料串起來，而不是資料本身緊鄰在一起。

鏈結串列（下一單元）把這個概念再往前推一步：既然反正都要透過位址去找資料，那乾脆連「順序排列的位址」都不要了，每一筆資料自己額外存一個「下一筆資料在哪裡」的指標，資料要放在記憶體的哪裡都無所謂。Python list 是「排好順序的參照集合」，鏈結串列則是「每個節點自己記得下一個在哪裡」——這是後面單元會直接感受到的差異。

03陣列的種類：一維／二維／多維

一維、二維、多維陣列 
# 一維陣列
arr1 = [1, 2, 3]

# 二維陣列：list 裡面包 list
arr2 = [[1, 2, 3], [4, 5, 6]]
print(arr2[1][2])   # 6，先取第 1 個 list，再取裡面的第 2 個元素

# 多維陣列：可以一直包下去
arr3 = [[[1, 2], [3, 4]], [[5, 6], [7, 8]]]
int arr1[3] = {1, 2, 3};                       // 一維
int arr2[2][3] = {{1,2,3}, {4,5,6}};             // 二維
int arr3[2][2][2] = {{{1,2},{3,4}}, {{5,6},{7,8}}}; // 三維（多維）
🖥️ C／C++ 的規則：二維陣列是「固定大小的格子」

C／C++ 宣告 int arr2[2][3] 之後，這就是一塊固定 2×3、共 6 格的連續記憶體——這正是下一節「位置計算」公式能夠成立的原因。Python 的二維陣列（list 包 list）則是「每一個 list 各自獨立存在記憶體某處」，並沒有真正連續排列在一起，所以 Python 並不會、也不需要用「位置計算公式」去找元素，直接用 arr2[i][j] 存取即可，底層幫你處理好了。

04陣列的位置計算：一維陣列（C／C++ 底層概念）

🖥️ 這整節都是 C／C++（甚至更底層）的規則

接下來這幾節「位置計算」，講的是陣列在記憶體裡「連續排列」時，怎麼用數學公式算出某個元素實際的記憶體位址。這是 C／C++ 或組合語言等級的底層概念，Python 完全不需要你自己算——寫 arr[i]，Python 就直接幫你找到那個元素了。不過這是計算機科學的基本功、也是 APCS 常考的題型，一樣要學會。

🏠 一個比喻：班級名冊 vs 門牌地址

Python 的 list 比較像拿著一張班級名冊：arr[41] 是「查名冊上第 41 號」，查到的是「這位同學家住哪裡」這筆資訊，還要再照著這個地址去找到他家、找到人——中間多轉了一手。

C／C++ 的陣列比較像是門牌地址本身：陣列宣告的時候，就直接是「XX 路 1～42 號」這種連續門牌，arr[41] 本身就是地址，不用再查名冊——想找隔壁號碼的家，直接往旁邊走就到了。

⚠️ 小提醒：這不代表 Python 的 arr[41] 變成「要找很久」——查名冊、查地址兩個動作都還是「一步到位」（都是 O(1)，不會因為陣列變大而變慢）。差別是 C／C++ 只要走一步（直接到地址），Python 要走兩步（先查名冊、再到地址），實際跑起來 C／C++ 通常會快一些，但兩者在「時間複雜度」這個分類上其實是同一個等級。

公式裡的符號意義：

  • A[n] 表示陣列裡有 n 格元素
  • l0 表示陣列的起始位址
  • l1 表示陣列的第一個索引值
  • d 表示每個元素的大小（byte 數）
📐 一維陣列位置公式

A[i] 的位址 = l0 + (i − l1) × d

✏️ 練習

  1. 假設有個陣列，起始位置 A[0] = 100，d = 2，求 A[16] = ?

    ▸ 看答案

    代入公式：A[16] = 100 + (16 − 0) × 2 = 132

  2. 假設有個陣列，起始位置 A[-3] = 100，d = 1，求 A[5] = ?

    ▸ 看答案

    這裡 l1 = −3（索引可以是負的，只是起始索引剛好是 −3），代入公式：A[5] = 100 + (5 − (−3)) × 1 = 100 + 8 = 108

05陣列的位置計算：二維陣列

二維陣列有兩種常見的記憶體排列方式：

  • Row-major（以列為主）：由上而下，一列一列讀入一維陣列
  • Column-major（以行為主）：由左而右，一行一行讀入一維陣列

Row-major 公式

A[i][j] = l0 + ((i−l1)×n + (j−l2)) × d

n 為每一列的元素個數

Column-major 公式

A[i][j] = l0 + ((i−l1) + (j−l2)×m) × d

m 為每一行的元素個數

✏️ 練習：Row-major

  1. 陣列 A[5][4]（也就是 5 列 4 行），第一個元素是 A[0][0]，l0=1000，d=1，求 A[3][2] = ?（Row-major）

    ▸ 看答案

    n（每列元素數）= 4。代入公式：A[3][2] = 1000 + (3×4 + 2) × 1 = 1014

  2. C 語言宣告 float A[7][8]（sizeof(float) = 4），已知 A[3][4] 的位址是 100，求 A[5][6] 的位址（Row-major，n=8）

    ▸ 看答案

    不用重新代整條公式，直接算「位移量」更快：位移 = ((5×8+6) − (3×8+4)) × 4 = (46−28) × 4 = 72。所以 A[5][6] = 100 + 72 = 172

✏️ 練習：Column-major

  1. 同樣是 A[5][4]，第一個元素 A[0][0]，l0=1000，d=1，求 A[3][2] = ?（這次是 Column-major）

    ▸ 看答案

    m（每行元素數）= 5。代入公式：A[3][2] = 1000 + (3 + 2×5) × 1 = 1013

06進階挑戰：反推是 Row-major 還是 Column-major

有些題目不會直接告訴你是 Row-major 還是 Column-major，要自己從位址資訊反推。先記住這個快速判斷技巧：

條件結論
列數較大的元素，位址也較大Row-major
行數較大的元素，位址也較大Column-major

✏️ 快速判斷練習

  1. A[3][5] = 14，A[5][3] = 22，是 Row-major 還是 Column-major？

    ▸ 看答案

    比較位址與列數：14 < 22，列數 3 < 5——位址跟著列數變大，是 Row-major。

  2. A[3][5] = 14，A[5][3] = 10，是 Row-major 還是 Column-major？

    ▸ 看答案

    比較位址與行數：14 > 10，行數 5 > 3——位址跟著行數變大，是 Column-major。

  3. A[3][5] = 14，A[5][7] = 33，能判斷嗎？

    ▸ 看答案

    列數 3→5 變大、行數 5→7 也變大，位址也變大——列跟行同時變大，無法只靠這兩點判斷，需要更多資訊（例如再給一個位址）才能確定。

如果題目給兩個位址，且無法直接用上面技巧判斷，就要代公式解聯立方程式。這裡示範一題完整過程：

📝 範例：A[1][1]=2，A[2][3]=18，A[3][2]=28，求 A[4][5]

先判斷 Row-major 或 Column-major：2 < 3（列 1→2 變大，位址也變大）、18 < 28（列 2→3，位址也變大）——判斷是 Row-major。

因為 A[1][1] = 2，所以 l0=2, l1=1, l2=1。代入公式 A[i][j] = l0 + ((i−l1)×n + (j−l2))×d 解 n、d：

A[2][3] = 2 + (1×n + 2)×d = 18　⟹　nd + 2d = 16　……(1)
A[3][2] = 2 + (2×n + 1)×d = 28　⟹　2nd + d = 26　……(2)

(1)×2 − (2)：3d = 6 ⟹ d = 2, n = 6

代入 A[4][5]：A[4][5] = 2 + [(4−1)×6 + (5−1)]×2 = 2 + [18+4]×2 = 2 + 44 = 46

📝 範例：A[3][3]=121，A[6][4]=159，元素大小 d=1，求 A[4][5]

先試 Row-major：代入兩式相減，解出 n = 37/3（不是整數）→ 不是 Row-major。

再試 Column-major：代入公式 A[i][j] = l0 + ((i−l1) + (j−l2)×m)×d，解出 m = 35（是整數）→ 是 Column-major，且 l0 = 49。

代入 A[4][5]：A[4][5] = 49 + [(4−1) + (5−1)×35] = 49 + [3+140] = 192

⚠ 這幾題已經是 APCS 檢定等級的難度

這種「反推 Row/Column-major」的題型計算量較大，考試常出，建議多練習幾次上面的解題流程，熟悉「先試 Row-major、算出來不是整數就改試 Column-major」這個標準流程。

07陣列的基本操作

讀取與更新 
arr = [1, 2, 3, 4, 5]
print(arr[3])    # 讀取索引 3 的元素 → 4
arr[3] = 10       # 更新索引 3 的元素為 10
print(arr)         # [1, 2, 3, 10, 5]
int arr[5] = {1, 2, 3, 4, 5};
cout << arr[3] << endl;   // 讀取，4
arr[3] = 10;                 // 更新
cout << arr[3] << endl;   // 10

插入元素

🖥️ C／C++ 的規則：固定陣列沒辦法插入，要用 vector

C／C++ 的固定大小陣列（int arr[5]）宣告之後大小就固定死了，沒有「插入」這個操作。要有跟 Python list 一樣「可以動態增減」的能力，C++ 要改用標準函式庫的 vector（動態陣列）。

插入元素 
my_list = [1, 2, 4, 5]
my_list.append(6)          # 尾部插入 → [1, 2, 4, 5, 6]
my_list.insert(2, 3)        # 中間插入（位置 2）→ [1, 2, 3, 4, 5, 6]
#include <vector>
using namespace std;
vector<int> myList = {1, 2, 4, 5};
myList.push_back(6);                  // 尾部插入 → {1,2,4,5,6}
myList.insert(myList.begin()+2, 3);   // 中間插入（位置2）→ {1,2,3,4,5,6}

刪除元素

刪除元素 
my_list = [1, 2, 3, 4, 5]
my_list.remove(3)            # 依照「值」刪除（找到第一個 3 並移除）→ [1, 2, 4, 5]

my_list2 = [1, 2, 4, 5]
del my_list2[1]                # 依照「索引」刪除位置 1 的元素 → [1, 4, 5]
#include <vector>
#include <algorithm>
using namespace std;
vector<int> myList = {1, 2, 3, 4, 5};
myList.erase(remove(myList.begin(), myList.end(), 3), myList.end()); // 依照「值」刪除

vector<int> myList2 = {1, 2, 4, 5};
myList2.erase(myList2.begin() + 1);   // 依照「索引」刪除位置 1 的元素

時間複雜度總表

💡 Python list 跟 C++ vector 的時間複雜度是「同一套」

下面這張表，Python 的 list 和 C++ 的 vector 適用的是同一套時間複雜度——兩者都是「動態陣列」，背後的設計策略基本相同。真正不一樣的是 C 的固定陣列：因為大小固定死了，「插入」「刪除（改變長度）」這兩件事根本做不到，沒有時間複雜度可言，只能重新宣告一個更大／更小的陣列，把資料整個複製過去。

操作時間複雜度說明
讀取元素O(1)直接用索引定位
更新元素O(1)直接用索引定位
尾部插入O(1)不影響其他元素位置（Python list／C++ vector 都是攤銷 O(1)）
中間插入O(n)後面元素都要往後搬一格
刪除（無排序要求，可用最後一個元素補位）O(1)把最後一個元素搬到被刪除的位置就好，不用管順序
刪除（要維持原本順序）O(n)後面元素都要往前補位

08陣列的優缺點

✅ 優點

可以直接用索引「隨機存取」任何一個元素，時間複雜度 O(1)，效率非常高。

⚠️ 缺點

插入與刪除元素（尤其是中間位置）會導致大量元素被移動，效率較差。

💡 結論：陣列適合用在「讀取操作多、寫入操作少」的資料。如果需要頻繁地在中間插入或刪除資料，下一單元的鏈結串列會是更好的選擇——這也是我們接下來要學的主題。
