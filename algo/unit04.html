資料結構(二) 鏈結串列

陣列需要連續記憶體，鏈結串列則用「指標」把資料一個一個串起來，插入刪除更有效率。

🎯 學習目標

  • 理解鏈結串列與陣列在記憶體配置上的差異
  • 認識單向、雙向、環狀三種鏈結串列
  • 能實作節點的建立、走訪、插入
💻 如何執行這些程式？

01鏈結串列 Linked List

陣列的元素必須存在「連續」的記憶體空間，鏈結串列則不需要——每個節點（Node）除了存資料，還存了一個指標，指向下一個節點的位置，像一串珠鍊一樣串起來。

  • 每個 Node 都有 data
  • next 指向下一個 Node
  • 最後一個 Node 的 next 是 None
  • Node 不需要連續存在記憶體中

💡 這張圖的資訊分四層：① head 從哪裡開始 → ② Node 長什麼樣（data + next 兩格） → ③ next 怎麼連到下一個 Node → ④ 最後一個 Node 的 next 指向 None，代表串列結束。

02三種型態

單向

每個節點只有一個指標，指向下一個節點。

雙向

每個節點有兩個指標：prev 指向上一個節點、next 指向下一個節點，可以往前也可以往後走。

環狀

最後一個節點的指標指回第一個節點，形成環狀。

⚠ 易混淆點：prev／next 格裡放的是「位址」，不是資料本身

雙向圖裡的 prev、next 看起來像是跟 data 平起平坐的三個「一樣的格子」，很容易誤會成「prev 格裡存的是上一筆資料的複製、next 格裡存的是下一筆資料的複製」。其實不是——prev 和 next 存的都只是「指標（位址）」，指向另一個節點；只有中間的 data 格才是真正存放這個節點資料的地方。這也是為什麼圖上把 prev、next 用不同底色標出來，跟 data 做區分。

03建立與走訪

建立一個單向鏈結串列並走訪 
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

# 建立 1 -> 2 -> 3
head = ListNode(1)
head.next = ListNode(2)
head.next.next = ListNode(3)

# 走訪
node = head
while node:
    print(node.val)
    node = node.next
#include <iostream>
using namespace std;

struct Node {
    int val;
    Node* next;
};

int main(){
    Node* head = new Node{1, nullptr};
    head->next = new Node{2, nullptr};
    head->next->next = new Node{3, nullptr};

    Node* n = head;
    while (n != nullptr){
        cout << n->val << endl;
        n = n->next;
    }
    return 0;
}
💡 這裡用到的 class 是什麼？

class 是 Python 用來定義「自訂資料型態」的寫法。ListNode 這個 class 把「一個節點該有的東西」定義好：一個存資料的 val，一個存指標的 next。每次呼叫 ListNode(1)、ListNode(2)，就是照著這個模板各自獨立產生一個新的節點物件——這些物件的資料互不相干，但都遵守同一套「格式」。

鏈結串列是 class 派上用場的經典場景：因為每個節點都要「自己存自己的資料 + 自己記得下一個是誰」，用 class 把這兩件事包在一起，比用一堆各自獨立的變數乾淨很多。

對遊戲程式設計方面有興趣的同學，之後可以再往這個方向精進：遊戲裡的角色、怪物，通常也都是用 class 定義的——例如「怪物」這個 class 可能會有生命值、攻擊力、技能清單等資料，每一隻怪物都是這個 class 產生出來的一個獨立物件，屬性可以各自不同（史萊姆生命值 10、王者史萊姆生命值 500，但兩者都是同一種「怪物」class）。這跟這裡「同一個 ListNode class，產生出資料各不相同的節點」是同一個概念。

04插入與刪除：只要改指標，不用搬資料

陣列中間插入要搬移大量元素（O(n)），鏈結串列只需要改「指標的指向」，如果已經有指到插入點的指標，插入本身是 O(1)。這是鏈結串列相對陣列最大的優勢。

⚠ 單向串列的限制

如果只知道節點 P 的位置，要在 P 之後插入是 O(1)（改兩個指標就好）；但要在 P 之前插入，單向串列沒辦法「回頭」，必須從頭開始找 P 的前一個節點，變成 O(n)。這正是雙向鏈結串列存在的理由之一。

在節點後方插入新節點 
def insert_after(node, val):
    new_node = ListNode(val)
    new_node.next = node.next
    node.next = new_node

# head: 1 -> 2 -> 3
insert_after(head, 99)   # 在 head(值1) 後面插入 99
# 結果變成 1 -> 99 -> 2 -> 3
void insertAfter(Node* node, int val){
    Node* newNode = new Node{val, node->next};
    node->next = newNode;
}
