資料結構(二) 鏈結串列

陣列需要連續記憶體，鏈結串列則用「指標」把資料一個一個串起來，插入刪除更有效率。

🎯 學習目標

  • 理解鏈結串列與陣列在記憶體配置上的差異
  • 認識單向、雙向、環狀三種鏈結串列
  • 能實作節點的建立、走訪、插入與刪除
  • 能說出陣列與鏈結串列各自的優缺點，知道什麼情況該用哪一個
💻 如何執行這些程式？

每個範例右上角有 ⧉ 複製 按鈕，點一下複製程式碼，貼到你電腦上的 IDLE（Python 內建的編輯器）就能執行看看結果。還不熟悉 IDLE 怎麼開、怎麼操作的話，可以先看單元 01b：IDLE 操作入門。

01鏈結串列 Linked List

陣列的元素必須存在「連續」的記憶體空間，鏈結串列則不需要——每個節點（Node）除了存資料，還存了一個指標，指向下一個節點的位置，像一串珠鍊一樣串起來。

  • 每個 Node 都有 data
  • next 指向下一個 Node
  • 最後一個 Node 的 next 是 None
  • Node 不需要連續存在記憶體中

💡 這張圖的資訊分四層：① head 從哪裡開始 → ② Node 長什麼樣（data + next 兩格） → ③ next 怎麼連到下一個 Node → ④ 最後一個 Node 的 next 指向 None，代表串列結束。

02三種型態

單向

每個節點只有一個指標，指向下一個節點。

雙向

每個節點有兩個指標：prev 指向上一個節點、next 指向下一個節點，可以往前也可以往後走。

環狀

最後一個節點的指標指回第一個節點，形成環狀。

⚠ 易混淆點：prev／next 格裡放的是「位址」，不是資料本身

雙向圖裡的 prev、next 看起來像是跟 data 平起平坐的三個「一樣的格子」，很容易誤會成「prev 格裡存的是上一筆資料的複製、next 格裡存的是下一筆資料的複製」。其實不是——prev 和 next 存的都只是「指標（位址）」，指向另一個節點；只有中間的 data 格才是真正存放這個節點資料的地方。這也是為什麼圖上把 prev、next 用不同底色標出來，跟 data 做區分。

🌍 生活中的三種鏈結串列

單向｜尋寶／解謎接力：第一張紙條告訴你第二個地點，到了才拿到下一張……每張紙條只知道「下一站在哪」，別的都不知道。想到第 5 站一定要從第 1 站一路找過去，也不能往回走——這正是單向：只有一個 next、一定從頭開始、想往前只能重來。

雙向｜瀏覽器的上一頁／下一頁：每一頁都記得「上一頁」和「下一頁」是誰，所以前進後退都行。音樂播放器上一首／下一首、Word 的復原／重做（Ctrl+Z／Ctrl+Y）也一樣——每個節點同時有 prev 和 next。

環狀｜行車紀錄器循環錄影：記憶卡錄滿後，最新畫面自動蓋掉最舊的，繞一圈繼續用——「最後」接回「最前」、空間循環利用。（資工加碼：作業系統讓多個程式「輪流」用 CPU 的 round-robin 排程，也是這個結構。）

03建立與走訪

建立一個單向鏈結串列並走訪 
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

# 建立 1 -> 2 -> 3
head = ListNode(1)
head.next = ListNode(2)
head.next.next = ListNode(3)

# 走訪
node = head
while node:
    print(node.val)
    node = node.next
#include <iostream>
using namespace std;

struct Node {
    int val;
    Node* next;
};

int main(){
    Node* head = new Node{1, nullptr};
    head->next = new Node{2, nullptr};
    head->next->next = new Node{3, nullptr};

    Node* n = head;
    while (n != nullptr){
        cout << n->val << endl;
        n = n->next;
    }
    return 0;
}

上面是「手動」一個一個接。但實務上你常常已經有一個普通的 list，這時更常見的做法是寫一個函式，讓 list 自動變成鏈結串列——就像把排好隊的人，從頭一個接一個牽起手：

把一般 list 轉成鏈結串列 
# 把一般的 list 自動變成鏈結串列
def build_from_list(arr):
    head = tail = None
    for x in arr:                 # 一個一個把元素接成節點
        node = ListNode(x)
        if head is None:          # 第一個節點：同時是頭，也是目前的尾
            head = tail = node
        else:                     # 其餘：接在尾巴後面，再把尾巴往後移
            tail.next = node
            tail = node
    return head

data = [10, 20, 30]
head = build_from_list(data)      # 一行就自動變成 10 -> 20 -> 30
Node* buildFromList(int arr[], int n){
    Node* head = nullptr;
    Node* tail = nullptr;
    for (int i = 0; i < n; i++){                // 一個一個接成節點
        Node* node = new Node{arr[i], nullptr};
        if (head == nullptr) head = tail = node;  // 第一個：同時是頭也是尾
        else { tail->next = node; tail = node; }  // 其餘：接在尾巴後面
    }
    return head;
}

走訪可以拿來做什麼？算長度、找資料

「從 head 沿著 next 一直走到 None」這個走訪模式，幾乎所有操作都用得到。例如算長度、搜尋某個值：

走訪的應用：算長度、搜尋 
# 走訪的兩個常見應用：算長度、找某個值
def length(head):
    count = 0
    node = head
    while node:                # 從 head 一直走到 None
        count += 1
        node = node.next
    return count

def find(head, target):
    node = head
    while node:
        if node.val == target:
            return True        # 找到了
        node = node.next
    return False               # 走到 None 都沒找到
int length(Node* head){
    int count = 0;
    for (Node* n = head; n != nullptr; n = n->next) count++;
    return count;
}

bool find(Node* head, int target){
    for (Node* n = head; n != nullptr; n = n->next)
        if (n->val == target) return true;
    return false;
}
🔎 注意到了嗎？

鏈結串列沒有索引，不能像 arr[3] 一步到位。想找第 k 個、或搜尋某個值，都只能從頭一個一個走 → 所以是 O(n)。這正是它跟陣列最關鍵的差別（最後一節會整理成一張表）。

💡 這裡用到的 class 是什麼？

class 是 Python 用來定義「自訂資料型態」的寫法。ListNode 這個 class 把「一個節點該有的東西」定義好：一個存資料的 val，一個存指標的 next。每次呼叫 ListNode(1)、ListNode(2)，就是照著這個模板各自獨立產生一個新的節點物件——這些物件的資料互不相干，但都遵守同一套「格式」。

鏈結串列是 class 派上用場的經典場景：因為每個節點都要「自己存自己的資料 + 自己記得下一個是誰」，用 class 把這兩件事包在一起，比用一堆各自獨立的變數乾淨很多。

對遊戲程式設計方面有興趣的同學，之後可以再往這個方向精進：遊戲裡的角色、怪物，通常也都是用 class 定義的——例如「怪物」這個 class 可能會有生命值、攻擊力、技能清單等資料，每一隻怪物都是這個 class 產生出來的一個獨立物件，屬性可以各自不同（史萊姆生命值 10、王者史萊姆生命值 500，但兩者都是同一種「怪物」class）。這跟這裡「同一個 ListNode class，產生出資料各不相同的節點」是同一個概念。

04插入與刪除：只要改指標，不用搬資料

陣列中間插入要搬移大量元素（O(n)），鏈結串列只需要改「指標的指向」，如果已經有指到插入點的指標，插入本身是 O(1)。這是鏈結串列相對陣列最大的優勢。

⚠ 單向串列的限制

如果只知道節點 P 的位置，要在 P 之後插入是 O(1)（改兩個指標就好）；但要在 P 之前插入，單向串列沒辦法「回頭」，必須從頭開始找 P 的前一個節點，變成 O(n)。這正是雙向鏈結串列存在的理由之一。

在節點後方插入新節點 
def insert_after(node, val):
    new_node = ListNode(val)
    new_node.next = node.next
    node.next = new_node

# head: 1 -> 2 -> 3
insert_after(head, 99)   # 在 head(值1) 後面插入 99
# 結果變成 1 -> 99 -> 2 -> 3
void insertAfter(Node* node, int val){
    Node* newNode = new Node{val, node->next};
    node->next = newNode;
}
⚠ 為什麼這兩行不能對調？

new_node.next = node.next 一定要在 node.next = new_node 之前。如果先把 node.next 改成 new_node，node 原本後面那一整串就「找不到了」（斷鏈），再也接不回來。口訣：先接好新節點的後面，再把前面接上來。

刪除：讓前一個節點「跳過」它

刪除比插入更簡單——把前一個節點的 next「跳過」要刪的那個，它就從串列上消失了（不用搬動其他任何資料，一樣是 O(1)）：

刪除某個節點 
# 刪除 node 後面那個節點
def delete_after(node):
    if node.next is not None:
        node.next = node.next.next   # 讓 next 跳過中間那個，它就被「斷開」了

# head: 1 -> 99 -> 2 -> 3
delete_after(head)   # 刪掉 head 後面的 99
# 結果變成 1 -> 2 -> 3
void deleteAfter(Node* node){
    if (node->next != nullptr){
        Node* target = node->next;
        node->next = target->next;  // 跳過 target
        delete target;              // C++ 要自己釋放記憶體，Python 會自動回收
    }
}

05陣列 vs 鏈結串列：什麼時候用哪個？

這張表把整個單元串起來——同一件事，兩種結構誰比較快？

操作陣列 (array)鏈結串列 (linked list)
讀取第 k 個元素O(1) ✅ 用索引一步到位O(n)　要從 head 一個一個走
在開頭插入／刪除O(n)　後面全部要往後／往前搬O(1) ✅ 改指標就好
在中間（已知位置）插入／刪除O(n)　要搬動後面的元素O(1) ✅ 改指標就好
搜尋某個值O(n)O(n)
記憶體必須連續不必連續，但每個節點要多存一個指標
📌 一句話選擇法

常常要「用位置直接拿第 k 個」→ 用 陣列；常常在頭尾或中間「插入／刪除」→ 用 鏈結串列。

其實生活中的鏈結串列很多：瀏覽器的上一頁／下一頁、音樂播放清單、文書軟體的復原／重做、作業系統管理記憶體……都是「常常插入刪除、不太需要用索引亂跳」的場景。
