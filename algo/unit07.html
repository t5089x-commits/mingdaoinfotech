01樹狀結構 Tree

樹是一種階層式的資料結構：有一個根節點（Root），每個節點可以有多個子節點。二元樹（Binary Tree）是最常見的樹，規定每個節點最多只有兩個子節點（左子節點、右子節點）。

02三種走訪方式

走訪方式順序
前序 Pre-order根 → 左子樹 → 右子樹
中序 In-order左子樹 → 根 → 右子樹
後序 Post-order左子樹 → 右子樹 → 根
⚠ 易混淆點：哪兩種走訪能重建唯一的樹

「中序＋前序」或「中序＋後序」可以決定唯一的二元樹；但「前序＋後序」不行。記憶方法：中序負責告訴我們「誰在左邊、誰在右邊」，前序或後序負責告訴我們「誰是目前的根」——少了中序，就無法切出左右子樹的邊界。

03二元搜尋樹 BST：建立、走訪、搜尋

二元搜尋樹（Binary Search Tree）多一個規則：左子樹所有值都比根小，右子樹所有值都比根大。這個規則讓搜尋可以像二分搜尋一樣，每次排除一半的節點。

BST 建立、走訪、搜尋 
class BST:
    def __init__(self, data=None):
        self.data = data
        self.left = None
        self.right = None

    def insert(self, data):
        if self.data is None:
            self.data = data
        elif data < self.data:
            if self.left: self.left.insert(data)
            else: self.left = BST(data)
        elif data > self.data:
            if self.right: self.right.insert(data)
            else: self.right = BST(data)

    def inorder(self):
        res = []
        if self.left: res += self.left.inorder()
        res.append(self.data)
        if self.right: res += self.right.inorder()
        return res

    def search(self, data):
        if self.data is None: return False
        if data == self.data: return True
        if data < self.data:
            return self.left.search(data) if self.left else False
        return self.right.search(data) if self.right else False

tree = BST()
for v in [11, 7, 15, 5, 3, 9]:
    tree.insert(v)
print(tree.inorder())    # [3, 5, 7, 9, 11, 15] 中序走訪一定是排序好的！
print(tree.search(9))    # True
#include <iostream>
using namespace std;

struct Node {
    int data;
    Node *left, *right;
};

Node* insert(Node* root, int val){
    if (root == nullptr){
        Node* n = new Node();
        n->data = val; n->left = n->right = nullptr;
        return n;
    }
    if (val < root->data) root->left = insert(root->left, val);
    else if (val > root->data) root->right = insert(root->right, val);
    return root;
}

void inorder(Node* root){
    if (root == nullptr) return;
    inorder(root->left);
    cout << root->data << " ";
    inorder(root->right);
}

int main(){
    Node* root = nullptr;
    int values[] = {11, 7, 15, 5, 3, 9};
    for (int v : values) root = insert(root, v);
    inorder(root);
    cout << endl;
    return 0;
}

04小觀察：BST 中序走訪 = 排序結果

💡 為什麼中序走訪一定是排序好的？

因為 BST 的規則本來就是「左子樹 < 根 < 右子樹」，而中序走訪的順序剛好是「左子樹 → 根 → 右子樹」——兩者的規則完全對應，所以中序走訪的結果必然由小到大排列。這也是 BST 常被拿來當作排序輔助結構的原因。
