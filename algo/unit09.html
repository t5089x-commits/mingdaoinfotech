01氣泡排序 Bubble Sort

規則很單純：從頭開始，一直比較「相鄰的兩個」元素，如果左邊比右邊大就交換，跑完一輪之後，最大的值就會像泡泡一樣「浮」到最右邊。點下面的「下一步」，看看電腦實際上是怎麼一步一步排序 [5, 3, 1, 4, 2] 的。

步驟 0 / 11

尚未確定 正在比較 剛交換 已排定位置
bubble_sort.py／.cpp 
list1 = [5, 3, 1, 4, 2]
for i in range(1, len(list1)):
    for j in range(0, len(list1) - i):
        if list1[j] > list1[j + 1]:
            list1[j], list1[j + 1] = list1[j + 1], list1[j]
print(list1)
#include <iostream>
using namespace std;
int main(){
    int arr[5] = {5, 3, 1, 4, 2};
    for (int i = 1; i < 5; i++){
        for (int j = 0; j < 5 - i; j++){
            if (arr[j] > arr[j+1]){
                int tmp = arr[j];
                arr[j] = arr[j+1];
                arr[j+1] = tmp;
            }
        }
    }
    for (int j = 0; j < 5; j++) cout << arr[j] << " ";
    cout << endl;
    return 0;
}

02時間複雜度

情況時間複雜度說明
最壞情況O(n²)資料完全反著排，每一輪都要一直交換
最好情況O(n)資料本來就排好了（如果程式有加「這輪都沒交換就提早結束」的優化）
加上提早結束優化 
def bubble_sort(a):
    n = len(a)
    for i in range(1, n):
        swapped = False
        for j in range(0, n - i):
            if a[j] > a[j+1]:
                a[j], a[j+1] = a[j+1], a[j]
                swapped = True
        if not swapped:      # 這一輪完全沒交換，代表已經排好了
            break
    return a
