演算法(三) 插入排序

插入排序：把每個新元素插入到已排序部分的正確位置，資料本來就快排好時效率特別好。

01插入排序 Insertion Sort

把每個新元素，往前插入到「已經排好的部分」中正確的位置——很像整理撲克牌時的手法：左手拿著已經排好的牌，每拿到一張新牌，就找到對的位置插進去。點下面的「下一步」，看看電腦實際上是怎麼一步一步排序 [5, 3, 1, 4, 2] 的。

步驟 0 / 21

尚未確定 正在比較 剛交換 已排定位置
insertion_sort.py／.cpp 
list1 = [5, 3, 1, 4, 2]
for i in range(1, len(list1)):
    key = list1[i]
    j = i - 1
    while j >= 0 and list1[j] > key:
        list1[j + 1] = list1[j]
        j -= 1
    list1[j + 1] = key
print(list1)
#include <iostream>
using namespace std;
int main(){
    int arr[5] = {5, 3, 1, 4, 2};
    for (int i = 1; i < 5; i++){
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key){
            arr[j+1] = arr[j];
            j--;
        }
        arr[j+1] = key;
    }
    for (int j = 0; j < 5; j++) cout << arr[j] << " ";
    cout << endl;
    return 0;
}

02為什麼插入排序在「快排好的資料」特別快

如果資料本來就幾乎排好了，每個新元素只需要往前移動很少的距離（甚至不用移動），內層 while 迴圈幾乎不會執行，實際比較次數會非常接近 O(n)。這跟氣泡/選擇排序不管資料原本排得多好、比較次數都差不多的特性完全不同。

情況時間複雜度
最壞（完全反著排）O(n²)
最好（已經排好）O(n)

    ▸ 看答案

    插入排序。因為資料本來就快排好了，插入排序的實際比較次數會非常接近 O(n)，遠比重新排一次的 O(n²) 快。
