資料結構(四) 堆疊

堆疊是「後進先出」的資料結構，一疊盤子就是最好的比喻。這一單元會從 Push/Pop 基礎，一路帶到括號配對、中序/前序/後序轉換，最後用堆疊直接算出運算式的答案。

  • 理解電腦用堆疊掃描處理運算式轉換的邏輯

01什麼是堆疊？

堆疊（Stack）就像一疊盤子：新盤子永遠疊在最上面，要拿盤子也只能從最上面拿——不可能抽底下那一個。這個「最上面」的位置，叫做 Top。

3　（最後放進去，最先拿出來）
2
1　（Bottom）

從這個比喻可以直接看出堆疊唯一的核心規則：

🔑 LIFO：Last In First Out（後進先出）

最後放進去的東西，會最先被拿出來。

💡 那要怎麼在程式裡「放」跟「拿」呢？下一節就來看堆疊實際上有哪些操作。

堆疊只有兩個核心動作：東西怎麼放進去、東西怎麼拿出來——但因為 LIFO 的規則，這兩個動作都只能發生在 Top：

stack = []
stack.append(1)   # push
stack.append(2)
stack.append(3)

#include <iostream>
#include <stack>
using namespace std;
int main(){
    stack<int> st;
    st.push(1);
    st.push(2);
    st.push(3);
    cout << "top: " << st.top() << endl;
    st.pop();
    cout << "剩下的 top: " << st.top() << endl;
    return 0;
}

💡 這兩個動作看起來很簡單，但接下來不管是括號配對還是運算式轉換，用到的全部都是這裡的 Push 跟 Pop——先把這節記熟，後面會一直用到。

03為什麼堆疊有用？先用括號配對理解

學會 Push / Pop 之後，來看堆疊的第一個實際用途：檢查括號是否配對，例如 ((a+b)*c) 是對的，但 ((a+b)*c 少了一個右括號。

💡 關鍵觀念

堆疊不只是拿來存數字，它可以拿來暫存「還沒處理完的東西」。掃描括號的過程中，每個左括號都代表一個「還沒配對完成」的任務，堆疊剛好可以把這些未完成的任務一個一個疊起來，等右括號出現時再取出來核對。

為什麼偏偏是堆疊？因為括號的配對規則正好符合 LIFO：最後出現的左括號，一定要最先被配對——例如 ( [ ) ] 是錯的，因為最後開的 [ 應該要最先被配對，不能讓 ) 插隊。這正是「後進先出」。

做法：遇到左括號就 push，遇到右括號就 pop 並核對是否對應，如果最後堆疊剛好清空，就代表括號都配對成功。

括號配對檢查 
def is_balanced(s):
    stack = []
    pairs = {')': '(', ']': '[', '}': '{'}
    for ch in s:
        if ch in '([{':
            stack.append(ch)
        elif ch in ')]}':
            if not stack or stack.pop() != pairs[ch]:
                return False
    return len(stack) == 0

print(is_balanced("((a+b)*c)"))   # True
print(is_balanced("((a+b)*c"))    # False
#include <iostream>
#include <stack>
#include <string>
using namespace std;

bool isBalanced(string s){
    stack<char> st;
    for (char ch : s){
        if (ch=='(' || ch=='[' || ch=='{') st.push(ch);
        else if (ch==')' || ch==']' || ch=='}'){
            if (st.empty()) return false;
            char top = st.top(); st.pop();
            if ((ch==')' && top!='(') || (ch==']' && top!='[') || (ch=='}' && top!='{'))
                return false;
        }
    }
    return st.empty();
}

int main(){
    cout << boolalpha << isBalanced("((a+b)*c)") << endl;
    cout << boolalpha << isBalanced("((a+b)*c") << endl;
    return 0;
}

💡 括號配對只是堆疊的第一個應用。接下來要看一個更厲害的用法——堆疊還能處理完整的數學運算式。

04堆疊如何處理運算式？中序／前序／後序

括號配對讓我們看到堆疊能「暫存還沒處理完的東西」。運算式其實也一樣——像 A+B*(C-D) 這種式子，在還沒算完之前，運算子（+、*）都得先「等在旁邊」，直到輪到它們的時候才能真正計算，這正是堆疊擅長的事。

在講堆疊怎麼處理運算式之前，要先認識三種表示法。中序 A+B 是人習慣的寫法，「前、中、後」指的其實是運算子相對於運算元的位置：

■ 運算元 Operand■ 運算子 Operator
表示法格式範例
中序 Infix<運算元1> <運算子> <運算元2>A + B
前序 Prefix<運算子> <運算元1> <運算元2>+ A B
後序 Postfix<運算元1> <運算元2> <運算子>A B +

為什麼要多學後序？因為後序完全不需要括號就能表達運算順序，而且能直接搭配堆疊、由左到右掃描一次就算出答案（這件事會在第 7 節實際做一次）。這就是為什麼電腦處理運算式時，經常會先把中序轉成後序。

💡 那要怎麼把我們習慣的中序，轉換成後序或前序呢？先來看人腦怎麼手算。

05人怎麼做？用「加括號去除法」手算轉換

✍️ 這是紙筆／考試上的手算方法

接下來這個方法是給人腦用的捷徑，方便手算或考試——電腦實際上並不是這樣做的（電腦的做法在下一節）。

重點是先用括號把優先順序標出來，再把運算子搬到括號的對應邊，最後拿掉括號。

→ 轉前序 Prefix（運算子移到左括號右邊）

例：A+B*(C-D)

① 加括號分優先權(A+(B*(C-D)))
② 運算子移到左括號右邊(A+(*B(-CD)))
(+A(*B(-CD)))
③ 拿掉括號+A*B-CD

→ 轉後序 Postfix（運算子移到右括號左邊）

例：A+B*(C-D)

① 加括號分優先權(A+(B*(C-D)))
② 運算子移到右括號左邊(A+(B(CD-)*))
(A(B(CD-)*)+)
③ 拿掉括號ABCD-*+
⚠ 易混淆點：兩個方向剛好相反

轉前序：運算子移到「左」括號右邊；轉後序：運算子移到「右」括號左邊——方向剛好相反，是手算時最容易搞混的地方。口訣：「前序靠左括號，後序靠右括號」。

💡 人腦可以「用眼睛」一次看出優先權、直接加括號，但電腦沒辦法用看的——那電腦到底怎麼一步一步做到同樣的事？

06電腦怎麼做？用 Stack 掃描、Push、Pop 進行中序轉後序

加括號去除法是「人」的捷徑，電腦實際上是用堆疊、一個字一個字掃描來處理的——而且這裡用到的動作，其實就是第 2 節學過的 Push 跟 Pop，只是現在應用到運算式轉換上。這裡先完整講清楚「中序 → 後序」，前序轉換的邏輯類似但掃描方向相反，留在最後當作補充。

電腦的操作規則（中序轉後序，由左而右掃描）

  • 遇到運算元（數字/字母） → 直接輸出，不放入堆疊
  • 遇到左括號 ( → 直接 Push（見右方「括號的特殊規則」）
  • 遇到右括號 ) → 不斷 Pop 並輸出，直到 Pop 出左括號為止（左括號本身不輸出，直接丟棄）
  • 遇到運算子（如 + - * /）→ 跟堆疊「頂端」比較優先權（優先權對照見右表）：
    • 如果比堆疊頂端優先權高 → 直接 Push
    • 如果不比堆疊頂端優先權高 → 先 Pop 堆疊頂端並輸出，再 Push 目前這個運算子
  • 掃描完畢後 → 堆疊裡如果還有剩下的運算子，依序全部 Pop 並輸出

符號的優先順序

符號說明
(　)特殊規則，不算在一般優先權高低裡：左括號一律直接 Push；只要還在堆疊裡「等待」，就視為優先權最低，這樣後面優先權更高的運算子才能疊在它上面；右括號一出現，就觸發「不斷 Pop 直到彈出左括號」，跟一般運算子的比較方式完全不同。
*　/　（優先權 2，較高）乘除法，比加減法優先
+　-　（優先權 1，較低）加減法

💡 左邊規則裡「跟堆疊頂端比較優先權」，比的就是這張表——例如掃描到 *、堆疊頂端是 +，因為 *（優先權 2）比 +（優先權 1）高，所以直接 Push，不會先彈出 +。

📎 補充：前序轉換怎麼做？

前序轉換的規則類似，但要由右而左掃描（跟後序的由左而右相反），運算元一樣直接輸出、運算子一樣跟堆疊頂端比較優先權，只是最後把輸出結果整個反過來才是答案。方向相反很容易搞混，建議先把後序的邏輯練熟，之後再挑戰前序。

07（延伸）用 Stack 計算後序運算式

我們已經知道怎麼把中序轉成後序了。那如果拿到一個後序運算式，要怎麼用堆疊直接算出答案呢？這一節把整條路徑串起來：Stack → 後序 → Push/Pop → 電腦算出結果。

規則比轉換還簡單：

  • 遇到運算元 → 直接 Push
  • 遇到運算子 → Pop 兩個運算元、計算出結果，再把結果 Push 回堆疊
  • 掃描完畢 → 堆疊裡剩下的唯一一個值，就是答案

以 3 4 + 2 *（也就是中序的 (3+4)*2）為例，手動追蹤一次：

讀到動作堆疊內容（由底到頂）
3運算元 → Push3
4運算元 → Push3, 4
+運算子 → Pop 4、Pop 3，計算 3+4=7，Push 77
2運算元 → Push7, 2
*運算子 → Pop 2、Pop 7，計算 7*2=14，Push 1414
（讀完）堆疊只剩一個值，就是答案14 ✅
計算後序運算式 
def eval_postfix(tokens):
    stack = []
    for t in tokens:
        if t in "+-*/":
            b = stack.pop()
            a = stack.pop()
            if t == "+": stack.append(a + b)
            elif t == "-": stack.append(a - b)
            elif t == "*": stack.append(a * b)
            elif t == "/": stack.append(a / b)
        else:
            stack.append(int(t))
    return stack.pop()

expr = "3 4 + 2 *".split()
print(eval_postfix(expr))   # 14
#include <iostream>
#include <sstream>
#include <stack>
#include <string>
using namespace std;

int evalPostfix(string expr){
    stack<int> st;
    stringstream ss(expr);
    string token;
    while (ss >> token){
        if (token=="+" || token=="-" || token=="*" || token=="/"){
            int b = st.top(); st.pop();
            int a = st.top(); st.pop();
            if (token=="+") st.push(a+b);
            else if (token=="-") st.push(a-b);
            else if (token=="*") st.push(a*b);
            else st.push(a/b);
        } else {
            st.push(stoi(token));
        }
    }
    return st.top();
}

int main(){
    cout << evalPostfix("3 4 + 2 *") << endl;
    return 0;
}
