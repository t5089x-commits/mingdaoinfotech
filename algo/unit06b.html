堆疊 vs 佇列 比較

學過堆疊和佇列之後，這一頁把兩者放在一起比較——重點不是「怎麼放進去」，而是「怎麼拿出來」。

🎯 學習目標

  • 理解 append() 不是分辨 Stack／Queue 的關鍵
  • 能用「取出的位置」正確分辨 Stack 與 Queue
  • 記住口訣：Stack → append()+pop()，Queue → append()+popleft()
💻 如何執行這些程式？

每個範例右上角有 ⧉ 複製 按鈕，點一下複製程式碼。左下角一直固定在畫面上的兩個按鈕，可以分別開啟 Programiz 的 Python／C++ 線上編譯器（免安裝、開瀏覽器就能跑），把程式碼貼過去即可看到執行結果。

01第一階段：概念

不看程式碼，先建立最單純的概念：

🟠 Stack 堆疊🔵 Queue 佇列
原則LIFO：後進先出FIFO：先進先出
白話最後放進去的，最先出來最先放進去的，最先出來

02第二階段：畫圖

Stack 用「同一端」進出畫，Queue 用「兩端分開」畫：

🟠 Stack：從同一邊進、同一邊出

3
2
1　（Bottom）

append() 放入、pop() 取出——兩個動作都發生在同一端（Top）

🔵 Queue：後面進、前面出

popleft() ← [1, 2, 3] ← append

append() 放入 Rear、popleft() 取出 Front——兩個動作發生在不同端

03第三階段：Python 與 C++ 實作

🟠 Stack

Stack 
stack = []
stack.append(1)  # 放入
stack.append(2)
stack.append(3)
stack.pop()       # 從最後面拿出（跟放入同一邊）
#include <iostream>
#include <stack>
using namespace std;
int main(){
    stack<int> st;
    st.push(1);
    st.push(2);
    st.push(3);
    st.pop();       // 從最後面拿出（跟放入同一邊）
    return 0;
}

Stack = append() + pop()

🔵 Queue

Queue 
from collections import deque
q = deque()
q.append(1)       # 從 Rear 放入
q.append(2)
q.append(3)
q.popleft()         # 從 Front 拿出（跟放入不同邊）
#include <iostream>
#include <queue>
using namespace std;
int main(){
    queue<int> q;
    q.push(1);
    q.push(2);
    q.push(3);
    q.pop();        // 從最前面拿出（跟放入不同邊）
    return 0;
}
💡 為什麼要 import deque？

Python 的 list 也有 pop(0) 可以從最前面取出，但那個動作是 O(n)——因為 list 在記憶體裡是連續排列的，拿掉第一個之後，後面所有元素都要往前搬一格。

collections.deque（雙向佇列）底層設計不同，不管從前面還是後面加入/取出都是 O(1)。佇列會一直從前面取資料，如果用一般 list，資料量一大效率會變得很差，所以佇列一律建議用 deque，不要用 list 的 pop(0)。

Queue = append() + popleft()

04最後才提醒：兩邊其實都有 append()

你們可能會發現，Stack 和 Queue 兩邊都有 append()：

兩個都有 append() 
stack.append(x)   # 堆疊：從右邊加入
q.append(x)        # 佇列：也是從右邊加入（Rear）
⚠ append() 不能拿來判斷是 Stack 還是 Queue

沒關係，這是正常的——append() 不是區分 Stack 和 Queue 的關鍵，取出的方法才是。真正該問的問題不是「東西從哪裡放進去」，而是：「東西從哪裡拿出來？」

🔑 不要看怎麼放，要看怎麼拿。

Stack → append() + pop()　　　　 Queue → append() + popleft()

生活比喻

🍽️ Stack🚶 Queue
想像疊盤子排隊
加入最上面放後面排
取出最上面拿最前面走
原則LIFO（後進先出）FIFO（先進先出）
Pythonappend() → pop()append() → popleft()

💡 Stack 像疊盤子：最後放的盤子最先拿。Queue 像排隊：最先來的人最先離開。
