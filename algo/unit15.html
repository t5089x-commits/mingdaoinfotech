01循序搜尋法 Sequential Search

最直覺的搜尋方式：從頭到尾一個一個比對，找到就回傳位置，找不到就回傳 -1。不需要資料先排序，任何順序的資料都能用。

循序搜尋 
def sequential_search(a, key):
    for i in range(len(a)):
        if a[i] == key:
            return i
    return -1

data = [7, 2, 9, 4, 1, 8]
print(sequential_search(data, 4))   # 3
print(sequential_search(data, 99))  # -1
#include <iostream>
using namespace std;

int sequentialSearch(int a[], int n, int key){
    for (int i = 0; i < n; i++){
        if (a[i] == key) return i;
    }
    return -1;
}

int main(){
    int data[6] = {7, 2, 9, 4, 1, 8};
    cout << sequentialSearch(data, 6, 4) << endl;
    cout << sequentialSearch(data, 6, 99) << endl;
    return 0;
}

02時間複雜度

情況時間複雜度
最好情況（第一個就找到）O(1)
最壞情況（最後一個或找不到）O(n)
平均情況O(n)
💡 什麼時候一定要用循序搜尋？

當資料沒有排序、而且只搜尋一次的時候——因為為了搜尋而先排序（至少 O(n log n)）反而更浪費。但如果同一份資料要搜尋很多次，先排序一次、之後都用二分搜尋，總體會更划算。
