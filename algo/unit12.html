演算法(四) 快速排序

01快速排序 Quick Sort

選一個基準值（pivot），把比它小的丟左邊、比它大的丟右邊，再對左右兩邊分別遞迴排序。這是「分治法」（切一半、分別解決、再合併）的經典應用。

quick_sort.py／.cpp 
list1 = [5, 3, 1, 4, 2]

def quicksort(a, left, right):
    if left >= right:
        return
    i, j, key = left, right, a[left]     # 以最左邊的值當基準點
    while i != j:
        while a[j] > key and i < j:       # 從右邊找比 key 小的
            j -= 1
        while a[i] <= key and i < j:       # 從左邊找比 key 大的
            i += 1
        if i < j:
            a[i], a[j] = a[j], a[i]
    a[left] = a[i]
    a[i] = key
    quicksort(a, left, i - 1)      # 遞迴處理左半邊
    quicksort(a, i + 1, right)      # 遞迴處理右半邊

quicksort(list1, 0, len(list1) - 1)
print(list1)
#include <iostream>
using namespace std;

void quicksort(int a[], int left, int right){
    if (left >= right) return;
    int i = left, j = right, key = a[left];
    while (i != j){
        while (a[j] > key && i < j) j--;
        while (a[i] <= key && i < j) i++;
        if (i < j) swap(a[i], a[j]);
    }
    a[left] = a[i];
    a[i] = key;
    quicksort(a, left, i-1);
    quicksort(a, i+1, right);
}

int main(){
    int arr[5] = {5, 3, 1, 4, 2};
    quicksort(arr, 0, 4);
    for (int j = 0; j < 5; j++) cout << arr[j] << " ";
    cout << endl;
    return 0;
}

02為什麼快速排序平均很快，最壞卻是 O(n²)？

情況時間複雜度原因
平均情況O(n log n)基準值大致能把陣列切成差不多大的兩半
最壞情況O(n²)每次都選到「最大或最小值」當基準，切出來一邊是空的，等於完全沒切
⚠ 什麼時候會踩到最壞情況

如果每次都固定選「最左邊」當基準值，而資料剛好本來就是排序好的，就會一直踩到最壞情況。實務上常用的解法是「隨機選基準值」或「三數取中」，降低踩到最壞情況的機率。

03分治法的三個步驟

  • 分割 Divide：用基準值把陣列切成兩半
  • 解決 Conquer：對左右兩半分別遞迴排序
  • 合併 Combine：快速排序不太需要額外合併，因為切割時已經確保左邊都比右邊小
