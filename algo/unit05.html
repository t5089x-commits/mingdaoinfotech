資料結構(三) 佇列

佇列是「先進先出」的資料結構，排隊買東西、遊戲配對都是這個概念。這一單元會介紹基本操作、環狀佇列的原理，以及 Python 的兩種實作方式。

  • 理解環狀佇列為什麼存在，以及它的容量陷阱
  • 能用手刻環狀陣列與 collections.deque 兩種方式實作佇列

01佇列 Queue：先進先出 (FIFO)

佇列就像排隊買飲料：先來的人先買到（先進先出，First In First Out）。資料從 Rear（尾端）加入，從 Front（前端）取出。

Front → [1, 2, 3] ← Rear
🎮 生活中的例子：遊戲伺服器排隊

玩線上遊戲時常看到「配對中…目前排隊人數 87 人」——這就是佇列！最早按下「開始配對」的玩家會最先被配對進遊戲（先進先出），伺服器內部通常就是用佇列在管理這個排隊名單。

03環狀佇列 Circular Queue

如果用一般陣列實作佇列，Dequeue 之後前面會空出格子，但 Rear 只會一直往右移動，用著用著就會誤判「已滿」——即使前面明明有空位。解法是把陣列頭尾相接，變成環狀佇列，讓 Rear 可以繞回陣列開頭繼續使用。

📊 為什麼只能真正用 n-1 格

⚠ 陷阱說明

環狀佇列要留一格「刻意不用」，用來區分「全空」跟「全滿」——因為這兩種狀態下 Front 和 Rear 都可能指向同一格，如果不留空位，程式沒辦法分辨「這是空的還是滿的」。所以容量 6 的環狀佇列，實際上只能放 5 筆資料。

🎮 環狀佇列解決了什麼問題？

手機遊戲的「連續技 / 招式候選清單」、音樂播放器的「循環播放清單」，都會用到環狀佇列的概念——固定大小的空間、用完了就繞回開頭繼續用，不需要無限增長的記憶體。例如節奏遊戲判定最近 N 個節拍的輸入，就常用固定大小的環狀緩衝區（circular buffer，跟環狀佇列是同樣的概念）不斷覆蓋最舊的資料。

⚠ 重點：Rear 是「數字一直往前跑」還是「會繞回去」

左邊（沒有環狀）的 Rear 指標一路往右走，走到底之後就再也回不去了，即使前面 0x1000、0x1004 這兩格已經被 Dequeue 釋放出來，Rear 也不會知道要回去用——所以判定「已滿」而失敗。右邊（有環狀）的 Rear 用「除以容量取餘數」的方式繞回開頭，於是能重複利用那兩格已經釋放的記憶體，繼續 Enqueue 成功。

對照程式碼：動畫背後實際跑的邏輯

上面動畫的每一步，其實就是在跑下面這兩段程式碼——差別只在 enqueue／dequeue 裡面那一行索引怎麼算。這裡用「函式 + global」來寫（跟補充單元教過的區域變數／全域變數是同一件事），還不需要用到 class：

🚫 沒有環狀（線性）

線性佇列 
data = [None] * 6
front = 0
rear = 0

def enqueue(v):
    global rear
    if rear >= len(data):
        print("已滿！")
        return
    data[rear] = v
    rear += 1          # 只會一直增加，不會回頭

def dequeue():
    global front
    if front >= rear:
        print("空的！")
        return None
    v = data[front]
    data[front] = None
    front += 1
    return v


# 對照動畫的操作順序：填滿 A~F，Dequeue 兩次，再 Enqueue G、H
for ch in "ABCDEF":
    enqueue(ch)
dequeue()          # 取出 A
dequeue()          # 取出 B
enqueue("G")        # ❌ 已滿！（即使前面兩格是空的）
enqueue("H")        # ❌ 已滿！

✅ 有環狀（環狀）

環狀佇列 
data = [None] * 6
front = 0
rear = 0
count = 0

def enqueue(v):
    global rear, count
    if count == len(data):
        print("已滿！")
        return
    data[rear] = v
    # 關鍵：取餘數，繞回開頭
    rear = (rear + 1) % len(data)
    count += 1

def dequeue():
    global front, count
    if count == 0:
        print("空的！")
        return None
    v = data[front]
    data[front] = None
    # 關鍵：取餘數，繞回開頭
    front = (front + 1) % len(data)
    count -= 1
    return v


# 對照動畫的操作順序：填滿 A~F，Dequeue 兩次，再 Enqueue G、H
for ch in "ABCDEF":
    enqueue(ch)
dequeue()          # 取出 A，0x1000 釋放
dequeue()          # 取出 B，0x1004 釋放
enqueue("G")        # ✅ 繞回開頭，放入剛釋放的 0x1000
enqueue("H")        # ✅ 繞回開頭，放入剛釋放的 0x1004
💡 兩段程式碼只差一個地方

整段程式幾乎一模一樣，唯一的差別就是 rear += 1 對比 rear = (rear + 1) % len(data)——多了 % len(data)（取餘數）這幾個字，就是「會不會繞回開頭」的全部差異。這也是環狀佇列在實作上最關鍵、也最容易忘記寫的一行。

04Python 怎麼實作

🔀 手刻環狀陣列 vs 內建 deque

手刻環狀陣列

用固定大小的陣列 + front/rear 索引自己實作，能看到佇列底層真正在做什麼、為什麼會有 n-1 格的限制。

環狀陣列版 
data = [None] * 6
front = 0
rear = 0

def is_empty():
    return front == rear

def is_full():
    return (rear + 1) % len(data) == front

def enqueue(v):
    global rear
    if is_full():
        print("佇列已滿")
        return
    data[rear] = v
    rear = (rear + 1) % len(data)

def dequeue():
    global front
    if is_empty():
        print("佇列是空的")
        return None
    v = data[front]
    front = (front + 1) % len(data)
    return v

內建 collections.deque

兩端操作都是 O(1)，程式碼最少、最不容易出錯，寫程式、比賽、APCS 都建議直接用這個。

deque 版 
from collections import deque
q = deque()
q.append(10); q.append(20)
print(q.popleft())
