演算法(五) 合併排序

合併排序：切到最小、分別排序、再合併。時間複雜度保證是 O(n log n)，是 Python 內建排序的底層概念。

🎯 學習目標

  • 理解合併排序「切、遞迴、合併」的邏輯
  • 能自己用 Python／C++ 寫出合併排序
  • 能比較合併排序與快速排序的優缺點

01合併排序 Merge Sort

也是分治法：先把陣列切一半、切一半、再切一半……切到只剩一個元素（天生排好），再把兩個排好的小陣列「合併」成一個排好的大陣列。

merge_sort.py／.cpp 
list1 = [5, 3, 1, 4, 2]

def merge(left, right):
    result = []
    while left and right:
        if left[0] < right[0]:
            result.append(left.pop(0))
        else:
            result.append(right.pop(0))
    return result + left if left else result + right

def merge_sort(a):
    if len(a) < 2:
        return a
    mid = len(a) // 2
    return merge(merge_sort(a[:mid]), merge_sort(a[mid:]))

print(merge_sort(list1))
#include <iostream>
#include <vector>
using namespace std;

vector<int> merge(vector<int> left, vector<int> right){
    vector<int> result;
    size_t i = 0, j = 0;
    while (i < left.size() && j < right.size())
        result.push_back(left[i] < right[j] ? left[i++] : right[j++]);
    while (i < left.size()) result.push_back(left[i++]);
    while (j < right.size()) result.push_back(right[j++]);
    return result;
}

vector<int> mergeSort(vector<int> a){
    if (a.size() < 2) return a;
    int mid = a.size() / 2;
    vector<int> left(a.begin(), a.begin()+mid), right(a.begin()+mid, a.end());
    return merge(mergeSort(left), mergeSort(right));
}

int main(){
    vector<int> arr = {5, 3, 1, 4, 2};
    vector<int> sorted = mergeSort(arr);
    for (int x : sorted) cout << x << " ";
    cout << endl;
    return 0;
}

02合併排序 vs 快速排序

合併排序快速排序
最壞時間O(n log n)（穩定保證）O(n²)
穩定性穩定不穩定
額外記憶體需要額外陣列存合併結果原地排序，不太需要額外空間
適合場景需要「保證」不會變慢的場合、外部排序（資料太大放不進記憶體）一般情況下平均更快
💡 這就是 Python sort() 的底層邏輯！

Python 內建的 sort()／sorted() 用的是 Timsort，是合併排序的優化版本（結合了插入排序處理小區塊），兼顧了「保證不會太慢」跟「實務上很快」兩個優點。
