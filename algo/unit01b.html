IDLE 操作入門

這學期的程式範例，統一用 IDLE（Python 內建的編輯器）來執行，不需要額外安裝軟體、也不需要連網。這是一個很小的單元，帶你快速認識 IDLE 的兩個視窗、怎麼新增檔案、怎麼執行程式。

🎯 學習目標

  • 知道 IDLE 是什麼、怎麼打開它
  • 分清楚「Shell 視窗」跟「編輯器視窗」的差別
  • 會新增一個 .py 檔案、輸入程式碼並存檔
  • 會用 Run → Run Module（或按 F5）執行程式，並在 Shell 看到結果

01什麼是 IDLE？

IDLE 是安裝 Python 的時候會自動一起裝好的編輯器，全名是 Integrated Development and Learning Environment。不用額外下載、不用註冊帳號、也不用連上網路——這學期上課、寫作業、練習範例程式，都用它就好。

🖼️ 圖片待補 IDLE 圖示 / 開始畫面示意

02怎麼打開 IDLE？

在 Windows 上，從開始選單找到 IDLE (Python 3.x) 點開即可（用開始選單搜尋「IDLE」三個字最快）。第一次打開時會看到一個標題寫著 Python 3.x.x Shell 的視窗，這就是 IDLE 的主畫面。

🖼️ 圖片待補 從開始選單找到並開啟 IDLE 的畫面

03Shell 視窗：先玩玩看

剛打開的這個視窗叫 Interactive Shell（互動模式），看到 >>> 這個提示符號，就代表它在等你輸入一行程式碼。輸入完按 Enter，馬上就會看到結果——很適合用來快速測試一小段程式碼。

在 Shell 裡直接輸入試試看 
>>> print("Hello, IDLE!")
Hello, IDLE!
>>> 3 + 5
8
🖼️ 圖片待補 Shell 視窗輸入程式碼與結果的畫面
💡 Shell 適合「玩」，不適合「寫完整程式」

Shell 裡打的東西不會存檔，關掉視窗就沒了。真正要寫作業、寫範例程式的時候，要用下一段介紹的「編輯器視窗」。

04新增檔案並執行程式

這是接下來每一堂課都會用到的流程：

步驟操作
1在 Shell 視窗選單列點 File → New File（快捷鍵 Ctrl+N），會開啟一個空白的編輯器視窗
2在編輯器裡輸入（或貼上）這一課要練習的程式碼
3按 Ctrl+S 存檔，檔名用英文與數字命名，例如 unit01.py
4選單列點 Run → Run Module，或直接按 F5 執行程式
5切回 Shell 視窗，就會看到程式的執行結果

🖼️ 圖片待補 編輯器裡寫好程式碼，準備存檔的畫面
🖼️ 圖片待補 按 F5（Run Module）後，Shell 顯示執行結果的畫面

05幾個小提醒

⚠ 存檔前要注意這幾件事

檔名不要用中文、空白或特殊符號，用英文、數字、底線就好（例如 unit01.py，不要用 單元01.py）；存檔位置建議固定放在一個容易找到的資料夾（例如桌面新增一個「演算法」資料夾），方便之後找檔案、交作業。

💡 執行前記得先存檔

如果程式碼改過還沒存檔就按 F5，IDLE 通常會自動跳出存檔視窗——看到就直接存檔即可，不用緊張。之後每次改完程式碼，養成先按 Ctrl+S 再執行的習慣。
