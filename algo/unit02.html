流程圖的表示方法

流程圖是用圖形把演算法畫出來的方式。這一單元直接拿你們高一 Python 課寫過的程式碼，練習畫成對應的流程圖。

🎯 學習目標

  • 認識六種常用流程圖符號的名稱與用途
  • 能把已經會寫的 Python 程式碼，反推畫成流程圖
  • 理解循序、選擇、重複三種結構在流程圖上的畫法
💻 如何執行這些程式？

每個範例右上角有 ⧉ 複製 按鈕，點一下複製程式碼，貼到你電腦上的 IDLE（Python 內建的編輯器）就能執行看看結果。還不熟悉 IDLE 怎麼開、怎麼操作的話，可以先看單元 01b：IDLE 操作入門。

流程圖是用「圖形」把演算法的每一步畫出來，最大的好處是不用寫程式語法、任何人都看得懂邏輯。這一單元我們會用一個新角度來學：直接拿你們高一 Python 課寫過的程式碼，練習把它畫成流程圖——因為程式邏輯你們已經會了，這裡只是換一種方式表達同樣的邏輯。

02循序結構：由上而下依序執行

這段程式碼你們高一應該寫過：輸入半徑、算面積、輸出結果，一行一行由上往下執行，沒有任何分支或迴圈。我們把它畫成流程圖，會發現每一行程式碼剛好對應流程圖的一個方塊，順序完全一樣。

💻 程式碼

計算圓面積 
r = float(input("請輸入圓的半徑："))
area = 3.14159 * r * r
print("圓面積是：", area)

    cout << "圓面積是：" << area << endl;
    return 0;
}

03選擇結構：把 if / else 畫成流程圖

這是你們高一學過的 if / else。流程圖用「決策符號（菱形）」來畫分支：菱形裡面寫判斷條件，「是 True」走一邊、「否 False」走另一邊，兩條路最後會再合併，繼續往下走。

💻 程式碼

判斷奇偶數 
n = int(input("請輸入一個整數："))
if n % 2 == 0:
    print("偶數")
else:
    print("奇數")
#include <iostream>
using namespace std;
int main(){
    int n;
    cout << "請輸入一個整數：";
    cin >> n;
    if (n % 2 == 0) cout << "偶數" << endl;
    else cout << "奇數" << endl;
    return 0;
}

開始
↓
輸入 n
↓
n % 2 == 0 ?
是 True
輸出「偶數」
否 False
輸出「奇數」
↓
結束

04重複結構：把 while 畫成流程圖

重複結構有「前判斷式」跟「後判斷式」兩種：前判斷式（while）先判斷條件，成立才執行，可能一次都不執行；後判斷式（do-while）先執行一次，再判斷是否要重複，至少會執行一次。Python 沒有內建 do-while 語法，通常用 while True + break 來模擬。

💻 程式碼

用 while 印出 1 到 5 
i = 1
while i <= 5:
    print(i)
    i += 1
#include <iostream>
using namespace std;
int main(){
    int i = 1;
    while (i <= 5){
        cout << i << endl;
        i++;
    }
    return 0;
}

📊 畫成流程圖

⚠ 流程圖裡「回到判斷之前」怎麼畫

重複結構畫完之後，箭頭要從最後一步「繞回」判斷符號之前，這條回頭的箭頭就是迴圈的關鍵——沒有畫這條線，就變成選擇結構而不是重複結構了。

05課後作業：自己畫畫看

📝 作業一：練習用（畫完可以自己核對）

請把下面這段程式碼，畫成流程圖（可以先畫在紙上或習作本上）：

作業一：奇偶數標記 
for i in range(1, 11):
    if i % 2 == 0:
        print(i, "偶數")
    else:
        print(i, "奇數")

▸ 畫完了嗎？點我核對步驟

你的流程圖應該包含這些步驟，順序是：

① 開始 → ② i = 1 → ③ 判斷「i ≤ 10 ?」→ 是的話進到 ④，否的話跳到 ⑦
④ 判斷「i % 2 == 0 ?」→ 是的話輸出「i 偶數」，否的話輸出「i 奇數」
⑤ i = i + 1 → ⑥ 回到步驟 ③ 重新判斷（這是一個迴圈套判斷的結構）
⑦ 結束

重點：這一題裡面，「重複結構」裡面又包了一層「選擇結構」——這種巢狀畫法，是這一題最容易漏掉線條的地方，畫的時候要特別注意「判斷完之後要繞回哪裡」。
