演算法(二) 選擇排序

選擇排序：每一輪從剩下的資料裡找出最小值，換到前面。跟氣泡排序比較次數一樣多，但交換次數少很多。

  • 能自己用 Python／C++ 寫出選擇排序
  • 能比較選擇排序與氣泡排序的異同

01選擇排序 Selection Sort

規則：每一輪都從「還沒排好」的範圍裡，找出最小值，換到最前面。跟氣泡排序不同的地方是——選擇排序每一輪「只交換一次」，氣泡排序每一輪可能交換很多次。

selection_sort.py／.cpp 
list1 = [5, 3, 1, 4, 2]
for i in range(len(list1) - 1):
    min_idx = i
    for j in range(i + 1, len(list1)):
        if list1[j] < list1[min_idx]:
            min_idx = j
    list1[min_idx], list1[i] = list1[i], list1[min_idx]
print(list1)
#include <iostream>
using namespace std;
int main(){
    int arr[5] = {5, 3, 1, 4, 2};
    for (int i = 0; i < 5; i++){
        int minIdx = i;
        for (int j = i+1; j < 5; j++){
            if (arr[j] < arr[minIdx]) minIdx = j;
        }
        int tmp = arr[i]; arr[i] = arr[minIdx]; arr[minIdx] = tmp;
    }
    for (int j = 0; j < 5; j++) cout << arr[j] << " ";
    cout << endl;
    return 0;
}

02手動追蹤一次：[5, 3, 1, 4, 2]

輪次 i找到的最小值位置交換後的陣列
i=0index 2（值 1）[1, 3, 5, 4, 2]
i=1index 4（值 2）[1, 2, 5, 4, 3]
i=2index 4（值 3）[1, 2, 3, 4, 5]
i=3index 3（值 4）[1, 2, 3, 4, 5]（沒變化）

03時間複雜度與跟氣泡排序的差異

選擇排序氣泡排序
比較次數O(n²)（固定，不管資料順序）O(n²)（最壞），O(n)（已排序時，加優化）
交換次數最多 O(n)（每輪最多一次）O(n²)（可能很多次）
穩定性不穩定穩定
💡 選擇排序什麼時候比較划算？

如果「交換」這個動作成本很高（例如交換的是很大的資料、或是寫入硬碟很慢），選擇排序因為交換次數少，會比氣泡排序更有優勢，即使比較次數一樣多。
