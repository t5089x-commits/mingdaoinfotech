APCS 是什麼？學期地圖

認識檢測架構、題本範圍，以及這學期的學習地圖

🎯 學習目標

  • 知道 APCS 是什麼、成績可以用在哪裡
  • 認識「程式識讀」與「程式實作」兩科的題型與配分
  • 認識初級／中級／中高級／高級四個題本的範圍
  • 清楚這學期（目標：中級）與下學期（挑戰中高級以上）的規劃

01為什麼要準備 APCS？

APCS（Advanced Placement Computer Science，大學程式設計先修檢測）是由臺灣師範大學資訊工程系主辦的線上檢測，用來衡量高中生的程式設計與運算思維能力。官方網站： apcs.csie.ntnu.edu.tw ↗， 最新的簡章、報名期程、歷屆試題都請以官網公告為準。

🎓升學用途

成績可以用在大學特殊選才、繁星推薦、申請入學等管道的備審／加分項目，是很多資訊相關科系看重的指標。

🧠檢驗運算思維

題目不是背語法，而是真的要「看懂問題、拆解問題、寫出程式解決問題」，跟我們平常練的思考方式一致。

🐍延續我們學過的 Python

高一資訊科技已經打好 Python 基礎；這門課就是把同一套語言，練到能應付 APCS 的題型與難度。

💡 老師的話

這門課的教材延續高一資訊科技的 Python 內容，用一樣的語言、一樣的教學方式，只是把深度往上加、加入更多 APCS 風格的題目。已經學過的同學會覺得很熟悉；沒學過的同學，這裡也會把基礎再帶過一次。

02檢測架構：程式識讀 ＋ 程式實作

APCS 分成兩個科目，可以只考一科，也可以兩科都考：

科目題型 ／ 配分考什麼
程式識讀 單選題
滿分 100 分
電腦自動評分，不涉及主觀
  • 程式運行追蹤（code tracing）：給一段程式，問跑完之後變數是多少
  • 程式填空（code completion）：程式缺一段，選出正確的填法
  • 程式測試與除錯（testing / debugging）：找出程式哪裡錯、哪個測資會爆
  • 程式效能分析（performance）：比較不同寫法誰比較快、比較省資源
  • 解析計算邏輯：不一定用程式碼呈現，考的是邏輯拆解能力
程式實作 撰寫完整程式或副程式
滿分 300 分
電腦自動評分		 可自選 C、C++、Java、Python 撰寫；我們課堂上、練習與範例一律用 Python。
🔎 「程式識讀」聽起來抽象？換句話說……

程式識讀考的其實就是「你在腦中能不能像電腦一樣，一行一行把程式跑過一遍」——這正是我們每個單元的課堂練習＋顯示解答在訓練的能力。多練「追蹤程式」，程式識讀就會越來越上手。

03四個題本：範圍一路往上疊加

APCS 依難度分成四個題本，範圍是累加的：中級包含初級的能力、中高級包含中級……以此類推，越後面的題本並不是「換一套全新的東西」，而是「在前一級的基礎上，再多學一些工具」。

題本著重能力檢測範圍
初級 基礎程式設計能力：用變數存資料、選擇結構做邏輯判斷、迴圈處理重複性任務 輸入與輸出・算術／邏輯／位元運算・條件判斷與迴圈
中級 序列型資料結構運用能力：用陣列或串列儲存與處理資料，能做文字處理與流程模擬 陣列（arrays）・字元（character）・字串（string）
中高級 基礎資料結構運用能力：能用基礎資料結構與演算思維解決問題 函式與遞迴・佇列／堆疊・簡單樹（如二元樹）・簡單圖（如網格）・枚舉／資料遍歷・搜尋（二分搜尋、DFS）
高級 基礎演算法運用能力：具備複雜度分析能力，能有效率地解決問題 樹／圖・動態規劃（DP）・分治法・貪心法則

✅初級 ＋ 中級

這學期的主戰場。把變數、運算子、條件、迴圈練到穩，再把陣列、字元、字串練到能上場挑戰中級。

🔜函式（中高級的一部分）

函式正式來說屬於「中高級」，但因為它是寫出乾淨程式的基本功，我們提早在單元 7 詳細講——順便替下學期的遞迴打地基。

📗 起點篇：初級打底（單元 1–4）

  • 變數、資料型態與輸出入
  • 運算子大全：算術・比較・邏輯・位元
  • 條件判斷與迴圈

🎯 挑戰篇：邁向中級（單元 5–8）

  • 陣列與串列（List）
  • 字元與字串（String）
  • 函式使用規則大全（附遞迴暖身）
  • 綜合實戰演練與下學期預告
📅 下學期預告

如果下學期繼續修 APCS，我們會接著把中高級到高級的內容講深：遞迴（recursion）、佇列與堆疊（queue／stack）、樹與圖的基本操作、二分搜尋與 DFS，一路往上到動態規劃、分治法、貪心法則——目標挑戰中高級以上的題本。

✏️ 課堂練習：猜猜看屬於哪個題本？

看看下面三個題目的敘述，猜猜看它們各自最接近哪一個題本？

  1. 「輸入一段英文句子，計算裡面總共有幾個母音字母。」
  2. 「輸入一個整數 n，用迴圈判斷 n 是不是質數。」
  3. 「給一棵二元樹，用遞迴計算樹的高度。」
▶ 顯示解答
  1. 中級——需要走訪字串裡的每個字元、判斷字元是否符合條件，屬於「字元／字串」的文字處理。
  2. 初級——只需要迴圈搭配條件判斷，不需要陣列或字串。
  3. 中高級——用到「樹」這種資料結構，還要搭配「遞迴」，超出中級範圍。
