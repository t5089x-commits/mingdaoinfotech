函式使用規則大全

正式來說屬於中高級範圍，但值得提早練熟——也是下學期遞迴的地基

🎯 學習目標

  • 熟悉函式定義與呼叫的完整語法規則
  • 搞懂四種參數規則：位置參數、預設值、關鍵字參數、不定量參數
  • 理解 return 的行為：單一回傳、多重回傳、不寫 return 會怎樣
  • 分清楚區域變數、全域變數，以及 global 關鍵字的用途
  • 認識常見的函式陷阱，並搶先看一眼「遞迴」長什麼樣子

01為什麼函式值得提早學？

函式（function）正式列在 APCS「中高級」的檢測範圍，跟遞迴、佇列、堆疊排在一起。但函式其實是寫出乾淨、可重複使用程式的基本功——中級的陣列、字串題目，只要用函式包裝，程式會更好讀、好除錯。所以我們提早在這裡把函式的規則練熟，一方面現在就能寫出更好的程式，一方面也替下學期的遞迴打好地基。

python 
def is_even(n):
    return n % 2 == 0

nums = [3, 8, 15, 24, 7]
for x in nums:
    if is_even(x):
        print(x, "是偶數")

02定義與呼叫的語法規則

  • 用 def 開頭，接函式名稱、括號裡放參數，最後一定要有冒號 :
  • 函式主體要縮排（通常 4 個空格），縮排結束就代表函式定義結束
  • 函式必須先定義、才能呼叫——Python 是由上往下讀程式的，呼叫寫在定義前面會出錯
  • 呼叫函式時，參數的順序、個數要對應（除非用了關鍵字參數，見下一節）
python 
def greet(name):        # 定義：name 是「參數」
    print(f"哈囉，{name}！")

greet("陳老師")           # 呼叫：把 "陳老師" 傳給 name
greet("APCS")             # 同一個函式可以重複呼叫，傳不同的值

03參數規則大全

① 位置參數（positional）——最基本的方式

python 
def rect_area(w, h):
    return w * h

print(rect_area(3, 5))   # 15　←　w=3, h=5（按「順序」對應）
print(rect_area(5, 3))   # 15　←　剛好結果一樣，但 w、h 對調了！

② 預設參數值（default value）

參數可以給預設值，呼叫時不傳這個參數就會用預設值。規則：有預設值的參數，一定要放在沒有預設值的參數後面。

python 
def power(base, exp=2):     # exp 預設是 2（平方）
    return base ** exp

print(power(5))        # 25　←　沒傳 exp，用預設值 2
print(power(5, 3))      # 125　←　傳了 exp=3，蓋過預設值

# def bad(a=1, b):    # ❌ 錯誤！有預設值的 a 不能放在沒預設值的 b 前面
#     ...

③ 關鍵字參數（keyword argument）

呼叫時用 參數名=值 指定，可以不照順序傳、也能讓程式碼更清楚看得懂每個值的意思：

python 
def rect_area(w, h):
    return w * h

print(rect_area(w=3, h=5))    # 15
print(rect_area(h=5, w=3))    # 15　←　用關鍵字參數，順序對調也沒差
print(rect_area(3, h=5))       # 15　←　位置參數和關鍵字參數可以混用（位置的要放前面）

④ 不定量參數（*args）

不知道呼叫時會傳幾個值進來，可以用 *args 收成一個 tuple：

python 
def my_sum(*args):     # args 會是一個 tuple，裝所有傳進來的值
    total = 0
    for x in args:
        total += x
    return total

print(my_sum(1, 2, 3))         # 6
print(my_sum(10, 20, 30, 40))   # 100
print(my_sum())                  # 0（沒傳也可以）
🔎 名字不是重點，* 才是關鍵

*args 的 args 只是慣用的命名，寫成 *nums 效果一樣——真正讓 Python「把多個值收成一個 tuple」的是參數名前面的那個 *。

⑤ 傳參數時：不可變 vs 可變型態，行為不一樣

python 
def add_one(n):        # n 是 int（不可變）
    n += 1
    return n

x = 5
print(add_one(x))    # 6
print(x)               # 5　←　x 本身沒被改變

def add_item(lst):     # lst 是 list（可變）
    lst.append(99)      # 直接修改「傳進來的那個」list 本身

y = [1, 2, 3]
add_item(y)
print(y)                # [1, 2, 3, 99]　←　y 被函式改變了！
⚠ 這是 APCS 除錯題最愛考的觀念

數字、字串是不可變（immutable）型態，傳進函式後在函式裡怎麼改，都不會影響外面的原始變數。但 list 是可變（mutable）型態，函式拿到的是「同一個 list」，在函式裡用 .append()、[i]= 這種直接修改內容的操作，會反映到外面。

04回傳值（return）的規則

  • return 執行到就立刻結束函式，後面的程式碼不會再執行
  • 沒有寫 return，或 return 後面沒接值，函式會回傳 None
  • return 可以一次回傳多個值（其實是包成一個 tuple）
python 
def classify(n):
    if n > 0:
        return "正數"
    if n < 0:
        return "負數"
    return "零"          # 前兩個 return 都沒觸發才會跑到這行

print(classify(5))    # 正數
print(classify(-3))    # 負數

def no_return(n):
    print(n * 2)          # 只是印出來，沒有 return
result = no_return(5)      # 10（print 的輸出）
print(result)                # None　←　函式沒 return，回傳值是 None

def min_max(nums):
    return min(nums), max(nums)   # 一次回傳兩個值

lo, hi = min_max([4, 8, 1, 9, 3])   # 用兩個變數「解包」接住
print(lo, hi)                          # 1 9
🔎 多重回傳的本質：其實是一個 tuple

return lo, hi 其實回傳的是 (lo, hi) 這個 tuple；a, b = min_max(...) 則是用「解包（unpacking）」把 tuple 拆開分別存進兩個變數。如果只用一個變數接，r = min_max(nums)，r 就會是整個 tuple (1, 9)。

05區域變數與全域變數

函式裡面定義（包括參數）的是區域變數（local），只在函式執行期間存在；函式外面定義的是全域變數（global），整個程式都看得到。

python 
score = 100           # 全域變數

def show():
    msg = "函式內部"     # 區域變數，只存在於 show() 執行期間
    print(msg, score)     # 函式裡「可以讀」全域變數

show()
print(score)             # 100
# print(msg)             # ❌ NameError：msg 只在 show() 裡面存在

def change_score():
    score = 0             # ⚠ 這是「新建立」一個區域變數 score，不是改外面的！
    print("函式內：", score)

change_score()
print("函式外：", score)   # 100　←　外面的 score 完全沒被動到

如果真的要在函式裡修改全域變數，要用 global 關鍵字明確宣告：

python 
score = 100

def add_bonus():
    global score      # 宣告：接下來的 score 指的是「外面那個全域變數」
    score += 10

add_bonus()
print(score)   # 110　←　這次真的被改變了
⚠ 別濫用 global

能不用 global 就盡量不用——用參數傳進去、用 return 傳回來，程式邏輯會更清楚，也比較不容易因為「函式偷偷改了全域變數」而產生難以追蹤的錯誤。global 是「規則要知道」，不代表要常常拿來用。

07搶先看：遞迴（recursion）長什麼樣子

遞迴是「函式呼叫自己」，正式屬於下學期的中高級範圍，這裡先用階乘（factorial）搶先感受一下。每次呼叫都要有基準情況（base case）讓它停下來，否則會無限呼叫下去：

python 
def factorial(n):
    if n == 0:            # 基準情況（base case）：停下來的條件
        return 1
    return n * factorial(n - 1)   # 遞迴呼叫：呼叫自己，問題規模變小（n-1）

print(factorial(4))   # 24　（4×3×2×1）

🔍 factorial(4) 的呼叫過程

  • factorial(4) 要等 factorial(3) 的結果，才能算 4 * factorial(3)
  • factorial(3) 要等 factorial(2)……一路往下，直到
  • factorial(0) 直接回傳 1（base case，不用再往下呼叫）
  • 接著一層一層往回算：1×1=1 → 2×1=2 → 3×2=6 → 4×6=24
📅 下學期會講得更深入

遞迴牽涉到「呼叫堆疊（call stack）」怎麼運作、什麼時候該用遞迴、遞迴和迴圈怎麼互相轉換，這些我們下學期會完整講解，搭配佇列、堆疊、樹狀結構一起練習。這裡只要先知道「函式可以呼叫自己」「一定要有 base case」就夠了。

08常見錯誤整理

錯誤原因
忘記寫 return，卻拿函式結果去用函式回傳 None，後續用 None 做運算會出錯
以為在函式裡改參數，外面的值也會變只有可變型態（list、dict）才會這樣；數字、字串不會
在函式裡直接對全域變數賦值，卻沒加 globalPython 會當成建立一個新的區域變數，外面的全域變數不受影響
有預設值的參數放在沒預設值的參數前面SyntaxError：預設參數一定要放在後面
遞迴忘了寫 base case函式無限呼叫自己，最後 RecursionError

✏️ 課堂練習

  1. 寫函式 bmi(weight, height=170)：height 預設 170（公分），回傳 BMI。分別用「只傳體重」與「兩個都傳」呼叫一次。
  2. 寫函式 stats(nums)，一次回傳這個 list 的總和、最大值、最小值三個值。
  3. 追蹤下面程式，寫出最後 print(y) 會印出什麼：
    y = 10
    def f(y):
        y = y + 5
        return y
    f(y)
    print(y)
▶ 顯示解答
第 1 題參考解 
def bmi(weight, height=170):
    h_m = height / 100
    return weight / (h_m ** 2)

print(bmi(60))         # 用預設身高 170
print(bmi(60, 165))     # 自己指定身高 165
第 2 題參考解 
def stats(nums):
    total = sum(nums)
    mx = max(nums)
    mn = min(nums)
    return total, mx, mn

t, hi, lo = stats([4, 8, 1, 9, 3])
print(t, hi, lo)   # 25 9 1

第 3 題：print(y) 印出 10。f(y) 裡的 y 是函式的參數（區域變數），跟外面的全域變數 y 是不同的東西——int 是不可變型態，函式裡的 y = y + 5 只是改了區域變數，呼叫完之後也沒有用 y = f(y) 把回傳值存回去，所以外面的 y 完全沒變。
