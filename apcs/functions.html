遞迴：階乘n! = n × (n-1)!，終止條件 n == 0

單元 7 附
遞迴：次方a^x = a × a^(x-1)

單元 7 附
遞迴：最大公因數GCD(a, b) = GCD(b, a % b)
def gcd(a, b):
    r = a % b
    if r == 0:
        return b
    return gcd(b, r)
print(gcd(76, 48))

單元 7 附
遞迴：費氏數列f(n) = f(n-1) + f(n-2)
def fib(x):
    if x <= 1:

    return fib(x - 1) + fib(x - 2)

for i in range(n):
    for j in range(m):
        c += 1
print(c)

單元 9 §07
用 head／tail 模擬佇列從 head 取出、放到 tail
Q = [1, 2, 3, 4, 5] + [0] * 10
head, tail = 0, 5
while tail > head + 1:
    v = Q[head]; head += 1
    Q[tail] = v; tail += 1
    head += 1
print(Q[head])
