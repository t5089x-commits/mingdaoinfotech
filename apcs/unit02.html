變數、資料型態與輸出入

資料型態、常數與變數、指定與表達式，以及 input()／print() 的使用

🎯 學習目標

  • 分辨 APCS 常考的資料型態：整數、浮點數、字串、布林值
  • 理解常數、變數、指定、表達式這幾個名詞的意思
  • 會用 input() 讀取使用者輸入，並轉換成需要的型態
  • 會用 print() 與 f-string 格式化輸出結果

01資料型態、常數與變數

程式裡的每一筆資料都有型態（data type），型態決定了這筆資料能做什麼運算。APCS 最常用到的四種型態：

型態Python 名稱範例說明
整數int10、-3沒有小數點的數字
浮點數float3.14、-0.5有小數點的數字
字串str"hello"一串文字，用 " 或 ' 包起來
布林值boolTrue、False只有真／假兩種值，判斷結果常常是它

常數（constant）是「值不會變」的資料，例如 3.14159 這個圓周率；變數（variable）是一個有名字、可以裝資料、值可以改變的「箱子」。把值放進變數，叫做指定（assignment），用 = 這個符號：

python 
pi = 3.14159        # 把常數 3.14159 指定給變數 pi
r = 5                # 半徑
area = pi * r ** 2   # area 是一個「表達式」算出來的結果
print(area)          # 78.53975

print(type(pi))      # <class 'float'>
print(type(r))       # <class 'int'>
print(type(area))    # <class 'float'>
🔎 什麼是「表達式」（expression）？

pi * r ** 2 這種「會算出一個值」的式子就叫表達式。表達式可以是一個數字（5）、一個變數（r），也可以是好幾個變數和運算子組合起來的算式；area = pi * r ** 2 這整行則叫做指定敘述（assignment statement）：先算右邊的表達式，再把結果存進左邊的變數。

變數命名規則

  • 只能用英文字母、數字、底線 _，而且不能用數字開頭（score1 ✅、1score ❌）
  • 大小寫視為不同變數（Score 和 score 是兩個變數）
  • 不能用 Python 保留字，例如 if、for、return
  • 建議取看得懂意思的名字，例如用 total 而不是 t

02型別轉換

不同型態之間常常需要互相轉換，尤其 input() 讀進來的資料一律是字串，要自己轉成數字才能運算：

python 
a = "10"
b = int(a)      # 字串 → 整數：10
c = float(a)    # 字串 → 浮點數：10.0
d = str(99)     # 數字 → 字串："99"

print(int(3.9))     # 3　（float → int 直接捨去小數，不是四捨五入！）
print(bool(0))       # False
print(bool(5))       # True（0 是 False，其他數字都是 True）
⚠ 常見陷阱：int() 是「捨去」不是「四捨五入」

int(3.9) 的結果是 3，不是 4！int() 轉換浮點數時是直接捨去小數部分。如果要四捨五入，要用 round()：round(3.9) 才是 4。這是程式識讀考「程式追蹤」很愛考的細節。

03輸入：input()

input() 讓程式暫停，等使用者從鍵盤輸入資料，按下 Enter 後把輸入的內容當成字串回傳。

python 
name = input("請輸入姓名：")
age = int(input("請輸入年齡："))     # 讀進來是字串，馬上轉成 int
print(name, "明年", age + 1, "歲")
💡 常用寫法：邊讀邊轉型

int(input(...)) 是 APCS 題目最常見的寫法：用 input() 讀進字串，馬上包一層 int() 或 float() 轉成數字，一行搞定。

04輸出：print() 與 f-string

print() 可以一次印多個值，預設用空白隔開、最後自動換行；也可以用 sep、end 參數調整：

python 
print("a", "b", "c")               # a b c
print("a", "b", "c", sep="-")      # a-b-c
print("a", end="")                  # 不換行
print("b")                          # 接在同一行 → ab

格式化輸出：f-string

在字串前面加一個 f，就能在 { } 裡直接放變數或表達式，非常適合組合輸出結果：

python 
name = "阿翔"
score = 87.6666
print(f"{name} 的分數是 {score}")            # 阿翔 的分數是 87.6666
print(f"{name} 的分數是 {score:.1f}")        # 保留 1 位小數 → 87.7
print(f"{score:6.1f}")                        # 總寬度 6，靠右對齊 →   87.7
📌 {值:.1f} 這種寫法要記熟

:.1f 表示「格式化成浮點數，保留 1 位小數」，APCS 程式實作很常需要輸出「到小數點後幾位」的答案，這個語法一定要練到看到就會用。

✏️ 課堂練習

  1. 寫程式讀入身高（公分）與體重（公斤），計算並輸出 BMI（體重 / (身高公尺)²），四捨五入到小數點後 2 位。
  2. print(int("7") + int("3")) 和 print("7" + "3") 的結果分別是什麼？為什麼不一樣？
  3. x = 9.8，print(int(x)) 和 print(round(x)) 分別輸出什麼？
▶ 顯示解答
第 1 題參考解 
h = float(input("身高(cm):"))
w = float(input("體重(kg):"))
bmi = w / ((h / 100) ** 2)
print(f"BMI: {bmi:.2f}")
  1. int("7") + int("3") 是數字相加 → 10；"7" + "3" 是字串接起來 → "73"。同樣是 +，作用在數字和字串上意義完全不同。
  2. int(9.8) 是捨去小數 → 9；round(9.8) 是四捨五入 → 10。
