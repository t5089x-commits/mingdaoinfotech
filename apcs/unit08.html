01綜合實戰一：成績統計小工具

輸入若干學生的分數（用空白分隔的一行），計算並輸出：總人數、平均分數（取小數點後 2 位）、最高分、最低分，以及及格（≥60）人數。

score_stats.py 
def stats(scores):
    total = sum(scores)
    avg = total / len(scores)
    hi = max(scores)
    lo = min(scores)
    passed = 0
    for s in scores:
        if s >= 60:
            passed += 1
    return avg, hi, lo, passed

line = input("請輸入分數（用空白分隔）：")
scores = [int(x) for x in line.split()]   # 字串切割後逐一轉成整數

avg, hi, lo, passed = stats(scores)
print(f"總人數：{len(scores)}")
print(f"平均分數：{avg:.2f}")
print(f"最高分：{hi}　最低分：{lo}")
print(f"及格人數：{passed}")
🔎 [int(x) for x in line.split()] 是什麼？

這叫串列生成式（list comprehension），是「for 迴圈 ＋ 建立新 list」的精簡寫法，等同： scores = []
for x in line.split(): scores.append(int(x))
APCS 題目常常要「一行讀進多個數字」，這個寫法非常實用，值得記起來。

02綜合實戰二：檢查密碼強度

輸入一個字串當作密碼，判斷是否符合：長度至少 8、同時包含英文字母與數字。符合輸出 "通過"，否則輸出 "不通過"。

check_password.py 
def is_strong(pw):
    if len(pw) < 8:
        return False
    has_alpha = False
    has_digit = False
    for ch in pw:
        if ch.isalpha():
            has_alpha = True
        if ch.isdigit():
            has_digit = True
    return has_alpha and has_digit

pw = input("請輸入密碼：")
print("通過" if is_strong(pw) else "不通過")
💡 a if 條件 else b：三元運算子

這是 if／else 的「單行寫法」：條件成立取 a，不成立取 b。print("通過" if is_strong(pw) else "不通過") 等同： if is_strong(pw): print("通過")
else: print("不通過")，寫法更精簡。

03綜合實戰三：字串加密（凱薩密碼）

把每個英文字母往後移動 k 位（超過 z 就繞回 a），數字與符號不變。這題整合了字元運算（ord/chr）、位元／餘數運算、函式、迴圈與字串組合。

caesar_cipher.py 
def caesar(s, k):
    result = ""
    for ch in s:
        if ch.isupper():
            base = ord('A')
            result += chr((ord(ch) - base + k) % 26 + base)
        elif ch.islower():
            base = ord('a')
            result += chr((ord(ch) - base + k) % 26 + base)
        else:
            result += ch          # 數字、符號、空白原封不動
    return result

msg = input("請輸入訊息：")
k = int(input("請輸入位移量："))
print("加密結果：", caesar(msg, k))
🔎 為什麼要 % 26？

英文字母只有 26 個，(ord(ch) - base + k) % 26 讓位移「超過 z 之後自動繞回 a」——例如 'y' 位移 3：(24 + 3) % 26 = 1，對應回 chr(1 + base) 就是 'b'。這種「繞圈」的除餘技巧，在陣列、字串題目裡非常常見。

  3. 綜合題：輸入一段英文句子，輸出每個單字的第一個字母大寫、其餘小寫（例如 "hello apcs world" → "Hello Apcs World"），並統計句子裡總共有幾個字母（不含空白）。

第 1 題參考解 
def second_max(nums):
    first = second = None
    for x in nums:
        if first is None or x > first:
            second = first
            first = x
        elif x != first and (second is None or x > second):
            second = x
    return second

print(second_max([5, 1, 9, 9, 4]))   # 5
第 3 題參考解 
def capitalize_words(s):
    words = s.split()
    result = []
    for w in words:
        result.append(w[0].upper() + w[1:].lower())
    return " ".join(result)

def count_letters(s):
    count = 0
    for ch in s:
        if ch.isalpha():
            count += 1
    return count

sentence = "hello apcs world"
print(capitalize_words(sentence))     # Hello Apcs World
print(count_letters(sentence))          # 14
