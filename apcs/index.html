ℹ️APCS 是什麼？

APCS（Advanced Placement Computer Science）是大學程式設計先修檢測，用來檢定高中生的程式設計與運算思維能力，成績可以用在大學特殊選才、繁星、申請入學等管道的備審或加分。官方網站在 apcs.csie.ntnu.edu.tw ↗， 詳細簡章、報名時間、歷屆試題都以官網公告為準，這裡整理的是這學期上課會用到的重點。

測驗科目題型 / 配分內容
程式識讀 單選題・滿分 100 分
電腦自動評分		 程式運行追蹤（code tracing）、程式填空、程式測試與除錯、程式效能分析、解析計算邏輯
程式實作 寫完整程式・滿分 300 分
電腦自動評分		 可自選 C、C++、Java、Python 撰寫；我們課堂上一律用 Python

整份檢測依難度分成四個題本，範圍是一路往上疊加的（中級包含初級的能力、中高級包含中級……以此類推）：

題本著重能力檢測範圍這學期
初級 基礎程式設計能力：用變數存資料、選擇結構做邏輯判斷、迴圈處理重複性任務 輸入與輸出・算術／邏輯／位元運算・條件判斷與迴圈 ✅ 主力範圍
中級 序列型資料結構運用能力：用陣列／串列存資料，處理文字與流程模擬 陣列（arrays）・字元（character）・字串（string） 🎯 本學期目標
中高級 基礎資料結構運用能力 函式與遞迴・佇列／堆疊・簡單樹／圖・搜尋（二分搜尋、DFS） 🔜 函式先暖身，其餘下學期
高級 基礎演算法運用能力，具備複雜度分析能力 樹／圖・動態規劃・分治法・貪心法則 📅 下學期深入
🎯 這學期的目標

把初級的內容練到穩，並把中級（陣列、字元、字串）練到能上場挑戰。函式（function）雖然正式列在「中高級」範圍，但因為函式是寫出「乾淨、可重複使用」程式的基本功，我們會提早在單元 7 詳細講——把函式的使用規則練熟，也是替下學期的遞迴打地基。

📅 下學期預告

如果下學期繼續修 APCS，我們會接著把中高級到高級的內容講得更深入：遞迴（recursion）、佇列與堆疊（queue／stack）、樹與圖（tree／graph）的基本操作、二分搜尋與深度優先搜尋（DFS），一路往上到動態規劃（DP）、分治法、貪心法則，目標是挑戰中高級以上的題本。
