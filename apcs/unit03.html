01算術運算子

+ 加、- 減、* 乘、/ 除、% 餘數、// 整數除（商）、** 指數。

python 
a, b = 17, 5
print(a + b)   # 22
print(a - b)   # 12
print(a * b)   # 85
print(a / b)   # 3.4   （/ 一定回傳浮點數）
print(a % b)   # 2     （餘數）
print(a // b)  # 3     （商，往下取整）
print(a ** b)  # 1419857
🔎 % 和 // 是好朋友

任何整數 a、b（b 不為 0），一定滿足 a == (a // b) * b + a % b。// 求「商」、% 求「餘數」，APCS 常考「奇偶判斷」（n % 2 == 0）、「個位數」（n % 10）都是靠它們。

02比較與邏輯運算子

比較運算子的結果一定是布林值：==、!=、>、>=、<、<=。邏輯運算子用來組合多個條件：and（且）、or（或）、not（否定）。

python 
score = 78
print(score >= 60)                          # True
print(score >= 90 or score >= 60)            # True（有一個為真就是 True）
print(score >= 60 and score < 90)            # True（兩個都要為真）
print(not (score >= 60))                     # False

n = 15
print(1 <= n <= 100)                          # Python 可以連續比較，等同 (1<=n) and (n<=100)
aba and ba or b
TrueTrueTrueTrue
TrueFalseFalseTrue
FalseTrueFalseTrue
FalseFalseFalseFalse

真假值：不是只有 True 和 False

放在 if、while、and／or／not 裡的資料，Python 都會把它看成「真」或「假」：0、0.0、空字串 ''、空串列 [] 是假，其他（不是 0 的數、有內容的字串……）都是真。用 bool() 可以查。

哪些是假？ 
print(bool(0), bool(7), bool(-1))      # False True True
print(bool(''), bool('0'), bool(' '))   # False True True（'0' 和空白都是有內容的字串）
print(bool([]), bool([0]))              # False True
▼ 執行結果 False True True False True True False True

and、or 回傳的不是 True／False，是「某一邊的原值」

先別急著背規則，自己猜一題：print(3 and 5) 會印出什麼？

🤔 幾乎每個人的直覺

3 是真、5 也是真，and 又是「兩個都要真」→ 想成「True and True」→ 很自然就猜答案是 True。

😮 其實印出的是 5

不是 True！而且它的型別還是 int（(3 and 5) == True 會得到 False）。關鍵在於：Python 算 and／or 時，是從左到右一個一個判斷，而且會把「最後真正判斷到的那個運算元」整個回傳回來，不會自己幫你轉成 True／False。

把 3 and 5 的判斷過程拆開，就懂為什麼是 5 而不是 True：

  1. and 的意思是「兩個都要真」，所以一定先看左邊：3 → 是真 → 還不能決定（萬一右邊是假，整句就變假了） → 繼續往右看。
  2. 再看右邊：5 → 也是真 → 兩邊都確認完了，就停在這裡 → 回傳最後判斷到的那個值 5。
▶ 先練最單純的：兩邊都是 True／False（按「下一步」逐步判斷）

換成 0 and 5 剛好相反：第一步看左邊 0 → 是假 → and 只要有一邊假、整句就不可能真 → 立刻停住、回傳 0，右邊的 5 連看都不會去看。所以可以濃縮成一句：

📌 一句話規則

and：從左往右，一遇到「假」就停、回傳那個假值；全部都真就回傳最後一個。

or：相反，一遇到「真」就停、回傳那個真值；全部都假就回傳最後一個。

兩邊剛好都是 True／False 時，結果就跟上面的真值表一樣（最後停在哪一個，那個本來就是 True／False）。但只要放的是數字或字串，回傳的就是原本那個值，不一定是 True／False：

運算左邊是真左邊是假
a and b回傳 b回傳 a（右邊不用看）
a or b回傳 a（右邊不用看）回傳 b
and／or 的回傳值 
print(3 and 5)            # 5
print(0 and 5)            # 0
print(3 or 5)             # 3
print('' or 'empty')      # empty
print((2 and 'ok') or 0)  # ok
print(not 0, not 'a')     # True False（not 一定回傳 True／False）

name = ''
print(name or '無名氏')    # 常見用法：空字串時給一個預設值
▼ 執行結果 5 0 3 empty ok True False 無名氏

▶ 進階：放「數字或字串」時，回傳的是「值」

一樣用「下一步」跑跑看——這次兩邊不是 True／False，而是數字。注意回傳的到底是什麼：

▶ 為什麼 3 and 5 回傳 5、而不是 True？

再進階：and／or／not 混在一起

三個邏輯運算子一起出現時，先算 not → 再算 and → 最後才 or（就像先乘除、後加減）：

and／or／not 混用 
print(not True)                 # False
print(not 0)                    # True（0 是假，not 之後變真）
print(True and not False)       # True
print(3 > 2 and 5 < 1)          # False（True and False）
print(0 or 5 and 3)             # 3（先算 5 and 3 = 3，再 0 or 3）
print(not (0 or 0))             # True（0 or 0 = 0 是假，not 變真）
▼ 執行結果 False True True False 3 True
💡 not 跟 and／or 不一樣

not 一定回傳 True 或 False（它只問「真還假」，再給相反的布林值）；但 and／or 回傳的是其中一個運算元本身（可能是數字、字串）。完整的先後順序整理在 單元 9 §03，學期後段準備識讀時一起練。

🔎 右邊不用看＝不會執行

and 左邊是假、or 左邊是真時，右邊根本不會被算（短路）。所以 x != 0 and 10 / x > 1 在 x 是 0 時會直接得到 False，不會發生除以 0 的錯誤。

03位元運算子（APCS 初級範圍）

位元運算子把數字看成二進位，一個 bit 一個 bit 做運算。這是資訊科技數字系統單元學過的二進位概念，官方把它列在初級範圍內，看得懂運算結果就好：

運算子名稱規則範例
&AND兩個 bit 都是 1 才是 10b1100 & 0b1010 → 0b1000（8）
|OR只要有一個 bit 是 1 就是 10b1100 | 0b1010 → 0b1110（14）
^XOR兩個 bit 不同才是 10b1100 ^ 0b1010 → 0b0110（6）
~NOT每個 bit 反過來（結果 = -x-1）~5 → -6
<<左移所有 bit 往左移 n 位，右邊補 0（等於 ×2ⁿ）3 << 2 → 12
>>右移所有 bit 往右移 n 位（等於整數除以 2ⁿ）12 >> 2 → 3
python 
a = 12   # 二進位 1100
b = 10   # 二進位 1010

print(bin(a))     # 0b1100
print(a & b)      # 8   →  1000
print(a | b)      # 14  →  1110
print(a ^ b)      # 6   →  0110
print(a << 1)      # 24  → 11000（左移 1 位＝乘以 2）
print(a >> 2)      # 3   → 0011（右移 2 位＝除以 4，取商）
🔎 位元運算子 vs 邏輯運算子：不要搞混！

&／| 是位元運算，作用在整數的每一個 bit 上；and／or 是邏輯運算，作用在 True／False 這種布林值上，考慮的是「兩個條件成不成立」。3 & 5（結果是 1）和 3 and 5（結果是 5，因為兩者都不是 0，取後面那個）意思完全不一樣，這兩組很容易搞混，看到時要特別注意。

💡 為什麼要學位元運算？

位元運算常用來用一個整數同時記錄很多個開關狀態（例如用 8 個 bit 記錄 8 種權限的開／關），或是快速做「乘 2 的次方」「除 2 的次方」「判斷奇偶」（n & 1 就能判斷 n 是不是奇數）。

04複合指定運算子

把「運算」和「指定」合在一起的簡寫：+=、-=、*=、/=、%=、//=、**=，位元運算也有對應的 &=、|=、^=、<<=、>>=。a += b 就等同 a = a + b。

python 
total = 0
for i in range(1, 6):
    total += i     # total = total + i
print(total)        # 15

flags = 0b0000
flags |= 0b0100     # 開啟第 3 個開關
flags &= ~0b0100    # 再關掉它
print(bin(flags))   # 0b0

✏️ 課堂練習

  1. 13 // 4、13 % 4、2 ** 6 分別是多少？
  2. a = 6（0b0110），b = 3（0b0011），求 a & b、a | b、a ^ b。
  3. 不用 %，改用位元運算判斷一個整數 n 是不是奇數，該怎麼寫？
▶ 顯示解答
  1. 13 // 4 = 3、13 % 4 = 1、2 ** 6 = 64。
  2. 0b0110 & 0b0011 = 0b0010（2）、0b0110 | 0b0011 = 0b0111（7）、0b0110 ^ 0b0011 = 0b0101（5）。
  3. (n & 1) == 1（或直接寫 if n & 1:）：奇數的最後一個 bit 一定是 1，偶數一定是 0。加上括號最不會看錯。
🔎 識讀還會考的運算子細節

負數的 // 與 %（-7 // 2 是 -4）、0 和空字串是「假」、and／or 回傳的是「其中一邊的值」、運算子優先順序（-2 ** 2 是 -4）——這些都整理在 單元 9 §03，學期後段準備識讀時一起練。
