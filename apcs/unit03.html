運算子大全：算術・比較・邏輯・位元

APCS 初級明確會考的四大類運算子，這裡一次補齊

🎯 學習目標

  • 熟悉算術、比較、邏輯運算子與複合指定運算子
  • 認識並會使用位元運算子：AND、OR、XOR、NOT、位移
  • 能判斷一段運算式的運算子優先順序與結果

01算術運算子

+ 加、- 減、* 乘、/ 除、% 餘數、// 整數除（商）、** 指數。

python 
a, b = 17, 5
print(a + b)   # 22
print(a - b)   # 12
print(a * b)   # 85
print(a / b)   # 3.4   （/ 一定回傳浮點數）
print(a % b)   # 2     （餘數）
print(a // b)  # 3     （商，捨去小數）
print(a ** b)  # 1419857
🔎 % 和 // 是好朋友

任何整數 a、b（b 不為 0），一定滿足 a == (a // b) * b + a % b。// 求「商」、% 求「餘數」，APCS 常考「奇偶判斷」（n % 2 == 0）、「個位數」（n % 10）都是靠它們。

02比較與邏輯運算子

比較運算子的結果一定是布林值：==、!=、>、>=、<、<=。邏輯運算子用來組合多個條件：and（且）、or（或）、not（否定）。

python 
score = 78
print(score >= 60)                          # True
print(score >= 90 or score >= 60)            # True（有一個為真就是 True）
print(score >= 60 and score < 90)            # True（兩個都要為真）
print(not (score >= 60))                     # False

n = 15
print(1 <= n <= 100)                          # Python 可以連續比較，等同 (1<=n) and (n<=100)

03位元運算子（APCS 初級必考）

位元運算子把數字看成二進位，一個 bit 一個 bit 做運算。這是資訊科技數字系統單元學過的二進位概念，在 APCS 會直接考它的運算結果：

運算子名稱規則範例
&AND兩個 bit 都是 1 才是 10b1100 & 0b1010 → 0b1000（8）
|OR只要有一個 bit 是 1 就是 10b1100 | 0b1010 → 0b1110（14）
^XOR兩個 bit 不同才是 10b1100 ^ 0b1010 → 0b0110（6）
~NOT每個 bit 反過來（結果 = -x-1）~5 → -6
<<左移所有 bit 往左移 n 位，右邊補 0（等於 ×2ⁿ）3 << 2 → 12
>>右移所有 bit 往右移 n 位（等於整數除以 2ⁿ）12 >> 2 → 3
python 
a = 12   # 二進位 1100
b = 10   # 二進位 1010

print(bin(a))     # 0b1100
print(a & b)      # 8   →  1000
print(a | b)      # 14  →  1110
print(a ^ b)      # 6   →  0110
print(a << 1)      # 24  → 11000（左移 1 位＝乘以 2）
print(a >> 2)      # 3   → 0011（右移 2 位＝除以 4，取商）
🔎 位元運算子 vs 邏輯運算子：不要搞混！

&／| 是位元運算，作用在整數的每一個 bit 上；and／or 是邏輯運算，作用在 True／False 這種布林值上，考慮的是「兩個條件成不成立」。3 & 5（結果是 1）和 3 and 5（結果是 5，因為兩者都不是 0，取後面那個）意思完全不一樣，這是程式識讀很愛出的陷阱題。

💡 為什麼要學位元運算？

位元運算常用來用一個整數同時記錄很多個開關狀態（例如用 8 個 bit 記錄 8 種權限的開／關），或是快速做「乘 2 的次方」「除 2 的次方」「判斷奇偶」（n & 1 就能判斷 n 是不是奇數）。

04複合指定運算子

把「運算」和「指定」合在一起的簡寫：+=、-=、*=、/=、%=、//=、**=，位元運算也有對應的 &=、|=、^=、<<=、>>=。a += b 就等同 a = a + b。

python 
total = 0
for i in range(1, 6):
    total += i     # total = total + i
print(total)        # 15

flags = 0b0000
flags |= 0b0100     # 開啟第 3 個開關
flags &= ~0b0100    # 再關掉它
print(bin(flags))   # 0b0

✏️ 課堂練習

  1. 13 // 4、13 % 4、2 ** 6 分別是多少？
  2. a = 6（0b0110），b = 3（0b0011），求 a & b、a | b、a ^ b。
  3. 不用 %，改用位元運算判斷一個整數 n 是不是奇數，該怎麼寫？
▶ 顯示解答
  1. 13 // 4 = 3、13 % 4 = 1、2 ** 6 = 64。
  2. 0b0110 & 0b0011 = 0b0010（2）、0b0110 | 0b0011 = 0b0111（7）、0b0110 ^ 0b0011 = 0b0101（5）。
  3. n & 1 == 1：奇數的最後一個 bit 一定是 1，偶數一定是 0。
