輸入技巧與常用函式：split()／map()

APCS 實作題最常見的輸入方式，加上這學期會一直用到的內建函式，這裡一次補齊

🎯 學習目標

  • 知道 APCS 程式實作最常見的輸入格式：「一行裡有好幾個數字，用空白隔開」
  • 會用 split() 把一行文字切開，並理解切開後還是字串
  • 會用 map(int, ...) 批次轉型態，寫出 list(map(int, input().split())) 這個最常見的一行寫法
  • 認識這學期會一直用到的內建函式對照表：sorted()、sum()、zip()、enumerate() 等

01APCS 最常見的輸入格式

APCS 實作題最常見的輸入方式，是「一行裡有好幾個數字，用空白隔開」，例如輸入 3 5 7 9。這種情況要用 split() 和 map() 這組技巧——這學期後面每一題只要牽涉到「一次讀好幾個數字」，幾乎都會用到：

split()：把一行文字依空白切開 
line = input()          # 假設使用者輸入：3 5 7 9
parts = line.split()      # 依空白切開 → ['3', '5', '7', '9']
print(parts)               # 注意：這些還是「字串」，不是數字！
print(parts[0] + parts[1])  # '3' + '5' → '35'（字串相加是接在一起，不是數學運算）
⚠ 切開之後，還是字串！

split() 回傳的 list 裡，每一個元素都還是字串，不是數字。如果直接拿去做加法，Python 不會報錯，而是會把字串「接在一起」，例如 '3' + '5' 的結果是 '35'，不是 8。這是初學者很容易忽略、但又不會報錯的陷阱，跟單元 2 學過的 input() 一樣，記得要先轉型。

02map()：把切開的每一段文字都轉成數字

map(f, x) 會把函式 f 套用到 x 裡的每一個元素上，回傳一個新的結果。搭配 int 一起用，就能把一整排字串「一次」轉成數字：

map(int, ...)：批次轉換型態 
line = "3 5 7 9"
parts = line.split()          # ['3', '5', '7', '9']（字串）
nums = list(map(int, parts))    # 把每個字串都轉成 int → [3, 4, 7, 9]
print(nums)
print(sum(nums))                  # 21，這次是真的數學運算

# APCS 最常見的寫法，直接一行搞定：
nums = list(map(int, input().split()))
print(nums)
📌 這一行程式碼，這學期會一直看到

nums = list(map(int, input().split())) 這行等於做了三件事：input() 讀一行文字 → .split() 依空白切開 → map(int, ...) 把每一段都轉成整數，最後用 list(...) 包成一個 list。這個「一行讀多個數字」的寫法值得直接背起來。

03split(sep)：依指定符號切開

split() 不寫參數預設依「空白」切開；如果資料是用逗號或其他符號分隔（例如處理 CSV 這類資料），可以直接指定分隔符號：

依指定符號切開 
line = "小明,88,92,76"
parts = line.split(",")     # 依逗號切開 → ['小明', '88', '92', '76']
name = parts[0]
scores = list(map(int, parts[1:]))   # 第 0 個是名字，其餘轉成數字
print(name, scores, sum(scores))

04這學期會一直用到的內建函式對照表

下面這些函式，這學期後面每一個單元幾乎都會用到——先在這裡認識一次，之後看到就不會陌生：

函式用途範例
len(x)取得長度（字串、list 都可以用）len([1,2,3]) → 3
x.append(v)在 list 尾端加入一個元素a=[1,2]; a.append(3) → [1,2,3]
x.pop()從 list 尾端取出並刪除一個元素a=[1,2,3]; a.pop() → 3
deque.popleft()從 deque 前端取出並刪除（佇列常用，下學期會用到）下學期單元：佇列與堆疊
"..".split()把字串依空白（或指定符號）切成 list"3 5 7".split() → ['3','5','7']
"-".join(x)把 list 的元素接成一個字串，中間插入指定符號"-".join(['a','b']) → 'a-b'
map(f, x)對 x 裡的每個元素都套用函式 flist(map(int,['1','2'])) → [1, 2]
set(x)把 list 轉成集合（自動去除重複）set([1,1,2]) → {1, 2}
list(x)把其他型態轉成 listlist(range(3)) → [0, 1, 2]
sorted(x)回傳排序好的「新」list（原本的不會被改變）sorted([3,1,2]) → [1, 2, 3]
x.sort()直接把 list 原地排序（沒有回傳值）a=[3,1,2]; a.sort() → a 變 [1,2,3]
sum(x)加總 list（或其他可迭代物件）裡所有的值sum([1,2,3]) → 6
zip(a, b)把兩個 list 一一配對起來list(zip([1,2],['a','b'])) → [(1,'a'), (2,'b')]
enumerate(x)走訪的同時取得「索引」和「值」for i, v in enumerate(['a','b']):
round(x, n)四捨五入到小數點第 n 位round(3.14159, 2) → 3.14
"x".isalpha()判斷字串是否全部是英文字母"ABC".isalpha() → True
🔎 sorted(x) 跟 x.sort() 差在哪？

sorted(x) 是內建函式，會回傳一份「排序好的新 list」，原本的 x 不會被改變；x.sort() 是 list 的方法，直接把 x 原地排序、沒有回傳值。如果題目要求「保留原本順序、另外輸出排序結果」，就要用 sorted()；如果只是要把資料排好備用，用 x.sort() 更省記憶體。

✏️ 課堂練習

  1. 讀入一行以空白分隔的整數（例如 12 45 7 89 23），輸出這些數字的總和與最大值。
  2. 讀入一行以逗號分隔的姓名（例如 小明,小華,小美），輸出總共有幾個名字，並依字母排序後印出（原本的順序不要被改變）。
  3. 追蹤思考：如果忘記寫 map(int, ...)，直接對 input().split() 的結果做 sum()，會發生什麼事？為什麼？
▶ 顯示解答
第 1 題參考解 
nums = list(map(int, input().split()))
print("總和：", sum(nums))
print("最大值：", max(nums))
第 2 題參考解 
names = input().split(",")
print("共有", len(names), "個名字")
print(sorted(names))     # 用 sorted()，names 原本的順序不會被改變
print(names)               # 印出來確認：names 本身還是原來的順序

第 3 題：不會報錯，但答案會是錯的——sum() 要求每個元素都能用 + 相加，字串之間的 + 是「接在一起」，所以 sum(['3','5']) 這種寫法其實會直接 TypeError（sum() 預設從整數 0 開始加，0 + '3' 型態不合會報錯）。要先用 map(int, ...) 把每個字串都轉成數字，sum() 才能正確加總。
