01認識 List

C、C++、Java 裡的陣列（array），在 Python 裡最常用串列（list）來實作——list 可以裝一整排資料，用索引（index）存取每一個位置，索引從 0 開始。

python 
nums = [10, 20, 30, 40, 50]
print(nums[0])     # 10（第一個）
print(nums[4])     # 50（第五個）
print(nums[-1])    # 50（負索引 = 從尾巴數，-1 是最後一個）
print(nums[-2])    # 40（倒數第二個）
print(len(nums))   # 5（一共 5 個元素）

nums[2] = 99        # 修改第 3 個元素
print(nums)          # [10, 20, 99, 40, 50]
⚠ 索引超出範圍會直接報錯

長度 5 的 list，合法索引是 0~4（或 -1~-5）。存取 nums[5] 會得到 IndexError——這正是「程式測試與除錯」很愛考的情境：邊界值有沒有算對。

建立串列的幾種方法

建立串列 
a = []                          # 空串列，之後再 append
b = [0] * 5                     # [0, 0, 0, 0, 0]：n 個 0，計數、記錄狀態最常用
c = list(range(1, 6))           # [1, 2, 3, 4, 5]
d = [i * i for i in range(5)]   # [0, 1, 4, 9, 16]：串列生成式（下面介紹）
print(a, b, c, d)
▼ 執行結果 [] [0, 0, 0, 0, 0] [1, 2, 3, 4, 5] [0, 1, 4, 9, 16]
📌 [0] * n 是什麼意思？

串列的 * 是「重複」（字串也一樣，'-' * 10 是 10 個減號，單元 6 會再講）：[0] * 5 就是把 [0] 重複 5 次。一維串列這樣寫沒問題；二維表格不能寫 [[0] * m] * n，原因在單元 6 附。

串列生成式：一行建立串列

單元 4 附的 list(map(int, input().split()))，很多程式（包括識讀題）會寫成 [int(x) for x in input().split()]。這叫串列生成式：[運算式 for 變數 in 一串東西]，意思是「把一串東西裡的每一個拿出來，套進運算式，收集成一個新的串列」。

串列生成式 
print([x * x for x in range(1, 6)])          # [1, 4, 9, 16, 25]
print([int(x) for x in "3 5 7".split()])     # [3, 5, 7]
print([x for x in range(10) if x % 3 == 0])  # [0, 3, 6, 9]（後面加 if，只留下符合的）
print([0 for _ in range(4)])                 # [0, 0, 0, 0]
▼ 執行結果 [1, 4, 9, 16, 25] [3, 5, 7] [0, 3, 6, 9] [0, 0, 0, 0]
用 map()用串列生成式
list(map(int, input().split()))[int(x) for x in input().split()]
list(map(float, input().split()))[float(x) for x in input().split()]

兩種寫法結果完全一樣，挑一種習慣就好。單元 4 附讀 n 行表格的迴圈，也可以寫成一行：[list(map(int, input().split())) for _ in range(n)]，每一輪讀一行，收集成 n 列。

⚠ 識讀陷阱一：生成式裡的變數不會改到外面

中括號裡的 x 只在生成式裡面有效。外面如果也有一個 x，跑完生成式之後還是原來的值。

外面的 x 沒有被改掉 
x = 'hi'
a = [x for x in range(3)]
print(x, a)          # hi [0, 1, 2]
▼ 執行結果 hi [0, 1, 2]
⚠ 識讀陷阱二：左右的個數要一樣

a, b = [int(x) for x in input().split()] 左邊有 2 個變數，右邊的串列就必須剛好 2 個元素；輸入 3 個數會出錯。

輸入 3 個數，卻只用 2 個變數接 
a, b = [int(x) for x in "100 45 25".split()]
▼ 執行結果 （沒有輸出） Traceback (most recent call last): File "程式.py", line 1, in <module> ValueError: too many values to unpack (expected 2)

02切片（slicing）

用 list[起點:終點] 一次取出一段，包含起點、不包含終點，不寫起點／終點就代表「到底」：

python 
nums = [10, 20, 30, 40, 50]
print(nums[1:3])    # [20, 30]      索引 1、2（不含 3）
print(nums[:3])      # [10, 20, 30]  從頭到索引 2
print(nums[2:])      # [30, 40, 50]  從索引 2 到底
print(nums[:])        # [10, 20, 30, 40, 50]  整份複製一份
print(nums[::-1])     # [50, 40, 30, 20, 10]  反轉（step = -1）

03走訪 List：三種寫法

python 
nums = [10, 20, 30, 40, 50]

for x in nums:                       # 寫法一：直接拿「值」，最常用
    print(x, end=" ")
print()

for i in range(len(nums)):           # 寫法二：拿「索引」，需要位置時用這種
    print(f"nums[{i}]={nums[i]}", end="  ")
print()

for i, x in enumerate(nums):         # 寫法三：索引和值一起拿
    print(f"{i}:{x}", end="  ")
print()
📌 小括號 ( ) 是 tuple，走訪方式一樣

識讀題有時候用小括號寫一串資料，例如 for t in (-5, -1, 5, 11):。小括號是 tuple（元組），用 for 走訪、用 t[0] 取值、用 len() 都跟串列一樣；差別是 tuple 不能修改（不能 append、不能改某一格）。

走訪 tuple 
for t in (-5, 3, 8):
    print(t, end=" ")
print()
p = (3, 5)
print(p[0], len(p))
▼ 執行結果 -5 3 8 3 2

04常見操作：不靠內建函式，自己動手實作

APCS 程式實作常常要求你自己寫出邏輯，而不是只呼叫內建函式。這幾個「手刻」模式一定要練到反射動作：

找最大值

python 
nums = [23, 67, 12, 89, 45]
mx = nums[0]              # 先假設第一個是最大
for x in nums:
    if x > mx:
        mx = x
print(mx)   # 89

線性搜尋（找某個值在哪個位置）

python 
nums = [23, 67, 12, 89, 45]
target = 12
pos = -1                    # 先假設找不到
for i in range(len(nums)):
    if nums[i] == target:
        pos = i
        break                # 找到就不用再找了
print(pos)   # 2

原地反轉（不用切片，自己交換）

python 
nums = [1, 2, 3, 4, 5]
n = len(nums)
for i in range(n // 2):
    nums[i], nums[n - 1 - i] = nums[n - 1 - i], nums[i]   # 頭尾交換
print(nums)   # [5, 4, 3, 2, 1]
🔎 Python 一行交換的祕密

a, b = b, a 這種寫法叫多重指定，Python 會先把右邊全部算好，再一次指定給左邊，所以不需要額外的暫存變數就能交換兩個值。C／Java 通常要寫三行（借一個暫存變數）才能做到同樣的事。

索引用 % 繞一圈

走到串列尾巴之後要「回到開頭」，可以把索引 % n：索引 n 會變回 0、n+1 變回 1，永遠不會超出範圍。

環狀走訪 
a = [10, 20, 30, 40, 50]
n = len(a)
for i in range(n):
    print(a[(i + 2) % n], end=" ")   # 從索引 2 開始，繞一圈
print()
▼ 執行結果 30 40 50 10 20

05常用 List 方法

方法作用範例
.append(x)在尾端加一個元素nums.append(6)
.insert(i, x)在索引 i 插入 xnums.insert(0, 99)
.remove(x)刪除「第一個」值為 x 的元素nums.remove(30)
.clear()把串列清空，變成 []（跟 b = a 共用的那一個也會一起變空）nums.clear()
.pop(i)移除並回傳索引 i 的元素（省略 i 就是最後一個）nums.pop()
.sort()原地排序（reverse=True 可降冪）nums.sort()
.index(x)回傳第一個 x 的索引nums.index(30)
.count(x)x 出現幾次nums.count(30)
x in a／x not in ax 在不在串列裡（結果是 True／False）30 in nums
sum()/max()/min()總和／最大／最小（內建函式，不是方法）sum(nums)
🔎 排序也可以指定規則：key= 與 reverse=True

reverse=True 是由大到小；key=len 是「依長度排序」：每個元素先丟進 len() 算出長度，再依長度排。sorted() 和 .sort() 都可以加這兩個參數。

key= 與 reverse=True 
words = ['pear', 'fig', 'banana']
print(sorted(words))                     # ['banana', 'fig', 'pear']（字典順序）
print(sorted(words, key=len))            # ['fig', 'pear', 'banana']（依長度）
print(sorted([3, 1, 2], reverse=True))   # [3, 2, 1]
▼ 執行結果 ['banana', 'fig', 'pear'] ['fig', 'pear', 'banana'] [3, 2, 1]

在不在裡面：in 與 not in

in、not in、count() 
nums = [1, 5, 7]
print(5 in nums)         # True
print(3 in nums)         # False
print(3 not in nums)     # True
print(nums.count(5))     # 1（5 出現幾次）
▼ 執行結果 True False True 1
⚠ 陷阱：b = a 不是「複製」，是「兩個名字指向同一份資料」

list 是可變（mutable）物件，b = a 只是讓 b 和 a 指向同一個 list，改 b 會連 a 也一起變。想要獨立一份要用 b = a[:] 或 b = a.copy()。這也是「找出程式錯誤」題型很常出的陷阱。

python 
a = [1, 2, 3]
b = a          # b 和 a 指向同一個 list
b[0] = 99
print(a)        # [99, 2, 3]　←　a 也被改了！

c = a[:]        # c 是「獨立複製」的一份
c[0] = 0
print(a)        # [99, 2, 3]　←　a 沒被影響
