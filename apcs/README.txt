明道中學 115學年度第一學期 高中部 APCS 先修班（高一多元選修）— 教學網站
===========================================================

■ 使用方式
1. 解壓縮整個資料夾（請保持資料夾結構完整，html 檔要和 assets 資料夾在一起）。
2. 用瀏覽器（Chrome / Edge / Safari）打開「index.html」即為課程首頁。
3. 從首頁點選任一單元進入獨立頁面上課。

■ 這門課在教什麼
  高一多元選修，每週三下午 2 節。教材延續高一資訊科技的 Python 基礎，針對 APCS 重新整理、
  加深加廣：初級練穩、中級（陣列、字元、字串、二維）練到能上場挑戰；函式與遞迴追蹤是識讀
  的重點，這學期也會練。目標：程式識讀 4 級分、程式實作中級 3 級分。

■ 功能
- 右上角月亮/太陽圖示可切換 淺色（預設）/ 深色。
- 每個 Python 範例右上角有「⧉ 複製」按鈕，複製到 IDLE 執行即可（配合考場不能上網）。
- 每一頁頁首有分頁列：課程首頁／Judge 與識讀練習／函式統整表。
- 每個單元最後有「🧩 本單元去哪裡 Judge」（ZeroJudge 題目、已派過的標 ✅ 與日期）
  與「📝 課後識讀練習」（官方識讀範例＋吳邦一 125 題分單元講義）。
- 單元 4 有巢狀迴圈逐步動畫、break／continue 分頁對照；單元 7 有函式呼叫互動追蹤。
- mock.html：期末線上識讀模擬考（題目與答案加密，密碼跟資電群那一份相同，不寫在任何檔案裡）。
- 練習題可展開解答；按 Ctrl/⌘ + P 可列印或另存 PDF（解答會自動展開）。

■ 檔案結構
  index.html          課程首頁（目前進度、已派 Judge、各單元卡片）
  judge.html          Judge 與識讀練習總表（已派 Judge、依單元題單、識讀講義、期末模擬考）
  functions.html      函式與語法統整表（最右欄是「在哪個單元」）
  mock.html           期末線上識讀模擬考
  教學單元（依上課順序）：
    01 → 01b → 02 → 02b → 03 → 04 → 04b → 05 → 06 → 07 → 07b → 06b → 08 → 09
    鎖定序號：01b 跟 1、02b 跟 2、04b 跟 4、06b 跟 6、07b 跟 7、09 跟 8 一起開放
    （所以共用總表的 apcs 最大值仍是 8）。
  assets/style.css、script.js   共用樣式與互動（跟 course-hub 原版相同）
  assets/progress.js            ★ 跟 course-hub 一樣：讀 ../shared/core/progress.js 的 "apcs"
  assets/tabs.css、plan.css     頁首分頁列、題目檢視等元件
  assets/judge.css              「本單元去哪裡 Judge」與總表的樣式
  assets/reading/               官方識讀範例 PDF 與 30 題截圖
  assets/handouts/              吳邦一 125 題分單元講義（起點篇／挑戰篇一／挑戰篇二＋總整理）
