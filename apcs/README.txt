明道中學 115學年度第一學期 高中部 APCS 先修班 — 教學網站
===========================================================

■ 使用方式
1. 解壓縮整個資料夾（請保持資料夾結構完整，html 檔要和 assets 資料夾在一起）。
2. 用瀏覽器（Chrome / Edge / Safari）打開「index.html」即為課程首頁。
3. 從首頁點選任一單元進入獨立頁面上課。

■ 這門課在教什麼
  教材延續高一資訊科技的 Python 基礎，針對 APCS（大學程式設計先修檢測）重新
  整理、加深加廣。這學期目標：把初級練穩、把中級（陣列、字元、字串）練到能上
  場挑戰；函式（單元7）正式屬於中高級範圍，提早在這學期詳細講，順便替下學期
  的遞迴打地基。下學期若繼續開課，會接著講中高級到高級（遞迴、佇列堆疊、樹、
  圖、DP、分治、貪心）。

■ 功能
- 右上角月亮/太陽圖示可切換 淺色（預設）/ 深色。
- 每個 Python 範例右上角有「⧉ 複製」按鈕；每頁最下方有 Programiz 線上
  編譯器連結，複製程式碼過去即可執行。
- 單元7 有一個「函式呼叫追蹤」互動小工具，一步一步看參數怎麼傳進函式、
  回傳值怎麼傳出來（離線可用）。
- 練習題可展開解答（離線可用）。
- 按 Ctrl/⌘ + P 可列印或另存 PDF（練習解答會自動展開）。

■ 單元鎖定（控制學生看到哪些單元）★重要
  ★ 現在老師平常改進度，不用打開這個資料夾裡的檔案，改上一層的
    ../shared/core/progress.js 就好——那是五科共用的進度總表，裡面
    「apcs」後面的數字就是這一科開放到第幾單元，改一次五科都套用，
    不用五個資料夾分別找。

    這個資料夾自己的 assets/progress.js 現在只是個轉接器，會去讀
    共用總表的值；如果只想讓「這一科」自己控制、不跟其他科一起連動，
    把 assets/progress.js 裡 unlockedUpTo 那一行改成寫死的數字即可。

    unlockedUpTo : 「已經開放到第幾單元」。
                   例如上到第 3 單元就填 3，之後每上完一個單元 +1。
                   還沒開放的單元，學生在首頁會看到變灰、有 🔒、點不開，
                   直接打網址進去也會被擋下並提示「尚未開放」。

    teacherKey   : 老師預覽用的密鑰（跟其他四科同一把 ji32k7au4a83，
                   可改成只有你知道的字串）。這把密鑰跟下面「影片資源庫」
                   用的密鑰現在是兩把互相獨立的，故意設成不同值，各自要換
                   都可以。
                   自己備課時，在任何頁面網址後面加上  ?key=ji32k7au4a83
                   （例如 index.html?key=ji32k7au4a83）就能解鎖預覽全部單元。
                   首頁右下角一律都有「🔒 教師專區」入口（不需要 key 也看得到
                   按鈕，但點進去還是要輸入密鑰才能進影片資源庫，見下方說明）。

  ※ 這是課堂用的「進度控制」，非高強度保全；懂技術的人仍可繞過，
     但對一般上課情境足夠。
