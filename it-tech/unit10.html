Python（五）重複結構

for 迴圈、while 迴圈與迴圈控制

🎯 學習目標

  • 會用 for 迴圈搭配 range() 重複執行
  • 會用 while 迴圈依條件重複
  • 理解 break 與 continue 的差別

01for 迴圈

先認識 list（串列）：用中括號 [ ] 把多個資料依序裝起來、中間用逗號 , 分隔，例如 ["香蕉", "蘋果", "橘子"]。它就像「一排有順序的箱子」：第 1 個是 list1[0]（從 0 開始數）、第 2 個是 list1[1]、第 3 個是 list1[2]。

for 迴圈最方便的用法，就是把 list 裡的元素一個一個取出來處理——每繞一圈，s 就依序變成「香蕉 → 蘋果 → 橘子」，各印一次：

python 
list1 = ["香蕉", "蘋果", "橘子"]
for s in list1:
    print(s)

搭配 range()

range(start, stop, step) 產生數字序列（不含 stop），預設 start=0、step=1。

寫法產生的數字
range(5)0, 1, 2, 3, 4
range(1, 11)1, 2, …, 10
range(0, 10, 2)0, 2, 4, 6, 8
python 
# 計算 1+2+…+10
sum = 0
for i in range(1, 11, 1):
    sum += i
print(sum)   # 55

👇 看不懂 i 怎麼跑、sum 怎麼越加越大嗎？點「下一步」一圈一圈跑跑看：

加總.py　—　目前執行的那一行會反白
sum = 0
for i in range(1, 11, 1):
sum += i
print(sum) # 55
🖥️ 程式輸出
i ＝ －
sum ＝ 0
按「下一步 ▶」開始跑迴圈：i 會從 1 一路數到 10，每一圈把 i 加進 sum。
第幾圈isum ＋ isum 變成

應用：倍數判斷

python 
n = int(input("請輸入一個數："))
for i in range(1, n + 1):
    if i % 6 == 0:
        print(f"{i}是2和3的倍數")
    elif i % 3 == 0:
        print(f"{i}是3的倍數")
    elif i % 2 == 0:
        print(f"{i}是2的倍數")

02while 迴圈

while 在條件成立時一直重複，適合「次數由條件決定」的情況。

python 
total = 0
n = 0
while n < 10:
    n += 1
    total = total + n
print(total)   # 55
⚠ 小心無窮迴圈

while 的條件一定要有機會變成 False（記得讓變數遞增／遞減），否則程式會停不下來。

03break 與 continue

⏱️ 提醒：動畫是「慢動作」

下面的動畫為了讓大家看懂程式的邏輯，是把數字一個一個、慢慢地顯示出來。但實際執行時，因為電腦跑得非常非常非常快，你會看到輸出幾乎一瞬間就全部跳出來，不會像動畫這樣一格一格慢慢跑。

⛔ break：強制離開迴圈

遇到 break 就立刻跳出整個迴圈，後面的圈數都不再跑。點「下一步」跑跑看：

break.py　—　目前執行的那一行會反白
for i in range(1, 11):
if i == 6:
break
print(i, end=",")
🖥️ 程式輸出
i ＝ –
按「下一步 ▶」開始。

⏭️ continue：跳過本次

遇到 continue 就跳過這一圈剩下的動作，直接進入下一圈（迴圈本身不會停）。點「下一步」跑跑看：

continue.py　—　目前執行的那一行會反白
for i in range(1, 11):
if i == 6:
continue
print(i, end=",")
🖥️ 程式輸出
i ＝ –
按「下一步 ▶」開始。

✏️ 課堂練習

  1. 用 for 迴圈印出 1~10 的平方。
  2. 用 while 迴圈算出 1×2×3×…×10（10 的階乘）。
  3. 用迴圈印出 1~50 中所有7 的倍數。
▶ 顯示解答
第 2 題參考解 
# 第 2 題
result = 1
n = 1
while n <= 10:
    result *= n
    n += 1
print("10! =", result)   # 3628800
第 3 題參考解 
# 第 3 題
for i in range(1, 51):
    if i % 7 == 0:
        print(i, end=" ")
# 7 14 21 28 35 42 49
