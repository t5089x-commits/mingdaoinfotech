電腦五大單元

輸入 / 輸出 / 控制 / ALU / 記憶

🎯 學習目標

  • 用生活比喻理解電腦「輸入 → 運算 → 輸出」的運作
  • 認識電腦五大單元各自負責什麼工作
  • 知道 CPU 是什麼，以及哪些因素會影響它的快慢
  • 分辨 GPU 和 CPU 的差別，並說出為什麼 AI／遊戲特別需要 GPU

01電腦怎麼運作？用「一家餐廳」來想

電腦做任何事，都逃不出三個步驟：輸入 → 運算 → 輸出。這其實跟一家餐廳出餐的流程一模一樣：

🍜 餐廳流程

客人點餐（輸入）→ 廚房做菜（運算）→ 把菜端上桌（輸出）

電腦裡負責這整個流程的，就是接下來要介紹的五大單元。

02電腦的五大單元（配餐廳比喻）

把電腦想成一家餐廳，五大單元就是餐廳裡的五種角色：

五大單元餐廳裡的角色負責什麼實際例子
⌨️ 輸入單元點餐服務生接收外面來的資料與指令鍵盤、滑鼠
💾 記憶單元冰箱／倉庫暫時存放要處理的資料與半成品記憶體 RAM
🧠 控制單元店長指揮大家：誰先做、做什麼在 CPU 裡
🧮 算術邏輯單元廚師真正動手「運算」（加減乘除、判斷）
🖥️ 輸出單元上菜把做好的結果送出來給人看螢幕、印表機、喇叭
🧩 CPU 就是「廚房」

其中控制單元（店長）＋ 算術邏輯單元（廚師）合在一起，就是電腦的大腦——CPU（中央處理器）。所以買電腦時 CPU 好不好，影響很大。

03CPU 的快慢看什麼？

同樣是「廚房」，有的出餐快、有的出餐慢。CPU 的快慢主要看三件事：

⏱️ 時脈（速度）

廚師手腳多快。單位是 GHz，數字越大、每秒能做的事越多。

👥 核心數

有幾個廚師同時做菜。核心越多，越能一次處理多件事（多工）。

⚡ 快取記憶體

廚師手邊的小備料檯。快取越大，越不用一直跑遠去倉庫拿東西。

🔎 想更深入（可略過）

CPU 每做一個指令，其實會經過「擷取 → 解碼 → 執行 → 儲存」四個小步驟（合稱一個機器週期）。這部分是進階內容，先知道「CPU 一步步照指令做事」就夠了。

04補充：除了 CPU，為什麼還要 GPU？

我們剛剛說 CPU（廚房）什麼都能算。那為什麼打遊戲、剪影片、跑 AI 的電腦，還要另外花大錢買「顯示卡（GPU，圖形處理器）」？因為有一種工作，CPU 做起來特別吃虧。

🎮 先想一想

為什麼文書處理用內建顯示就夠，但打 3A 大作、剪 4K 影片、跑 AI 就要搶很貴的顯示卡？

差別在「做事的方式」。用兩種人來比喻最好懂：

🧑‍🎓 CPU ＝ 幾個博士生

人少（核心少），但每個都很強，擅長複雜、要照順序、要判斷的任務：開作業系統、跑文書、執行程式邏輯。

🧒 GPU ＝ 幾千個國小生

每個只會簡單的加減乘除，但靠人海戰術，同一瞬間一起算（平行處理）：螢幕上幾百萬個像素、影像、AI 的大量矩陣運算。

💡 一句話記住

CPU 擅長把「一件難事」做得快；GPU 擅長把「一萬件簡單的事」同時做完。

比較項目🧠 CPU 中央處理器🎨 GPU 圖形處理器
核心數少（數個～數十個）多（數百～數千個）
每個核心強、功能齊全簡單、專算數學
擅長複雜邏輯、順序任務大量重複、可平行的運算
比喻幾個博士生幾千個國小生
典型工作作業系統、文書、開程式繪圖、影片、遊戲、AI、挖礦
🚀 接到時事：AI 為什麼讓 NVIDIA 爆紅？

AI 訓練說穿了就是「海量的矩陣加減乘」——正好是 GPU 最拿手、CPU 最吃虧的事。所以這幾年 AI 一紅，做 GPU 的 NVIDIA 就成了全球市值最高的公司之一。你搶不到的那張顯示卡，和新聞上的 AI 浪潮，其實是同一件事。

05資料放哪裡？儲存單元金字塔

電腦裡存放資料的地方不只一種，它們像金字塔一樣分層：越上面越快、越貴、容量越小；越下面越慢、越便宜、容量越大。

另外要記得：暫存器、快取、主記憶體是揮發性（一斷電資料就不見），硬碟／SSD 是非揮發性（斷電資料還在）——這也是為什麼打字要記得存檔！

✏️ 課堂練習

  1. 電腦做任何事都包含哪三個步驟？
  2. 用餐廳比喻：負責「運算（做菜）」的是哪個單元？負責「指揮」的又是哪個？
  3. CPU 是由哪兩個單元合起來的？
  4. 其他條件相同時，時脈 3.5 GHz 與 2.0 GHz 的 CPU 哪個比較快？
  5. 為什麼打字打到一半突然停電，沒存檔的內容會不見？（提示：揮發性）
  6. 為什麼跑 AI 或打遊戲時，GPU 常常比 CPU 更吃香？用「博士生 vs 國小生」的比喻說說看。
▶ 顯示解答
  1. 輸入 → 運算 → 輸出。
  2. 做菜（運算）＝算術邏輯單元（廚師）；指揮＝控制單元（店長）。
  3. 控制單元 ＋ 算術邏輯單元。
  4. 3.5 GHz 較快（時脈較高）。
  5. 因為打字的內容暫時放在「記憶體（RAM）」，它是揮發性的，一斷電就消失；存檔是把它寫進非揮發性的硬碟／SSD。
  6. 因為遊戲畫面、AI 運算屬於「大量又重複、可以同時做」的簡單運算——正是幾千個「國小生」(GPU) 人海戰術的強項；交給幾個「博士生」(CPU) 一題一題算反而慢。
