進階程式設計 —— 課程教學網站（基本版草稿）
===========================================================

■ 使用方式
1. 解壓縮整個資料夾（請保持資料夾結構完整，html 檔要和 assets 資料夾在一起）。
2. 用瀏覽器（Chrome / Edge / Safari）打開「index.html」即為課程首頁。
3. 從首頁點選任一單元進入獨立頁面上課。

■ 這一版做了什麼
- 共 10 個單元，對應你這學期要教的範圍：
    單元 1       課程總覽＋專題預告（含「景氣指標綜合分析」範例作品連結）
    單元 2–4     Python 前導複習（變數與資料型態／運算子與判斷／迴圈與函式）
    單元 5       Vibe Coding 體驗——用 AI 打造 pygame 小遊戲
    單元 6       pandas 基礎操作（依你提供的教材整理：Series＋DataFrame）
    單元 7       Matplotlib 基本使用（依你提供的教材整理：折線／直方／柱狀／圓餅／存檔）
    單元 8–10    專題實作與發表（開放資料探索 → 視覺化工作坊 → PDF 成果與發表）
- 網站視覺風格沿用「資訊安全導論」課程網站的架構，重新配上一組還沒用過的
  暖橘／琥珀色系（其他課程目前用過藍、紫、綠），淺色／深色模式都已經配好。
- 你附的「景氣指標綜合分析」PDF，以及後來給我審閱的五份學長姐真實專題

■ 網站架構（給你自己備課用，學生不需要知道這些）
  index.html          課程首頁（6 大 Part、10 個單元卡片）
  unit01~unit10.html  各單元頁面
  assets/style.css    共用樣式（暖橘／琥珀色系，支援深／淺色）
  assets/script.js    共用互動腳本（深淺色切換、複製程式碼、練習題展開解答等）
  assets/progress.js  轉接器，讀 ../shared/core/progress.js 的共用總表
                       （老師平常改進度改共用總表就好，見下面「■ 單元鎖定」說明）
  assets/examples/    專題範例檔案（目前放了「景氣指標綜合分析.pdf」）
  build/              產生這個網站的 Python 原始碼（common.py 存單元清單與版型、
                       content.py 存每個單元的內容、build.py 執行後會重新產生
                       全部 html）—— 這是為了方便之後大量修改內容用的，教學
                       使用不需理會，但如果你想直接改文字，也可以改 html 檔案本身。

■ 功能
- 右上角月亮/太陽圖示可切換 深色／淺色（預設淺色）。
- 練習題與「顯示解答」可點擊展開；部分單元有隨堂小問答（點一下看答案）。
- 程式碼區塊右上角「⧉ 複製」可以一鍵複製，貼到 VS Code 執行。

■ 單元鎖定（控制學生看到哪些單元）★重要
  ★ 現在老師平常改進度，不用打開這個資料夾裡的檔案，改上一層的
    ../shared/core/progress.js 就好——那是五科共用的進度總表，裡面
    「advprog」後面的數字就是這一科開放到第幾單元，改一次五科都套用，
    不用五個資料夾分別找。

    這個資料夾自己的 assets/progress.js 現在只是個轉接器，會去讀
    共用總表的值；如果只想讓「這一科」自己控制、不跟其他科一起連動，
    把 assets/progress.js 裡 unlockedUpTo 那一行改成寫死的數字即可。

    unlockedUpTo : 「已經開放到第幾單元」（1~10）。
                   例如上到第 3 單元就填 3，之後每上完一個單元 +1。
                   還沒開放的單元，學生在首頁會看到變灰、有 🔒、點不開，
                   直接打網址進去也會被擋下並提示「尚未開放」。

    teacherKey   : 老師預覽用的密鑰，五科統一用 ji32k7au4a83（設在共用
                   總表裡，只用來解鎖單元，跟下面「影片資源庫」用的密鑰
                   是兩把互相獨立的，故意設成不同值，各自要換都可以）。
                   自己備課時，在任何頁面網址後面加上
                   ?key=ji32k7au4a83 （例如 index.html?key=ji32k7au4a83）
                   就能解鎖預覽全部單元；學生沒有這個密鑰，看到的仍是鎖住
                   的狀態。

  ※ 這是課堂用的「進度控制」，非高強度保全；懂技術的人仍可繞過，
     但對一般上課情境足夠。
