Python 前導複習（二）運算子與判斷

算術／比較／邏輯運算子、if／elif／else

🎯 學習目標

  • 能正確使用算術、比較、邏輯與複合指定運算子
  • 能寫出 if、if-else、if-elif-else 條件判斷
  • 能用 and／or／not 組合多個條件

01運算子 Operator

類別運算子說明
算術運算子+ - * / // % **加、減、乘、除、整數除、取餘數、次方
比較運算子== != > < >= <=回傳 True／False
邏輯運算子and or not組合多個條件
複合指定運算子+= -= *= /=「先運算、再存回自己」的簡寫
python 
a = 7
print(a // 2)   # 3   整數除（無條件捨去）
print(a % 2)    # 1   取餘數
print(a ** 2)   # 49  7 的平方

score = 88
score += 2       # 等同 score = score + 2
print(score)     # 90

print(3 > 2 and 5 > 4)   # True：兩個條件都成立
print(3 > 2 or 1 > 4)    # True：至少一個成立
print(not (3 > 2))       # False：把 True 反過來
print(10 % 3 == 1)→ True：10 除以 3 餘 1，1 == 1 為 True。
print(5 > 3 and 2 > 3)→ False：5 > 3 是 True，但 2 > 3 是 False，and 要兩個都 True 才成立。

02單向判斷 if

條件成立（True）才執行縮排內的程式碼：

python 
score = 85
if score >= 60:
    print("及格了！")
print("程式繼續往下跑")
⚠ 縮排很重要

Python 用縮排（通常是 4 個空白）來表示「這行屬於 if 底下」，縮排錯了程式邏輯就會跑掉，甚至直接報錯。

03雙向判斷 if–else

python 
score = 55
if score >= 60:
    print("及格了！")
else:
    print("不及格，再加油！")

04多向判斷 if–elif–else

有多個條件要依序檢查時，用 elif（else if 的縮寫）：

python 
score = 76

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"分數 {score} 分，等第是 {grade}")
💡 由上往下、符合第一個就停

elif 會由上往下依序檢查，一旦符合某一條就執行該區塊、不再往下比對。所以條件通常要「由嚴格排到寬鬆」，順序寫反答案就會錯。

✏️ 課堂練習：分數等第判斷

寫一支程式：用 input() 讀入一個 0–100 的分數（記得轉成 int），依照下表印出等第與是否及格：

分數範圍等第
90 以上A
80–89B
70–79C
60–69D
60 以下F（不及格）
▶ 顯示解答／參考方向
python 
score = int(input("請輸入分數："))

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

result = "及格" if score >= 60 else "不及格"
print(f"等第：{grade}（{result}）")
