02變數 Variable

變數用來存放資料，可以想成一個貼了名字的箱子：用指定運算子 = 把右邊的值放進左邊的箱子。

python 
x = 1
print(x)          # 1

a = b = c = 20    # 一次把 20 指定給 a、b、c
age, name = 17, "小明"   # 同時指定不同的值

a = 10
a = a + 5         # 取出 a、加 5、再存回 a
print(a)          # 15

命名規則

  • 首字必須是字母、底線 _ 或中文，其後可加數字。
  • 區分大小寫：age 與 Age 是不同變數。
  • 不能使用 Python 保留字（如 if、for）當變數名。
  • 盡量避免用內建函式名稱當變數（如 list、str、print），否則會把它的原本功能蓋掉。
合法命名 ✅不合法命名 ❌為什麼不合法
score2score首字不能是數字
total_pricetotal price名稱中不能有空白
my_listlist與內建函式同名，會蓋掉原本功能

03資料型態 Data Type

用 type() 可以查看某個值是什麼型別：

分類型別說明範例
數值型int 整數沒有小數點1、-20
數值型float 浮點數帶小數點1.5、3.14
數值型bool 布林值只有真／假兩種True、False
字串型str 字串用引號括住的文字"Hello"
容器型list 串列一串有順序的資料[1, 2, 3]
容器型dict 字典「鍵 → 值」對應的資料{"name": "小明"}
python 
x = 1
print(x, type(x))          # int

y = 1.5
print(y, type(y))          # float

flag = True
print(flag, type(flag))    # bool

name = "小明"
print(name, type(name))    # str
🔎 動態型別

Python 是動態型別：型態由「指派的值」決定，同一個變數之後可以改放不同型態的值，不需要事先宣告。

python 
a = 10
print(a, type(a))   # int
a = 3.2
print(a, type(a))   # float —— 同一個 a，型別跟著「值」改變
a = "換成字串了"
print(a, type(a))   # str

04型別轉換 Casting

把一個值從一種型態轉成另一種，稱為轉型（casting）：

函式作用例子
int(x)轉成整數（小數直接捨去）int(3.9) → 3
float(x)轉成浮點數float(5) → 5.0
bool(x)轉成布林值bool(0) → False
str(x)轉成字串str(100) → "100"
python 
x = 54.87
y = int(x)
print(x)   # 54.87
print(y)   # 54  （.87 被直接丟掉，不是四捨五入！）

💭 先自己猜猜看：下面這幾行 bool() 會印出 True 還是 False？

print(bool(""))→ False：空字串（裡面完全沒有字）算 False。
print(bool(0))→ False：數字 0 算 False。
print(bool("False"))→ True：小心陷阱！"False" 是「非空字串」，只要字串裡有字就是 True，跟裡面寫的字是不是「False」無關。
規則

空字串、0、None（還有空的容器，如 []、{}）會是 False；其餘全部都是 True。

05格式化輸出：f-string

要把變數的值「排版」進一段文字裡，最方便的方式是 f-string：在字串前面加上 f，用 {變數} 把值嵌進去。

python 
name = "小明"
age = 17
score = 88.666

print(f"我是{name}，今年{age}歲。")
print(f"我的分數是{score:.1f}分")   # :.1f 保留小數點後 1 位 → 88.7分
💡 小技巧：:.1f／:.2f

{變數:.1f} 表示四捨五入到小數點後 1 位，.2f 就是 2 位，畫圖表、算平均分數時非常常用。

✏️ 小挑戰

  1. 用 input() 讀取使用者輸入的姓名與年齡（年齡記得轉成 int）。
  2. 用 f-string 印出一句自我介紹，例如「我是小明，今年 17 歲」。
  3. 算出「10 年後的年齡」並印出來。
▶ 顯示解答／參考方向
python 
name = input("你的名字是？")
age = int(input("你的年齡是？"))

print(f"我是{name}，今年{age}歲。")
print(f"10 年後我 {age + 10} 歲。")
