Matplotlib 基本使用

折線圖、直方圖、柱狀圖、圓餅圖與存檔

🎯 學習目標

  • 能匯入 matplotlib.pyplot 並繪製基本圖表（標題／軸標題／格線／刻度）
  • 能畫出折線圖、直方圖、柱狀圖、圓餅圖
  • 能用 savefig() 將圖表存成圖檔
  • 能依資料特性選擇合適的圖表類型，為專題做準備

01匯入 Matplotlib

就像之前用 pd 作為 pandas 的簡寫，Matplotlib 也習慣用簡寫匯入：

python 
import matplotlib.pyplot as plt

plt.plot()
plt.show()

02標題、軸標題、格線與刻度

python 
plt.title("uniform accelerated motion")  # 表格標題
plt.xlabel("Time")                        # x 軸標題
plt.ylabel("Velocity")                    # y 軸標題
plt.grid(True)                            # 格線
plt.plot()
plt.show()

調整刻度可以用 xticks／yticks，或是用 axis 一次設定 x、y 軸的顯示範圍：

python 
plt.xticks([0, 1, 2, 3, 4])
plt.yticks([0, 0.8, 1.0, 1.3, 1.7])
plt.show()

plt.axis([0, 4, 0, 2])   # [xmin, xmax, ymin, ymax]
plt.show()

03折線圖

只給 Y 值時，X 會自動被設成 0, 1, 2, ⋯：

python 
plt.plot([0, 1, 4, 9, 16])
plt.show()

也可以同時給 X 值和 Y 值：

python 
x = [0, 0.2, 0.4, 0.6, 0.8]
y = [i ** 2 for i in x]
plt.plot(x, y)
plt.show()

修改樣式（顏色、線條種類、線寬）：

python 
x = [0, 0.2, 0.4, 0.6, 0.8]
y = [i ** 2 for i in x]
plt.plot(x, y, 'r:', linewidth=5)   # 紅色、虛線、線寬 5
plt.show()

04直方圖 Histogram

直方圖描述的是連續型資料（例如年齡、金額、身高），X 軸上的區間彼此有順序性。

python 
import matplotlib.pyplot as plt
import numpy as np

x = np.random.randint(100, size=10)
plt.hist(x, bins=10)
plt.show()
python 
import matplotlib.pyplot as plt
import numpy as np

z = np.random.randn(10000)
plt.hist(z, bins='auto')
plt.show()

05柱狀圖 Bar Chart

柱狀圖（長條圖）描述的是確切的類別，類別之間沒有順序關係，可以依需要調整排列順序：

python 
import matplotlib.pyplot as plt
import numpy as np

x = np.random.randint(1000, size=10)
y = np.random.randint(1000, size=10)
plt.bar(x, y)
plt.show()

06圓餅圖 Pie Chart

圓餅圖利用百分比呈現每個資料的比例：

python 
import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame([
    ['Czech Republic', 10228744], ['France', 61083916],
    ['Germany', 82400996], ['Greece', 10706290]],
    columns=['country', 'pop'])

separated = [0, 0, 0, 0.3]
plt.pie(df['pop'], labels=df['country'], autopct='%1.2f%%',
        pctdistance=0.7, explode=separated)
plt.title('Population')
plt.show()

07儲存檔案

用 savefig() 可以把圖表直接存成圖檔（記得放在 plt.show() 之前）：

python 
import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame([
    ['Czech Republic', 10228744], ['France', 61083916],
    ['Germany', 82400996], ['Greece', 10706290]],
    columns=['country', 'pop'])

separated = [0, 0.1, 0, 0.3]
plt.pie(df['pop'], labels=df['country'], autopct='%.3f%%',
        pctdistance=0.5, explode=separated)
plt.title('Population')
plt.savefig('plot.png')
plt.show()

08VS Code 操作站

🖼️圖表視窗跳出來了？

一般直接執行 .py 檔，plt.show() 會另外跳出一個圖表視窗，關掉視窗程式才會繼續往下跑。

📓想在編輯器裡直接看圖？

安裝 VS Code 的 Jupyter 延伸套件，用 Interactive Window（互動視窗）執行，圖表會直接顯示在編輯器右側，很適合一邊調整一邊看結果。

💾存檔在哪裡？

savefig("plot.png") 預設會存在你目前 .py 檔案所在的資料夾，可以打開檔案總管確認。

🎨中文字變成方框？

圖表標題若用中文出現亂碼，可以加上 matplotlib.rcParams["font.family"] = ["Microsoft JhengHei"]（Windows）指定中文字型。

✏️ 課堂練習

想像一組資料：一週五個上課天（一～五），某飲料店每天的來客數分別是 [42, 35, 58, 61, 77]。畫出柱狀圖呈現這組資料，並存成 drink_sales.png。

▶ 顯示解答／參考方向
python 
import matplotlib.pyplot as plt

days = ["一", "二", "三", "四", "五"]
customers = [42, 35, 58, 61, 77]

plt.title("本週每日來客數")
plt.xlabel("星期")
plt.ylabel("來客數")
plt.bar(days, customers)
plt.savefig("drink_sales.png")
plt.show()
