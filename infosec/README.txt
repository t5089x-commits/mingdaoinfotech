資訊安全導論 —— 課程教學網站（基本版草稿）
===========================================================

■ 使用方式
1. 解壓縮整個資料夾（請保持資料夾結構完整，html 檔要和 assets 資料夾在一起）。
2. 用瀏覽器（Chrome / Edge / Safari）打開「index.html」即為課程首頁。
3. 從首頁點選任一單元進入獨立頁面上課。

■ 這是「基本版」，接下來可以怎麼調整
- 這一版先把 20 個單元的骨架和內容都放上來了，內容主要取材自你附的 PPT
  （Chapter 1、Caesar／Monoalphabetic／Polyalphabetic／Rotor、RSA、Chapter 6 比特幣）
  以及你附的去年參考連結（Enigma 影片與模擬器、RSA 教學 PDF、比特幣／Web3.0 相關影片）。
- 有幾個單元（古典密碼學、虛擬貨幣與比特幣、RSA、Merkle Tree 等）在頁面內還留著
  「這個單元的兩種教學方案」卡片，是刻意先把兩種可行做法都寫出來，之後可以挑一種、
  或是混著用 —— 這些卡片一眼就找得到（淺綠色的框）。單元 1（開場方式）和單元 2
  （影片破題＋討論）已經依照你的選擇改成單一流程了。
- 單元 8（專題啟動 PBL）和 Part 3（單元 13–15，成果製作）已經改成三條專題路線
  （技術實作／議題研究／未來機制發想），並加了「Vibe Coding 時代」的資安提醒，
  對應這學期文組／社會組同學的需求，不強制要求寫程式。
- 評量配分／班級名稱等都是先抓一個合理的預設值，之後跟我說要怎麼改就可以。
- 想要新增/刪除單元、調整順序、換掉某段內容、加真實案例……都可以直接跟我說。

■ 網站架構（給你自己備課用，學生不需要知道這些）
  index.html          課程首頁（4 大 Part、20 個單元卡片）
  unit01~unit20.html  各單元頁面
  assets/style.css    共用樣式（沿用「資訊科技」課程網站的視覺風格）
  assets/script.js    共用互動腳本（深淺色切換、練習題展開解答等）
  assets/progress.js  課程進度設定（要不要鎖單元、老師預覽密鑰）
  build/              產生這個網站的 Python 原始碼（common.py 存單元清單與版型、
                       content.py 存每個單元的內容、diagrams.py 存示意圖 SVG、
                       build.py 執行後會重新產生全部 html）
                       —— 這是為了方便之後大量修改內容用的，教學使用不需理會，
                       但如果你想直接改文字，也可以改 html 檔案本身。

■ 功能
- 右上角月亮/太陽圖示可切換 深色（預設淺色）/ 淺色。
- 練習題與「顯示解答」可點擊展開。
- 影片區塊點縮圖會開新分頁到 YouTube；外部連結（PDF、線上工具）用小卡片呈現。
- 目前 assets/progress.js 把 unlockedUpTo 設為 20（全部單元都開放），方便你自己整份
  瀏覽調整；之後要正式上課鎖單元進度，把這個數字改小即可。
- 這一版不特別標註學期／年度，網站專屬「資訊安全導論」這門課，之後每學期都可以直接沿用。

■ 放到網路上
  把整個資料夾上傳到任何靜態網站主機（GitHub Pages、Netlify 等）即可。
