幣圈模擬交易所 —— 老師一次性設定說明
=====================================================

這個交易所分成「前端網頁」和「後端資料庫」兩塊：
  ‧ 前端網頁：就是 exchange/ 這個資料夾，放在 GitHub Pages（你現在的教材網站）。
  ‧ 後端資料庫：一份你自己的 Google 試算表 ＋ Apps Script 程式。
     全班的帳戶、下單紀錄、開關狀態都存在這份試算表裡，打開就是報表。

整個設定大約 10 分鐘，只要做一次。之後上課只要開/關「交易時段」開關就好。


────────────────────────────────────────
STEP 1　建立後端試算表 ＋ 貼上程式
────────────────────────────────────────
1. 到 https://sheets.google.com 新增一份空白試算表，命名例如「資安交易所後台」。
2. 上方選單：擴充功能(Extensions) → Apps Script。
3. 把左邊預設的 Code.gs 內容整個刪掉，改貼上本資料夾裡「Code.gs」的全部內容，存檔（💾）。
4. 回到 Apps Script 編輯器上方，函式下拉選「setupSheets」→ 按「執行」。
   第一次會跳出授權：選你的 Google 帳號 → 進階 → 前往(不安全) → 允許。
   （這是因為程式要去讀寫「你自己這份」試算表、以及抓幣價，正常現象。）
5. 執行完回試算表，會自動長出這幾個分頁：
      名冊、帳戶、交易紀錄、事件紀錄、設定、價格快取。


────────────────────────────────────────
STEP 2　填名冊（學號、姓名、PIN）
────────────────────────────────────────
到「名冊」分頁，一列一個學生，填：
      學號 ｜ 姓名 ｜ PIN ｜ 起始資金USD(可留空=預設100000) ｜ 班級(可留空)

PIN 是學生登入用的 4 位數密碼：
  ‧ 可以自己填，
  ‧ 或是用上方「🏦 交易所管理」選單 →「幫名冊沒有 PIN 的人自動產生」一鍵產生。
把學號＋PIN 發給對應的學生即可（像發帳密一樣）。


────────────────────────────────────────
STEP 3　把後端「部署」成網址
────────────────────────────────────────
1. 回 Apps Script 編輯器，右上角「部署(Deploy)」→「新增部署作業」。
2. 類型選「網頁應用程式(Web app)」。
3. 設定：
      執行身分(Execute as)：我(你自己)
      誰可以存取(Who has access)：⚠ 選「任何人(Anyone)」
         （這樣學生不用登入 Google 也能用；資料仍只存在你的試算表）
4. 按「部署」，複製它給你的網址，長得像：
      https://script.google.com/macros/s/AKfy............/exec


────────────────────────────────────────
STEP 4　把網址貼進前端，重新上傳
────────────────────────────────────────
1. 用記事本打開本資料夾的「config.js」。
2. 把這一行引號裡的字換成你 STEP 3 複製的網址：
      window.EXCHANGE_API = "請貼上你的 Apps Script 網址";
   存檔。
3. 把整個 exchange/ 資料夾（含你改好的 config.js）上傳到 GitHub 的 infosec/ 底下。
4. 開 https://你的網站/infosec/exchange/ 就能看到登入畫面了。
   （課程首頁「🔮 額外企劃 → 幣圈模擬交易所」那張卡片也會連到這裡。）


────────────────────────────────────────
上課怎麼操作（平常只做這些）
────────────────────────────────────────
‧ 開放/關閉交易：三個地方任選其一，效果相同——
    (a) 交易所網頁最下方「🛠️ 老師控制台」輸入密碼 → 切換，或
    (b) 試算表上方「🏦 交易所管理」選單 → 開啟/關閉交易時段，或
    (c) 直接改「設定」分頁 tradingOpen 的值 TRUE/FALSE。
  關閉時學生看得到頁面、看得到報表，但不能下單。

‧ 老師控制台密碼：預設 mdinfo-teacher，
  請到「設定」分頁把 teacherPassword 改成只有你知道的字串。

‧ 看全班報表：打開試算表就是即時報表；或在老師控制台按「看全班排行榜」。
‧ 學生下單理由：每筆下單學生都「必須」寫為什麼這樣操作（可貼新聞連結或自己說明），
  內容存在「交易紀錄」分頁最右邊的「下單理由（學生填）」欄，方便你課後看他們的判斷依據。


────────────────────────────────────────
資安事件（釣魚演練）怎麼跑
────────────────────────────────────────
1. 挑一堂你想演練的課，把 phishingEventOn 開關打開
   （老師控制台、選單、或設定分頁皆可）。
2. 學生的交易頁會冒出一個「🎁 玩小遊戲免費領 $50000 投資金」的假廣告。
   點了 → 跳出假的「領取頁」要他輸入學號／PIN「驗證身分」→ 按「立即領取」。
3. 一按下去，系統會：
      ‧ 立刻跳出「你被釣魚了（這是演練）」的教學說明＋破綻解析；
      ‧ 從他帳戶轉走一部分現金（預設 30%，可在設定 phishTakePct 改），
        而且拿不回來（會反映在排行榜上）；
      ‧ 在「事件紀錄」分頁記下是誰上鉤。
4. 演練結束把 phishingEventOn 關掉即可。

★ 安全說明（也可以直接講給學生聽）：
  這個假頁面「故意」不會真的讀取、也不會儲存學生打進去的任何密碼——
  後端只記錄「這位學號願意點、願意送出」這個動作。要教的重點就是：
  在真實世界，光是「肯點、肯填」本身就足以讓你受害，不是密碼多複雜的問題。
  真正的釣魚網站則會把你送出的帳密傳走。這正好對應後面單元 17「Web3 資安風險 /
  釣魚錢包」的內容。

  金額、幣種都是虛擬的，整套系統不涉及任何真實金流或投資。


────────────────────────────────────────
常見狀況
────────────────────────────────────────
‧ 學生說「尚未設定後端網址」：config.js 還沒貼網址，或上傳的是沒改到的舊檔。
‧ 改了程式(Code.gs)之後：要重新「部署 → 管理部署作業 → 編輯(鉛筆) → 版本選新版本 →
  部署」，網址不變。只改「設定」分頁的值則不用重新部署。
‧ 幣價顯示 $0：CoinGecko 偶爾擋流量，稍等一下會自動恢復（系統會用上一次快取價）。
‧ 想重開一輪：選單「⚠ 重設一輪」，所有人回到起始資金（交易紀錄保留）。
