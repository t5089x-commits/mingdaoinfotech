明道中學 115學年度第一學期 高中部 資訊科技 — 教學網站
===========================================================

■ 使用方式
1. 解壓縮整個資料夾（請保持資料夾結構完整，html 檔要和 assets 資料夾在一起）。
2. 用瀏覽器（Chrome / Edge / Safari）打開「index.html」即為課程首頁。
3. 從首頁點選任一單元進入獨立頁面上課。

■ 功能
- 右上角月亮/太陽圖示可切換 深色（預設）/ 淺色。
- 每個 Python 範例右上角有「⧉ 複製」按鈕；每頁最下方有 Programiz 線上
  編譯器連結，複製程式碼過去即可執行。
- 單元2 有進位轉換器、單元3 有邏輯閘互動、練習題可展開解答（皆離線可用）。
- 按 Ctrl/⌘ + P 可列印或另存 PDF（練習解答會自動展開）。

■ 單元鎖定（控制學生看到哪些單元）★重要
  打開 assets/progress.js，裡面只有兩個設定：

    unlockedUpTo : 「已經開放到第幾單元」。
                   例如上到第 3 單元就填 3，之後每上完一個單元 +1。
                   還沒開放的單元，學生在首頁會看到變灰、有 🔒、點不開，
                   直接打網址進去也會被擋下並提示「尚未開放」。

    teacherKey   : 老師預覽用的密鑰（目前為 t5089x，可改成只有你知道的字串）。
                   自己備課時，在任何頁面網址後面加上  ?key=t5089x
                   （例如 index.html?key=t5089x）就能：
                     (1) 解鎖預覽全部單元；
                     (2) 首頁右下角出現「🎬 影片資源庫（老師專用）」入口。
                   學生沒有密鑰，看不到這些，看到的仍是鎖住的狀態。

  ※ 這是課堂用的「進度控制」，非高強度保全；懂技術的人仍可繞過，
     但對一般上課情境足夠。

■ 圖片（單元6 電腦硬體 已示範）
- 各零組件的實體照片來自 Wikimedia Commons（自由授權），以穩定連結嵌入，
  瀏覽時需要「網路連線」才會顯示；若某張圖沒出現，會顯示灰色備援框，
  告訴我是哪一張，我可以換一張。
- 想在其他單元加圖片，把圖給我（上傳或給網址）即可，我會幫你嵌入。

■ 課堂互動工具的位置
- 進位轉換器（單元2）、邏輯閘互動（單元3）等工具，放在頁面最底部
  「🧪 課堂互動工具」區（上一/下一單元之下），刻意讓學生先自己算，
  再用工具對答案。
- 「Programiz 線上編譯器」連結只出現在 Python 單元（8–12）。

■ 影片資源庫（教師專區）
  首頁右下角有「🔒 教師專區」按鈕 → 點了進入 video-access.html（上鎖頁）
  → 輸入密鑰 t5089x → 才會跳轉到 video-library.html（影片對照表）。
  學生按了只會看到上鎖頁、進不去。標「⚠ 需斟酌」的影片為敏感題材。

■ 檔案結構
  index.html          課程首頁
  unit01~unit12.html  各單元頁面
  video-library.html  影片資源庫（教學規劃用）
  assets/style.css    共用樣式
  assets/script.js    共用互動腳本
  assets/progress.js  ★ 課程進度 / 鎖定設定（老師每週改這裡）
  images/             圖片（加法器電路圖、皮卡丘像素圖等）
  build/              原始產生器程式（教學使用不需理會）

■ 放到網路上
  把整個資料夾上傳到任何靜態網站主機（GitHub Pages、Netlify 等）即可。
